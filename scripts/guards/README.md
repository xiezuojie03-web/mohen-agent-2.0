# Data Production Guards

This directory is the target category for repository-level machine enforcement scripts.

Phase C freezes contracts; executable `.mjs` implementations are completed later.

Guard categories:
- registry / structure / naming / identifiers (cross-cutting)
- G0 source/acquisition
- G1 evidence quality
- G2 world integrity
- G3 interpretation
- G4 runtime eligibility
- review triage (internal adjudication debt control)

A Guard is an enforcement mechanism, not a production Stage.
