V1.3 五母题通用方法深化版

从值得追问的人文问题出发，在证据中解释历史，将理解转化为时空体验与下一步开发。

文档定位：这是叙事方法论与内容研究框架，不是 UI 规范，也不是技术架构。它用于约束 AI/Agent 的选题与叙事方向，避免“资料驱动的随机讲解”和“为了功能证明而编故事”。

本版保留十二节框架，先将五个核心母题细化为通用叙事方法，指导 UI 表达与数据生产；金泽先盘点实际材料，不以预先选定主母题为研究目标。新增附录 A 的五母题方法卡与附录 B 的 UI、数据、组合及扩展规则。

# 1 为什么要修正先让资料说话

“先让资料说话”适合避免先有结论、后找证据，但如果把它当成墨痕的内容起点，会产生另一个问题：现存资料本来就是偶然、不完整、偏科的。数据库里有什么，AI 就讲什么，最后很容易变成资料摘要、POI 百科或随机知识拼接。

这里必须保留一条边界：母题不是预设答案。我们可以先问“今天孤立的遗存是否曾属于同一个生活世界？”，但不能先断言“它们一定属于同一个生活世界”，再去挑证据证明。母题负责提出问题，Evidence 负责约束答案。

更适合墨痕的顺序是：人文母题 → 研究问题 → 定向寻找资料 → 放回历史背景 → 证据检验 → 形成解释 → 转化为体验。研究过程中可以根据新证据回退、修正问题。

听通史、阅读历史人文书籍、论文和专题文章带来的启发，在于把人物、事件、制度与环境放回当时的条件，追问为什么形成、为什么变化、为什么发生在这里。考古发现、遗址、典籍与器物既可支持解释，也可能修正甚至推翻它。

# 2 固化稳定的人文追问

如果把五个母题固化成固定剧情，AI 很快又会走偏：每到一个地方都强行套“桥—河—寺”“消失—重现”的套路。真正应该固化的是一组跨地域、跨时代都有效的探索视角。Agent 可以选择最适合当地真实材料的一副或几副，但不能强迫现实服从模板。

固定的是追问的方向，开放的是历史答案。母题库提供可选择的研究视角，具体问题和解释必须服从当地材料。

# 3 五个核心叙事母题

| **母题**               | **核心问题**                                         | **用户吸引力**               | **最终重新看见**                  |
| -------------------- | ------------------------------------------------ | ----------------------- | --------------------------- |
| M1 消失的关系世界           | 今天彼此孤立的桥、河、寺、街、市场、遗址、人物或制度，过去是否曾属于同一个生活世界？       | 把“景点列表”变成逐渐显影的关系世界。     | 今天留下的是碎片；历史曾是被人生活过的整体。      |
| M2 一个地方为什么会长成这样      | 为什么这里会有这么多桥/庙/巷/码头/城门/会馆/园林？反复出现的事物背后是什么结构？      | 从人人看得见的现象进入更深的地方逻辑。     | 一个熟悉物件可能是理解整个地方的一把钥匙。       |
| M3 过去的人生活在怎样的一张“地图”里 | 如果拿掉今天的道路、行政边界和景点分类，过去的人如何通过水、路、市场、信仰、生产和往来理解这里？ | 发现自己一直用今天的空间逻辑误读过去。     | 时间变化也是“组织世界的方式”变化。          |
| M4 一个地方究竟是怎样活起来的     | 自然条件、交通、生产、贸易、信仰、制度与人的日常如何共同生成聚落、街区、城市或文化空间？     | 从静态遗产转向“一个世界如何生成”。      | 地方不是建筑集合，而是人与环境长期共同作用。      |
| M5 今天到底还剩多少过去        | 眼前哪些是原物、重建、延续的名称、空间关系、生活习惯、记忆或后来的文化重塑？           | 天然触发“真的假的”“到底留下了什么”的好奇。 | 历史延续不等于一件东西几百年没变；连续性本身值得理解。 |

# 4 为什么这些母题更接近墨痕

  - 从普通人可以产生的疑问出发，而不是从“我们有哪张表、哪类文献”出发。

  - 天然要求纵向变化、横向关系、空间组织与人的生活同时进入，而不是停在单点知识。

  - 都允许回到今天：用户最终不是记住过去，而是重新理解眼前的地方。

  - 适用于古镇，也适用于城市街区、遗址、考古现场、园林、河流、交通线、人物活动空间乃至跨文明比较。

  - 能约束 AI 的叙事方向，却不会替 AI 预设历史答案。

这些母题继承了历史研究从问题出发、放回背景、寻找证据、允许修正的方法。墨痕要进一步帮助用户完成阅读和聆听中常需自行承担的工作：把分散的年代、地点、人物和材料组织成可以理解的时空关系。

时空视觉化服务于理解历史，并进一步服务于当下生活的乐趣与意义。它可以落到一次散步的新发现、一段旅行的期待、对地方气质的理解，也可以促成更深的人文思考。

# 5 统一叙事逻辑

## 5.1 从人文问题到历史解释

研究组织逻辑：母题 → 历史问题 → 时代背景 → 人物与行动 → 时空关系 → 证据检验 → 历史解释 → 冲突与不确定性 → 延续与变化 → 当下连接。

这是一组需要相互校验的环节，不是必须单向执行的流水线。解释应说明条件与行动如何发生作用，不能把同时出现或空间相邻直接当作因果关系。

## 5.2 从历史解释到用户体验

用户体验逻辑：看见当下 → 产生疑问 → 进入过去 → 看见关系与变化 → 按需查看证据 → 修正最初理解 → 回到今天 → 继续观察、追问或行动。

这条逻辑比旧的“五幕页面骨架”更上位。未来可以是三幕、五幕、十分钟、Citywalk、地图探索或对话；表现形式可以变化，但用户的认知运动应尽量保留：先看见 → 产生疑问 → 过去介入 → 理解发生变化 → 回到今天。

需要特别强调：这不是要求每个五分钟故事把所有环节都讲全。相反，前台体验仍然应该轻、清楚、有悬念。完整解释链主要存在于墨痕背后的研究与组织逻辑中，用户只在需要时逐层深入。

## 5.3 让视觉承担解释

墨痕将历史解释中隐含的时间、空间、关系和证据结构转化为可探索的体验。地图、时间轴、图像与文字需要共同回答一个问题，让用户看到某个关系如何成立、变化以及留下痕迹。

| **传统历史表达擅长** | **墨痕应增加的表达能力**                     |
| ------------ | ---------------------------------- |
| 时代背景与因果解释    | 把背景落实到可感知的时间层、空间范围与关系变化            |
| 人物与事件叙述      | 把人物行动放回真实地点、路径、同时代关系与环境            |
| 典籍/论文引用与脚注   | 让 Evidence 可按需出现，并与地图、时间、对象和判断直接对应 |
| 考古/遗址/器物佐证   | 让“文献中的过去”与“今天仍能看见的痕迹”发生对照          |
| 章节式线性论述      | 允许用户沿地点、时间、人物、关系和证据继续追问，而不是只能顺序阅读  |

# 6 Agent 如何开展定向研究

| **步骤**               | **Agent 应做什么**                 | **禁止什么**             |
| -------------------- | ------------------------------ | -------------------- |
| ① 观察当下               | 寻找普通人可感知的反常、重复、断裂、遗存、空间错位或生活痕迹 | 直接从数据库挑一条“最丰富”的记录开始讲 |
| ② 匹配母题               | 判断 M1–M5 哪个最能把现象变成值得追问的问题      | 每个地方强行套完五个母题         |
| ③ 生成研究问题             | 把母题具体化成可被史料检验的问题               | 把问题写成已经成立的结论         |
| ④ 定向检索               | 围绕人物、地点、时间、关系、生活、制度、空间、图像寻找资料  | 只因为资料容易获得就改变故事方向     |
| ⑤ Evidence 检验        | 判断哪些关系成立、哪些只有可能、哪些被证伪或存在冲突     | 挑支持预设故事的材料，忽略反证      |
| ⑥ 形成 Story Candidate | 选择真正有认知变化潜力的一条发现链              | 把资料多等同于故事好           |
| ⑦ 回到今天               | 寻找“这段过去如何改变今天的观看/行走/理解”        | 用空泛的“珍惜文化遗产”收尾       |

## 6.1 研究需要同时关注的四类内容

  - Context｜当时的时代、自然环境、交通、制度、经济、社会与文化背景；

  - Actors & Actions｜人物、群体、事件与具体行动；

  - Material Traces｜考古发现、遗址、建筑、器物、地图、图像、典籍与其他可定位材料；

  - Continuity & Change｜这些条件、关系和物质痕迹后来如何变化、消失、重建或延续到今天。

定向检索既包括典籍、考古报告等材料，也包括已有书籍、论文和专题研究。引用研究成果时，应区分材料中的记载、研究者的解释与墨痕的归纳；无法直接核验原始材料时，明确标注转引。

## 6.2 将来源追溯纳入关键判断

历史书籍、论文和通史常在章节末尾或脚注中列出参考来源。墨痕应继承这种学术诚实，但不照搬论文的阅读负担。典籍、方志、考古报告、遗址、历史地图、图像、器物、现代现场和研究成果都可以成为不同性质的佐证。

  - 主体验中：Evidence on Demand，不让出处压倒故事；

  - 关键判断处：用户能立即知道“凭什么这样说”；

  - 存在冲突处：呈现不同材料，而不是让 AI 假装存在唯一答案；

  - 深入模式中：能够追溯完整 provenance、原文位置、图像/遗址/地图及研究来源。

每项关键判断应对应具体来源与可核查位置，并说明支持范围、冲突和未知。现代现场能够说明今天的状态；要用它解释过去，还需核对年代、重修、迁移与延续情况。没有出处支持的关系不能通过地图连线或复原图变成确定事实。

# 7 五分钟核心故事的五个吸引力测试

| **测试**                  | **判断问题**                       |
| ----------------------- | ------------------------------ |
| 反常 / Curiosity          | 用户在知道答案以前，会不会真的觉得“咦，为什么？”      |
| 展开 / Generativity       | 一个小入口能否自然牵出多层时间、空间、人物、关系与材料？   |
| 人 / Human Life          | 能否最终回到人的生活、选择、往来、信仰、劳动、记忆或地方感？ |
| 认知变化 / Transformation   | 结尾是否让用户修正了开头对这个地方的简单理解？        |
| 今天 / Present Connection | 回到现实后，用户是否会重新看、继续问、想去走、比较或观察？  |

最重要的验收是：五分钟以后，用户是否对眼前的地方形成了新的理解，是否愿意继续看、问、走或比较。

同时检查三个基础条件：关键解释可以追溯；视觉确实帮助理解时空关系或变化；已知、推测与未知能够区分。这些是进入体验验证的条件，不替代五个吸引力测试。

# 8 重新理解金泽样稿

旧金泽样稿的重要价值仍然成立：它已经找到了“今天 → 疑问 → 过去 → Evidence → 回到今天”的正确运动方向。问题主要不在骨架，而在故事发动机。“万安桥、普济桥、颐浩寺约 620 米”更像研究者发现的空间异常，普通用户未必天然觉得反常。

因此金泽不必推翻重做，而应把旧材料重新放入 M1–M5 中审视。万安桥、普济桥、颐浩寺可以继续存在，但它们不再因为“已有 Demo 需要它们”而成为主角；只有当它们真正回答某个更强的人文问题时，才进入主故事。

下一轮还应检查：桥、寺、河、街各自出现于什么历史条件下，哪些时期存在可证实的生活联系，今天的遗存保留了什么。空间接近只能提出问题，历史背景与材料才决定能否形成解释。

| M5 今天还剩多少过去 | 今天被称为“古”的东西，各自延续的究竟是物、位置、名称、关系还是记忆？  | 修建/重修记录、历史图像、文保资料、地图对照、名称沿革、现场资料 |

五条研究线在本轮承担材料盘点与方法检验，不以选出金泽第一主母题作为预设目标。先完成 M1–M5 同深度方法卡，再盘点实际材料覆盖与缺口；依据可成立的历史问题决定后续实施切片，可使用一个母题或组合多个母题。

每条研究线记录候选问题、时期与空间范围、材料及核查位置、可支持判断、反证与缺口、可能改变的当下理解。区分已发现、可访问、已核验和可用于表达的材料；材料盘点可反向修订方法，不以资料数量决定主线。

# 10 防止 Agent 走偏的四条硬规则

一 母题可以先于资料，答案不能先于证据。将人物与事件放回当时条件，保留反证、分歧与未知。

二 材料不足时缩小问题、保留未知或换母题。不能为凑齐解释链、五分钟故事或视觉效果补造关系。

三 资料多少与画面丰富程度都不能替代解释质量。优先呈现能改变理解的关系与变化，关键判断必须有可追溯来源。

四 故事最终要回到今天的生活。重新看见、理解、散步、旅行、比较与审美的乐趣，都可以成为有效落点。

# 11 从金泽走向墨痕的可复用叙事能力

M1–M5 是第一版 Narrative Motif Library 的核心，应先共同完成方法深化，再在具体场景中检验与选择。通用方法说明值得怎样问、解释怎样形成、UI 与数据需要支持什么；具体地点的答案服从材料。不得把方法库研究缩减为金泽主母题筛选。

母题库应该允许长期增长。例如未来可能出现“一个名字为什么活了这么久”“一个地方如何被不同群体反复解释”“一件普通器物如何连接远方世界”等新母题。但新增母题必须来自真实内容实践，而不是为了让分类看起来完整。

母题库的第一层回答什么值得问，第二层组织背景、人物行动、时空关系与证据，第三层将成立的解释转化为体验。五个母题先形成同深度的方法卡；金泽材料盘点用于检验可用性并决定首个实施切片，随后逐步验证跨地点复用。

## 11.1 下一步需要沉淀的内容

母题研究记录：记录适用现象、具体问题、检索方向和证据要求；不预写统一结论。

解释与证据记录：将关键判断与时代背景、对象、时间、地点、来源位置、支持范围及不确定性对应起来。

体验脚本：把每个叙事节点的用户疑问、解释内容、视觉变化、按需证据及后续追问写清楚。视觉形式依据解释需要选择。

先以可审阅的轻量记录落实方法、材料与表达的映射，不在本阶段扩展为完整数据库或复杂自动化系统。方法用于指导数据生产，实际材料也用于修订方法；通过真实切片后再固化为 Agent 的研究、组织与引导能力。

# 12 墨痕下一阶段的开发顺序与验收

下一阶段分为通用方法与场景验证两层。先完成五母题的方法深化，同时准备金泽五母题材料盘点；材料与问题匹配关系清楚后，再选择首个实施切片，形成脚本、逐帧 UI 与代码任务。方法能力可以先设计，真实历史解释不能先于证据。

## 12.1 先深化五母题方法并盘点场景材料

五个母题分别明确核心问题、适用边界、认知进程、证据要求、UI 表达、数据生产、失败分支和当下连接。再按第 9 节盘点金泽材料，形成五母题覆盖矩阵、关键判断与证据、冲突和缺口。此时不预设主母题，不为覆盖方法而编造故事。

## 12.2 再完成可审阅的体验脚本

材料支持具体问题后，选择首个实施切片；可由单一或组合母题组织。编写五分钟核心体验，明确入口疑问、理解转折、当下连接和证据边界。逐节点写清看到什么、理解什么、为什么变化、依据在哪里、如何追问及返回。

## 12.3 用轻量原型验证时空表达

依据体验脚本制作可审阅的关键画面或交互原型，验证叙事、地图、时间与证据能否共同解释问题。重点观察第一次认识金泽的人是否愿意进入、能否看懂转折、是否愿意继续探索；无需在这个阶段完成全站界面。

## 12.4 将验证结果转成开发任务

通过体验验证后，将脚本与交互转成 开发总工程师 任务，写明现有功能、数据映射、用户偏好保持、具体证据与验收场景。先实施一个可验证切片控制范围，但五母题方法继续保留，并通过后续样本逐步检验。

## 12.5 本阶段完成的判断

方法阶段：五母题同深度、区别明确、能指导 UI 与数据、允许未知与反证。样本阶段：说明问题为何值得问、证据支持到哪里、视觉怎样改变理解、用户回到今天获得什么；用第 7 节五个吸引力测试验证。两阶段分别记录，不互相代替。

下一步先完成五母题通用方法深化与金泽材料盘点准备，再让实际证据决定可实施的体验切片。附录 A、B 提供本版的方法细化；其作为待实践检验的工作标准，不预设统一历史结论。

# 附录 A 五个核心母题的通用叙事方法

本附录把 M1–M5 从选题视角深化为可复用的叙事逻辑。五个母题都完成方法定义，再用真实材料检验适用性；不以选出金泽主母题作为方法研究的先决目标。这里规定问题结构、理解进程、证据条件和表达能力，不规定历史答案、固定人物或必然结局。

方法先行不意味着闭门把全部标准定死。五个母题应先达到同一深度的可审阅版本，同时允许材料盘点揭示不可检验的问题、缺失的字段和不适用的表达，反过来修订方法。之后选择实施切片，是资源与证据条件下的工程决策，不是给五个母题排序，也不取消其通用价值。

## A1 标准化的边界与共用记录

每个母题统一记录九项内容：核心追问；适用与不适用条件；入口直觉；认知进程；关键判断与证据需求；UI 表达与操作；数据生产要求；材料不足、冲突和反证分支；回到今天与验收。标准化这些关系，具体节拍数量、画面顺序、构图和前台文字按材料与用户探索调整。

共用研究记录至少包含：问题及范围、对象或群体、时间及其精度、地点及其精度、行动与关系、判断、来源及可核查位置、材料身份、支持范围、冲突或未知、与今天的连接。该记录先映射到现有数据模型；这里不新增数据库核心对象，也不要求一条材料具备所有字段。缺失应显式记录，不能让 Agent 补齐为事实。

时间需区分事件发生、材料形成、材料描绘及今日观察；空间需区分历史位置、今日位置、迁移与推测范围。证据状态使用可解释的“支持、部分支持、冲突、尚未证实、已被反证”等描述，不用无校准的数字置信度伪装精确。

## A2 M1 消失的关系世界

**核心追问：** 今天看似孤立的对象，在某一历史时期是否通过人的活动构成过一个共同生活世界？关系怎样形成、变化或中断？“消失”是待检验的问题，材料也可能表明关系仍然延续，或者这些对象从未构成设想中的整体。

**适用与边界：** 适合若干遗存、人物、器物、机构或地点之间存在可检验联系的情形。仅有空间邻近、相似名称或同时出现，不足以启动确定关系的揭示。与 M2 的区别在于，本母题首先解释对象之间的联系，而非某类形态为何在整个地方反复出现。

**建议认知进程：** 先看见今天的碎片并提出联系假设；进入一个有材料支撑的历史时段；跟随某类人的一次活动，看到对象如何彼此作用；比较关系变化或断裂的条件；回到今天重新辨认哪些联系留下痕迹。每一步都可停留、追问或被新材料修正。

**画面与操作：** 入口用单景或并置保留碎片感；进入过去后让人物、活动目的与相关对象共同进入关系观察。点击对象可看到它在这条关系中的作用，点击关系可在墨痕查看具体依据；关系的方向、类型和时间范围要可辨。历史路线未知时使用示意关系而非绘制精确行走线。前后关系变化可用对照或连续镜头；不为连满网络添加无证据的线。

**数据生产：** 生产关系两端、关系类型、参与群体、行动、有效时期、成立依据和变化依据；将每条关键关系绑定到来源位置。若只能证明两个对象各自存在，记录两项存在判断，不自动生产“二者联系”判断。形成关系、关系延续和关系中断分别需要材料支持。

**不足与分支：** 无法证明联系时，展示“目前能确认哪些对象，哪些关系待查”；材料冲突时对照关系成立的时间和解释；关系仍存时转向“为何今天不易看见”，不强行讲失落故事。可转入 M3 看不同群体怎样使用这些对象，或转入 M5 检查关系的当代延续。

**回到今天与验收：** 用户能解释至少一项关系由什么活动维系，以及依据到哪里为止；重新看见的应是人如何生活，而非多记住一组 POI。若只形成待查假设，作为开放探索交付，不标为完整关系解释。

## A3 M2 一个地方为什么会长成这样

**核心追问：** 一个地方的某种重复、分布、密度、朝向或组织特征，为什么形成于这里？关键不只是物件多，而是这些物件在地方整体中呈现什么结构。

**适用与边界：** 需要一个可描述、可核查的整体或局部结构，以及适当的观察范围。仅选取几个方便展示的对象，不能推出地方特征；只解释单个桥头或街口，也尚未回答整个地方为何这样。与 M4 的区别在于，M2 从当下或某时段的结构反推解释，M4 从过程追踪生成。

**建议认知进程：** 从一个可感知细节进入；拉回整体，确认它是否为重复或有组织的现象；提出多种可能条件并寻找反例；把条件与人的行为、制度或环境放回相应时期；返回整体检验解释能否说明分布与差异；回看眼前细节为何属于这一结构。

**画面与操作：** 必须有一次局部与整体的关联变化，可使用单景聚焦与全局分布、局部对照或关系观察。对象过多时不堆叠标记，按当前问题显示一类特征和其范围；用户点击一个例外可以追问“为什么这里不同”。若使用跨地区比较，需要交代时期、尺度、统计口径与保存条件是否可比。五种历史空间模式按证据精度选择，不默认全局配准。

**数据生产：** 记录研究范围、对象纳入规则、分布时间、对象类型与状态、环境和制度条件、人的活动、例外与比较口径。现存数量与历史数量分开；未被记录不等于从未存在。解释需关联到可检验的作用机制，而非把水多、贸易旺盛等一般背景直接当作答案。

**不足与分支：** 无整体资料时把结论收窄为局部观察；无法建立可比条件时取消密度排名，保留并置阅读；反例不能被隐藏，应使用户理解解释的适用范围。可转 M4 追踪结构怎样形成，或转 M1 查看具体活动网络。

**回到今天与验收：** 用户能把入口细节放回整体，说明至少一个条件通过什么行动影响了形态，并指出该解释未覆盖的现象。画面应让局部与整体之间的关系可见，不能只在旁白里宣称“看懂地方”。

## A4 M3 过去的人生活在怎样的一张地图里

**核心追问：** 某个时期、某类人为了谋生、往来、信仰、治理或日常生活，怎样组织自己的空间？这里的“地图”既可能是历史原图，也可能是由目的、路径、障碍、节点与关系构成的生活空间。

**适用与边界：** 必须明确时期、群体与活动目的；“过去的人”不能被当成拥有同一种空间经验的整体。不能用今日最短路反推历史行程，也不能把精英留下的舆图当作所有人的共同认知。与 M1 相比，本母题突出行动者的空间逻辑，而不是关系是否存在。

**建议认知进程：** 先暴露今日观看方式；引入一个有材料依据的群体与活动目的；按当时可达性、节点重要性和障碍重组空间；比较另一个群体、时段或今日组织方式；回到今天识别自己曾经忽略的方向、边界或生活联系。

**画面与操作：** 原图细读可用于理解其表达逻辑；关系观察突出目的和节点，连续镜头可跟随有据可查的活动过程。用户切换群体或问题时，变化的是焦点、关系和材料，不改变墨痕分区或悬浮选择。无法定位的路径用明确的示意顺序呈现，不投射为可导航路线。历史地图的方向与比例限制需随材料出现。

**数据生产：** 记录群体身份与其代表范围、活动目的、出发地与目的地、交通方式、可达条件、时间或成本记载、障碍、节点角色及来源。实际记载、研究者归纳和体验性示意必须分开；没有真实人物传记时，可讨论有证据的群体活动，不虚构一个人物的第一人称经历。

**不足与分支：** 无具体行程时展示“哪些节点重要、为何重要”，避免补绘路径；同一时期不同群体的空间经验有差异时保留并列解释；材料只反映某阶层时限定代表性。可转 M1 研究活动联系，转 M5 看空间习惯的延续。

**回到今天与验收：** 用户能说明至少一种“在当时对这些人重要、而在今日地图上不显眼”的关系，并知道其证据边界。成效是改变观看空间的方法，不要求生成一条旅行路线。

## A5 M4 一个地方究竟是怎样活起来的

**核心追问：** 在什么条件下，哪些人的行动、事件、制度或环境变化，使一个地方逐步形成、扩展、转向、衰退或再生？过程允许中断和多路径，不预设一直繁荣。

**适用与边界：** 需要至少能辨认若干先后状态，以及用于解释变化的材料。时间先后只能建立顺序，不能自动建立因果；自然条件提供可能性，也不等于必然生成某种地方。与 M2 相比，重点是变化机制与过程，而非最终形态。

**建议认知进程：** 从今天的状态提出“如何成为这样”；回到有材料的早期条件；识别一个关键变化及参与行动；观察条件、行动与结果如何相互作用，并检查其他解释；看到后续路径或中断；回到今天理解现状是历史过程中的一个阶段。

**画面与操作：** 连续镜头适合有顺序的状态变化，对照适合揭示节点前后差异，关系观察适合解释作用机制。时间作为画面内容标明阶段、范围和未知区间；不要靠均匀动画暗示历史均匀发生。过程箭头需区分“先后”与“有依据的影响”；用户可点击关键变化在墨痕查看依据与其他解释。

**数据生产：** 记录阶段状态、事件及时间精度、参与群体、行动、环境或制度条件、变化结果、机制判断与竞争解释。把“材料直接记载发生了什么”和“研究解释为何发生”分开；保留来源对年代、先后或影响因素的分歧。任何动画补间都不能被登记成新的历史状态。

**不足与分支：** 只有几张时点材料时做“已知阶段比较”，不补造中间过程；机制证据不足时保留多种假设；反证出现时可撤回某条因果解释。可转 M2 看结果如何形成整体结构，转 M1 看变化影响了什么关系。

**回到今天与验收：** 用户能区分条件、行动与结果，说明哪个转折改变了地方以及为什么如此判断；也能说出仍不确定的环节。若只完成年代排列，不标为形成机制已解释。

## A6 M5 今天到底还剩多少过去

**核心追问：** 今天看到、使用、称呼或记忆的对象，究竟延续了过去的什么？连续性可以发生在物质、位置、名称、功能、关系、实践或记忆等不同层面，不用一个“真／假”标签包办。

**适用与边界：** 适合原物、重修、迁建、复建、名称沿用、实践延续与后期文化重塑存在区分需要的情形。历史上的建筑重建是研究对象；UI 的解释性几何重建是表达方式，二者必须区分。新建筑不意味着没有历史联系，古老材料也不自动证明所有叙事都古老。

**建议认知进程：** 从“这是不是过去留下的”进入；把对象拆成可以分别追溯的连续性层面；核对各层的年代、变化和依据；并置冲突或不同保存方式，修正最初简单判断；回到今天理解哪些值得看、怎样看，以及当代使用如何参与其意义。

**画面与操作：** 单景选取当前对象，原件细读核对来源，对照表现有可比依据的古今状态，时间内容标记修建、迁移、重修或命名节点。点击对象的某个层面，可在墨痕查看对应判断；不能用一张通用来源卡替代。没有同视角条件时保持并置，不用擦拭叠加制造精确连续。

**数据生产：** 按连续性层面分别记录对象身份、建造或重修事件、迁移、材料更换、名称沿革、功能与实践变化、记忆的讲述者与形成时期。区分历史记载、文保认定、现代现场与口述记忆各能支持的判断；口述可证明某种记忆被讲述，不必然证明记忆所指事件发生。

**不足与分支：** 无法辨认原物比例时不输出伪精确百分比；记录“无法确认哪些部分”；材料相互冲突时展示分歧怎样影响判断。可转 M1 查关系延续，转 M3 看生活实践怎样保留或改变。

**回到今天与验收：** 用户能说出至少两种不同的延续或变化，避免把“全部原物”当成唯一价值，也避免以文化意义掩盖事实不明。落点可以是更细致的观看、对修复与使用的理解，或一个值得继续查证的问题。

# 附录 B 方法怎样指导 UI 与数据生产

## B1 五母题与表达能力的对应

| **母题**  | **必须能表达的理解变化**    | **数据生产的重点**         |
| ------- | ----------------- | ------------------- |
| M1 关系世界 | 碎片怎样通过活动相连及变化     | 关系类型、行动、有效时期、关系证据   |
| M2 地方结构 | 局部与整体、规律与例外       | 范围、分布、口径、条件、机制与反例   |
| M3 生活地图 | 不同人的目的怎样改变空间重要性   | 群体、活动、可达性、节点角色与代表范围 |
| M4 生成过程 | 条件与行动怎样产生变化       | 阶段、事件、时间精度、机制与竞争解释  |
| M5 连续性  | 物、位置、名称、实践等怎样分别延续 | 身份沿革、变化事件、连续性层面及来源  |

五种舞台构图是视觉组织方法，五种历史空间模式是证据与几何条件下的空间表达方法，五个母题是组织人文问题与理解进程的方法。三者是多对多关系，不能按数量相同而一一绑定。一条母题可使用多种构图；不涉及地图时也能通过器物、原件、图像或比较开展叙事。

## B2 双组件中的共同能力

视觉舞台承担对象、材料、时间、关系、比较和变化的呈现；墨痕承担问题、简洁引导、具体依据、分支选择与追问。辅助操作按需出现，不能把墨痕堆成工具面板。舞台对象可以直接点击，但应提供可感知的可操作状态和可访问的替代操作，不能只有无法发现的隐藏热点。

用户选择的显隐、分区或悬浮、尺寸属于体验容器偏好；母题切换、认知节拍推进、追问和回退不能覆盖这些选择。Agent 在其内改变焦点、镜头、构图与叙事。减少动态效果模式下，关键状态和认知变化仍应可辨认。

每个逐帧施工记录写明：当前问题、用户可能的原理解、这一帧增加什么认识、舞台焦点与材料、时间和空间范围、视觉操作、墨痕引导、关键判断对应的依据、下一步与分支返回、材料不足时的表达。认知节拍与画面帧分开编号或建立对应，不规定一个节拍只能有一帧。

## B3 数据生产的优先次序

先由五个母题定义“为回答这类问题通常需要什么”；再盘点实际材料“目前能支持什么”；据此形成采集、核验、结构化与补缺清单。清单允许记录预计不存在或难以取得的材料；不把缺口全部变成必须补齐的任务，更不反向要求史料支持既定剧情。

先整理来源身份和可用性，再提取原文、时间、地点和对象，随后形成可核查的判断及关系，最后产出可被 UI 使用的素材与解释。原始材料、研究解释与墨痕归纳分别保留。优先使用已有模型表达这些记录，只有真实样本证明现有模型无法承载时再做架构协调。

跨母题共用同一材料与判断时保留统一身份和来源，不复制成五份互相矛盾的数据。来源内容或判断改变后，所有引用它的叙事节点都应能被识别并复核；本阶段先用可审阅的映射记录落实这一要求。

## B4 金泽研究准备的交付范围

金泽在这一阶段承担材料盘点与方法检验场景。围绕五个母题建立同深度的盘点记录：候选问题、现有材料与来源位置、时间和空间覆盖、可读性与使用条件、目前能支持的判断、反证与缺口、下一步查什么。此处不预先选定主母题，也不把“桥多”或既有三个遗存固定为最终故事中心。

盘点后可以出现三种结果：某一母题适合独立切片；多个母题适合围绕同一真实问题组合；暂时没有足够材料支持完整历史解释。第三种结果可以继续研究或制作明确标为方法示意的画面，但不能登记为历史故事已验证。最终选择首个实施切片时，比较证据支持、普通人的兴趣、理解变化、当下连接与实现成本，而非材料数量排名。

## B5 母题的组合与扩展

组合应跟随用户问题。例如先用 M2 识别地方结构，再以 M4 追问形成过程，最后用 M5 检查今日延续；这只是可用路径，不是通用必经顺序。每次转换说明新问题从何而来，保留已探索判断、证据和返回入口，避免五个栏目轮番播放。

新增母题需说明它带来的独特追问和认知变化、现有母题为何不能充分覆盖、需要哪些证据、UI 是否能承载，以及材料不足时如何停止。先作为候选记录，在有真实材料的样本中验证后再纳入方法库。仅换地名、对象或修辞，不构成新母题。

## B6 本轮验收与后续验证

本轮方法稿的验收：五个母题均具备完整方法卡；其间差异可说明；UI 能力与数据要求可追溯到人文问题；未知、冲突和反证有明确处理；可以跨地点使用而不预设答案。

后续样本验证分别记录：方法是否可用、材料是否支持、UI 是否表达清楚、用户是否发生理解变化。方法文档完成，不等于历史内容已成立；原型可点击，不等于真实 Agent 已完成研究、判断或动态编排。五个吸引力测试和 C4 Human Experience Gate 继续用于真实体验验收。
