# 02_读懂提纲（D02 读前设计 · 含抽样试读）

> **性质**：D02 载体适配器读前设计，供项目拥有者确认"读懂标准"。含对真实材料的抽样试读，展示「读懂」与「通用切块」的差异。未执行任何数据生产。
> **依据**：宽进与广联 §5.1–§5.6（T01/T02/T03/T05/T06/T08）、§6 Observation Contract、§7 质量闸 W1–W7。

---

## 通用 Observation 三件套（每条必带）
`source_id + locator`（页/段/图号/区域可回溯）· `modality` · `raw_excerpt_or_region` · `normalized_observation` · `mentions` · `actions_events` · `time_scope/place_scope` · `relation_signals` · `qualifiers` · `extraction_method + uncertainty` · `association_readiness`（禁 `usable/published/verified`）。

> **与现状的差异**：现有 `research-pipeline.mjs` 的 `d02Observations` 只做 `extractText→excerpt` 的通用切块，且 `modality` 仅 `text`/`map_image` 二分。下方每类都要求**载体专属字段**，这是"读懂"与"切块"的根本区别。

---

## T01 方志 / 地方文献（重点：条目级，不是书名）

**读懂要回答**：版本/卷目结构？相关门类（建置沿革·桥梁水利·人物·寺观·风俗·物产·艺文·灾异）下各有什么条目？条目里的人/地/机构/活动/时间/对象用途/变化词？

**预期 Observation 字段**：
```
TextObservation {
  source_id, locator: "gj_*_entries.json#<卷>.<条目>",
  modality: text, normalized_observation: "条目讲的是什么",
  mentions: [人物/地点/机构], actions_events: [建/修/迁/毁…],
  time_scope, place_scope, relation_signals: [显式谓词/共现],
  qualifiers: [传闻/约略], uncertainty, association_readiness: ready/limited
}
```

**抽样试读（真实材料 `gj_fangzhi.json`）**：
- 现状态：`gj_fangzhi.json` 是 catalog_only（书目+注记）。可读片段：`workInfo.hasAnnotation[].hasBody = "《青浦县志》四十卷。（王昶撰。）"`
- **读懂应产出**：
  ```
  { source_id: gj_fangzhi.json, locator: "$.[1].workInfo.hasAnnotation[0].hasBody",
    modality: text, normalized_observation: "青浦县志，四十卷，王昶撰",
    mentions: [{青浦县志, place/work}, {王昶, person}],
    actions_events: [{action: 撰, actor: 王昶, object: 青浦县志}],
    association_readiness: limited, note: "来自注记片段，非条目正文" }
  ```
- ⚠️ **真正条目级读懂须转向 `gj_*_entries.json` / `mgts_*_entries.json` / `gj_*_ocr.json`**：例如 `mgts_4581_entries.json` 的扫描本条目应切到"卷目+条目"，抽人物/地点/活动/变化词；OCR 质量差则标 `uncertainty` 并降级。

## T02 古籍 / 诗文 / 笔记（重点：作者—地点—活动—感知，且"待核"须显式）

**读懂要回答**：谁在何时何地、因何写、写到什么对象/景观/活动/情感？与方志条目能否互证？

**预期 Observation**：`TextObservation` + 作者/时代/作品语境 + `qualifiers: 创作性/抒情性`。

**抽样试读（真实材料 `souyun_poems_by_place.json`）**：
- 材料明示：`path: "B · 镇名入诗（三重过滤后仍为『待核』，不得当确证展示）"`；`corroborate.金泽 = [松江,青浦,淀湖,淀山,华亭,三泖,泖,吴中,颐浩,苏州]`。
- **读懂应产出（且必须标 Lead/待核）**：
  ```
  { source_id: souyun_poems_by_place.json, locator: "$.corroborate.金泽",
    modality: text, normalized_observation: "金泽入诗的地名互证候选：松江/青浦/淀湖/…",
    mentions: [金泽, 松江, 青浦, 淀山, 颐浩…],
    qualifiers: [待核, 非确证], association_readiness: limited,
    note: "镇名入诗候选，须另源佐证方可进 Evidence" }
  ```
- ⚠️ 现有做法若把 `corroborate` 当"已证地点关系"会直接违反宽进 §15（near/same_period 仅弱信号）与材料自述"不得当确证"。

## T03 档案 / 契约 / 族谱 / 碑刻（重点：优先抽"动作"而非实体）

**读懂要回答**：发生了什么动作/交易/制度约束？actor/object/from/to/time/quantity/role？

**预期 Observation**：`ActionObservation` / `TransactionObservation` / `InstitutionObservation` / `ChangeObservation` / `GenealogyObservation`（保留 action/event 结构）。

**抽样试读（真实材料 `clans.json`）**：
- 可读正文：`families[].works[].description = "始遷祖順一、松鶴兄弟，明洪武三十一年自温州府城（今鹿城區）墨池坊遷居樂清縣石塘村（今虹橋鎮七村村）。譜載序、跋、行第、世系圖。"`
- **读懂应产出**：
  ```
  GenealogyObservation {
    source_id: clans.json, locator: "$.families[赵].works[0].description",
    actor: [順一, 松鶴], kinship: 兄弟, action: 遷居,
    from: 温州府城墨池坊, to: 樂清縣石塘村, time: 明洪武三十一年,
    source_scope: 趙氏宗譜, association_readiness: ready }
  ActionObservation {
    actor: 順一/松鶴, action: 遷, object: 宗族, from: 温州, to: 樂清,
    time: 明洪武三十一年 }  // 动作链入口，可接 M1/M4
  ```
- 价值：这是"人物网络 + 迁徙 + 制度（宗譜世系）"的高密度源；`clans.json` 是库内最该优先读懂的结构化文本之一。

## T06 古代舆图（重点：必须"读图"，catalog 不是读懂）

**读懂要回答（图面语义）**：题名/编绘者/年代/图幅/地图类型/绘制目的？方向/比例/图例/符号/文字标签/边界/道路·水系·桥·聚落·寺观？
**拓扑观察**：谁在谁旁/跨越/上下游/围合/节点？区分"图上可见"与"现实推断"。
**几何资格**：能否 registration/anchor，理由？证据不足**禁止全图 GIS 配准**。

**预期 Observation**：`MapLabelObservation` + `MapFeatureObservation` + `MapTopologyObservation` + `MapAnnotationObservation`。

**抽样试读（真实材料 `yutu_catalog.json` + `yutu_probe/`）**：
- catalog 层（`yutu_catalog.json` item）：`title="[川沙南汇奉贤奉教图]", year=1840, dimensions="95×66cm", edition="绘本", note=["图名自拟","彩色"]`。
  - **catalog 只能产出**：`MapLabelObservation`（题名/年代/尺寸/版本/图名自拟说明），`association_readiness: catalog_only`——**不能宣称已读图**。
- **真正读图对象 = `yutu_probe/` 本地 142 PDF + 45 PNG**（如参谋本部测绘/石印/日绘等）。需视觉读取：图面符号、聚落/桥/水系拓扑、绘制目的。
  - 例（设计态，待视觉模型）：`MapTopologyObservation { source: yutu_probe/xxx.png, observed: "朱家角镇居淀山湖东南、市河十字交汇、放生桥跨市河", topology: [镇⊂淀山湖东南, 桥 crosses 市河], qualifiers: [图上可见] }`

> ⚠️ **关键能力缺口**：当前 D02 体 `modality` 只到 `map_image`，且实际是从 JSON 抽文字，**没有图面/拓扑读取**。要"读懂舆图"，必须新增视觉读取层（或先仅做 catalog Lead，明示未读图）。

## T08 历史照片 / 明信片 / 影像（重点：进关联池前须有内容级 Visual Observation）

**读懂要回答**：来源/摄影者/时间/描绘时期/权利？画面可辨对象（人/建筑/桥/河/街巷/器物/标识）？人在做什么、对象如何被使用、谁与谁同框、空间如何组织？拍摄/观看方向、前后景、岸桥街关系？图中招牌/题记/碑铭？"图中确实可见" vs "据标题/说明得知" 分开；创作性 vs 纪实分开；叙事资格？

**预期 Observation**：`VisualObservation`（画面对象 + 活动 + 空间视角 + 图中文字 + 证据身份 + 叙事资格）。

**抽样试读（真实材料 `commons_images.json`）**：
- 目录层：`title="File:1 zhujiajiao 2023 aerial.jpg", towns=[朱家角], license=CC BY-SA 4.0, artist=Chensiyuan, date=2023-11-03, description="zhujiajiao 2023 aerial"`。
- **目录只能产出（catalog 级 VisualObservation）**：
  ```
  { source_id: commons_images.json, locator: "$.images[0]",
    modality: image, identity: {来源: Wikimedia, 作者: Chensiyuan, 时间: 2023-11-03, 权利: CC BY-SA 4.0},
    place_scope: 朱家角, evidence_identity: "据标题/说明得知（非画面自读）",
    association_readiness: catalog_only,
    note: "图像字节在外部 URL；真正读画面需取图字节，当前未做" }
  ```
- ⚠️ 宽进 §5.3 视觉 Gate：100% 进关联池的图必须有内容级 Visual Observation；**当前仅目录元数据，不构成"已读图"**。commons 系列图像字节在外部 URL，需取图或先标 Asset Pending。

## 下游如何支撑叙事转化（D03→D05→M1–M5，衔接设计）

| 载体读懂后 | D03 Mention | D04 信号(A01–A12) | D05 母题透镜 |
|---|---|---|---|
| T01 方志条目 | 人物/地点/机构/活动 | A01 显式谓词、A03 时间序列、A04 空间拓扑 | **M2**（地方为何长这样）、**M4**（地方如何活起来） |
| T03 族谱迁徙 | 宗族/人物/地名 | A05 行动链、A06 制度作用、A09 变化链 | **M1**（消失的关系）、**M4** |
| T02 诗文（待核 Lead） | 作者/地点/意象 | A02 跨源共现（须另源佐证）、A10 冲突 | **M1**、**M3** |
| T06 舆图（读图后） | 图面要素/拓扑 | A04 空间拓扑、A07 跨模态共指（方志↔图↔照片） | **M3**（过去的地图）、**M5**（今天还剩多少） |
| T08 图片（读画面后） | 画面对象/活动 | A07 跨模态（图↔今日现场）、A12 古今对齐 | **M5**、**M3** |

**交付形态（对齐你 2026-10-05 偏好 · 内容看板）**：按资料类别展示「原始资料 → AI 读出原文/图面 → 发现人物/地点/事件/关系 → 可支撑的故事」，不堆 DB schema。

**出口纪律**：仅 Selected Discovery 进 `review_queue`；AssociationCandidate **0 自动晋级** Runtime Truth（G-LINK-10）。
