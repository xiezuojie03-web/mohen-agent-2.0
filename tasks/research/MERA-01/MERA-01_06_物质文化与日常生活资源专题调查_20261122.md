# MERA-01｜第06类物质文化与日常生活资源专题调查

**核查日期：** 2026-11-22  
**资源类别：** 06｜物质文化与日常生活  
**依据：** MERA-01 V1.1 唯一任务书及 2026-11-22 Owner 恢复执行指令  
**归档性质：** 既有专项的专题研究增量，不是新任务书，不建立平行资源主库

---

## 1. 本轮研究判断

第06类不能只理解为“博物馆藏品图像”。墨痕需要的是能帮助解释普通人如何穿衣、饮食、居住、生产、交易、出行、娱乐和组织家庭生活的历史材料。

因此本轮将资源分成两种互补层次：

1. **物质对象层：** 服装、家具、陶瓷、器具、纺织品、乐器、工具、装饰艺术等实物及其对象级元数据。
2. **日常生活记录层：** 照片、菜单、地图、手稿、广告、视频、声音、个人记录、家庭/商业/行业材料等能够呈现实际生活场景的历史记录。

本轮已完成第一批官方机构调查，建立 4 项资源记录候选（含 1 项对象级样本），但第06类尚不应最终准出：博物馆对象资源已经较强，饮食、家庭、劳动、消费、民俗、地方生活等一手记录还需要继续补齐。

## 2. 重点资源调查

### 2.1 The Metropolitan Museum of Art（The Met）Open Access / Collection API

**官方入口：** https://www.metmuseum.org/hubs/open-access  
**API 文档：** https://metmuseum.github.io/  
**对象级样本：** https://www.metmuseum.org/art/collection/search/103551

#### 资源实际提供什么

- The Met 覆盖全球艺术与物质文化五千余年。
- 官方当前 Open Access 页面称有超过 492,000 件公有领域作品图像可免费、无限制使用。
- API 提供 JSON 对象数据，包括 Object Name、Culture、Period、Dynasty、Medium、Dimensions、Country、Geography、Creator、Tags、Rights and Reproduction、对象链接、图像链接等。
- 资源范围可用于服饰、纺织、家具、陶瓷、乐器、日用品、器物、艺术品等研究。
- 官方页面另称有 100 多件 3D 模型可探索；这是增量形式，不应当作全库三维覆盖。

#### 访问路径与技术条件

- REST JSON API，无需注册或 API Key。
- 官方建议请求频率不超过每秒 80 次。
- 对象列表、对象详情、部门列表、搜索等端点可用于检索和结构化整理。
- 2026-09-04 官方 API 更新新增 `/public/collection/v1.1/search` 分页搜索端点。
- 旧 `/public/collection/v1/search` 计划于 2026-10-01 退役。当前日期已过该日期，后续利用必须以 v1.1 或官方 Objects/Open Access 数据集路径为准，不能继续把旧端点写为当前有效方法。

#### 开放与权利判断

- The Met 将开放项目中的对象数据集按 CC0 提供。
- 图像只对符合 Open Access/公有领域条件的对象提供；对象 API 中也有 `isPublicDomain`、`primaryImage` 等字段。
- 数据集包含部分仍受版权限制对象的基本元数据，不代表这些对象的图像也开放。
- CC0 不消除第三方隐私、肖像、商标等其他权利。

#### 对象级样本

- 题名：`Dress`
- 年代：1840—1849
- 文化：American
- 材质：cotton
- 对象号：1980.246.1
- 部门：The Costume Institute
- 对象页标记 Public Domain。

该对象可支撑服饰史、纺织材料、身体与社会身份、19 世纪日常生活等叙事。对象页与 API 字段能将实物、材质、年代、文化和图像联系起来。

#### 墨痕推荐利用

- 将 The Met 作为全球物质文化对象的高优先级入口。
- 研究服饰、家具、陶瓷、器具、乐器等主题时，优先用对象类别、材质、地域和年代组合检索。
- 以对象元数据和图像的 OA 状态分别登记；只有明确 OA 的图像才按 CC0 路径使用。
- 适合建立“器物—材料—制作地—使用文化—年代—人物/社会生活”的关联。

**优先级：高。** 开放程度、机器可读性、对象元数据字段和图像利用条件较好；需使用当前 API 版本。

### 2.2 Rijksmuseum Collection Online / Data Services

**官方入口：** https://data.rijksmuseum.nl/  
**数据服务文档：** https://data.rijksmuseum.nl/docs/  
**数据政策：** https://data.rijksmuseum.nl/policy/  
**技术与数据架构：** https://data.rijksmuseum.nl/about/

#### 资源实际提供什么

- 官方 Data Services 说明称超过 800,000 件馆藏对象元数据可供再利用，多数对象附有高分辨率图像。
- Collection Online 网站提供超过 100 万件对象及艺术品、书籍等资源的访问。
- 对象类型从绘画到模型船、家具、服饰、工艺品、器物等。
- 数据服务包括对象 Search API、OAI-PMH、LDES、PID Resolver、完整馆藏下载、控制词表。
- 数据以 Linked Art、Europeana Data Model 等结构组织；馆方强调 FAIR、标准化、跨馆连接与语义整合。
- 图书馆书目另有 SRU 服务；Search API 明确不提供图书馆和档案记录，不能把博物馆对象接口范围外推到整个机构。

#### 访问路径与技术条件

- Search API 无需 API Key。
- OAI-PMH 无需 API Key，可使用 Identify、ListMetadataFormats、ListSets、ListRecords、GetRecord、ListIdentifiers 等动词。
- 另有 LDES、PID Resolver、完整数据下载及控制词表下载。
- 数据服务可按对象标识解析不同格式的记录；适合按研究主题定向查询，而非默认全量获取。

#### 开放与权利判断

- 许多对象信息和图像以 Public Domain 或 CC0 发布，可用于商业和非商业用途。
- 部分材料采用 CC BY 4.0，需要署名。
- 另有仍受版权或协议限制的对象，必须依据单件页面的版权声明。
- 博物馆建议在适当情况下署名馆方及相关工作人员。
- 馆方也强调敏感和机密信息保护，不能把“开放数据”理解为没有治理边界。

#### 墨痕推荐利用

- 适合作为跨地域物质文化比较资源，尤其是器物、服饰、家具、工艺、贸易与收藏史。
- Linked Art、EDM、PID 和控制词表能为跨馆对象关联提供基础。
- 研究某类器物时，优先检索对象元数据和权利字段，再决定是否使用高清图像。
- 对未数字化对象或未公开的研究数据，保留馆方访问/申请路径，不以接口不可见判定资源无价值。

**优先级：高。** 资源规模、元数据结构和开放路径均有价值；对象级许可分层必须保留。

### 2.3 Victoria and Albert Museum（V&A）Explore the Collections / Collections API / IIIF

**馆藏入口：** https://www.vam.ac.uk/info/explore-the-collections/  
**API 文档：** https://developers.vam.ac.uk/  
**Collections API：** https://developers.vam.ac.uk/collections/  
**IIIF 图像服务：** https://developers.vam.ac.uk/images/  
**使用条款：** https://www.vam.ac.uk/info/va-websites-terms-conditions

#### 资源实际提供什么

- 官方说明超过 100 万条对象记录和超过 50 万张图像。
- 强项包括设计史、服饰、纺织、家具、陶瓷、装饰艺术、摄影和日常用品。
- 对象页将目录记录、馆方策展知识和编辑性叙述汇集在一起。
- 馆藏数据库持续丰富，新增文本和图像按日/按月更新。

#### 访问路径与技术条件

- Collections API v2 支持对象搜索、过滤、聚类、受控词检索及单件对象读取。
- IIIF Image API 可按图像 ID 请求尺寸、裁切、旋转和 JPEG 格式。
- IIIF Presentation API 为同一对象的多张高清图像提供 Manifest，可在 Mirador、Universal Viewer 等阅读器中使用。
- 当前 API 文档未要求 API Key，但 V&A 保留未来要求 Key 或其他认证的权利。
- 对象页高清图像通常最长边不超过 2500 像素，打印品质约 A5/300dpi；更大尺寸需联系授权部门。

#### 开放与权利判断

- V&A API 条款默认允许非商业个人与教育用途；商业 API 用途需联系 V&A Images。
- Explore the Collections 网站对非商业使用有明确限制：数字图像最长边 768 像素、印刷不超过 A5、使用内容不超过项目总内容的 25%，并需署名；封面、首页、展览展示等另按商业条件处理。
- 商业网站、广播、出版物超出非商业范围、广告、营销、商业产品等通常需要申请许可并付费。
- V&A 及第三方可能拥有内容版权；第三方权利由使用者自行取得。

#### 墨痕推荐利用

- 适合研究服饰、纺织、家具、陶瓷、设计、工业与日常物质文化。
- IIIF Manifest 适合对同一器物的多视图、细节和图像组进行研究展示。
- 若墨痕作品具有商业属性，V&A 不应作为默认可自由复制的图像来源；应优先链接引用，或提前取得授权/报价。

**优先级：高（研究与发现）；商业图像再利用优先级中低。** 资源丰富、IIIF 成熟，但商业授权成本需提前考虑。

### 2.4 New York Public Library（NYPL）Digital Collections

**数字馆藏入口：** https://digitalcollections.nypl.org/  
**官方说明：** https://digitalcollections.nypl.org/about  
**Repo API 页面及状态：** https://api.repo.nypl.org/  
**API 条款：** https://api.repo.nypl.org/terms_conditions

#### 资源实际提供什么

- 官方平台说明有超过 100 万件数字化对象，覆盖图书、视频、地图、手稿、插图、照片、声音和动态影像。
- 近 50 万件对象被标注为 Public Domain / No Known U.S. Copyright Restrictions，且持续增加。
- 可按年代、主题、馆藏、Division、可在线访问、公共领域状态等筛选。
- 页面提供单件对象下载选项；部分对象可能仅能馆内阅览。
- 平台还提供 Audio and Moving Image Preservation and Access Initiative 的专门入口。
- 元数据使用 MODS；对象层级包含 Collection、Container、Item、Capture，Capture 对应图像、视频或音频资产。
- 平台正向 IIIF 兼容迁移。

#### 访问路径与重要变化

- 旧 Digital Collections Repo API 官方页面明确宣布：自 2026-08-01 起弃用，且当时没有计划公开 API 替代方案。
- 旧 API 说明页仍残留大量 API 字段和调用示例，不能据此认定旧 API 在当前日期仍有效。
- 官方 About 页面仍列出公共领域部分的 GitHub CSV/JSON 数据，以及经 DPLA 提供的全站元数据批量下载；页面称 DPLA 批量元数据大约每两个月刷新一次。
- 当前不把旧 Repo API 作为墨痕稳定生产接口。新出现的 Collections API 与旧 Digital Collections Repo API 是否构成替代关系，尚无足够官方证据确认，先标记待核。

#### 开放与权利判断

- NYPL 元数据通过 Repo API 发布为 CC0；但元数据许可不等于其描述的数字内容也为 CC0。
- 对象权利状态分为：
  - No Known U.S. Copyright Restrictions；
  - CC0；
  - Copyright Held or Managed by NYPL；
  - Undetermined。
- “No Known U.S. Copyright Restrictions”是美国版权范围内的判断，不等于全球范围无版权或无其他权利。
- 隐私权、肖像权、宣传权等仍可能适用；未标记对象不能默认开放。
- API 条款只允许非商业用途；商业用途需要联系 NYPL。

#### 墨痕推荐利用

- 对城市史、移民史、家庭生活、商业、交通、饮食、视觉文化、手稿与声音/动态影像研究具有高价值。
- 先通过网站发现具体对象，再使用官方可公开的公共领域元数据数据集或 DPLA 批量元数据路径。
- 对旧 API 不做新工程接入；对新 API 替代关系保持待核。
- 对象级权利判断以最新页面 Rights Statement 为准。

**优先级：高（资源发现与对象研究）；中（机器批量利用）。** 内容广度很有价值，但 API 退役和权利标识需要严格维护。

## 4. 对墨痕的具体价值

这四项资源共同支持以下研究问题：

| 墨痕研究问题 | 优先资源 | 主要寻找材料 |
|---|---|---|
| 普通人穿什么、衣料如何变化 | The Met、V&A、Rijksmuseum | 服装实物、纺织材料、年代、制作地、图像 |
| 家庭如何居住、使用家具和器具 | The Met、Rijksmuseum、V&A | 家具、陶瓷、家用器具、室内装饰 |
| 贸易、工艺和消费如何变化 | Rijksmuseum、V&A、NYPL | 器物、广告、商品图像、贸易/商业材料 |
| 城市日常生活如何被记录 | NYPL、LOC PPOC | 街道照片、地图、手稿、插图、视频与声音 |
| 不同文明同一时期的物质文化有何异同 | The Met、Rijksmuseum、V&A | 同年代、不同地域的对象、材质、用途和风格 |
| 器物如何进入博物馆、收藏史如何塑造今天的文化认知 | The Met、Rijksmuseum、Smithsonian | 对象来源、收藏记录、捐赠、流转与馆藏元数据 |

## 5. 本类尚未覆盖的关键缺口

本轮四个机构主要提供“物质对象与其数字记录”，不能替代对普通人实际生活过程的研究。后续仍需补充：

1. 历史食谱、菜单、食品广告、餐饮账簿和饮食习俗记录；
2. 家庭账簿、商品目录、贸易目录、商店广告和消费记录；
3. 农业生产、手工业、劳动过程、交通出行和地方行业档案；
4. 口述历史、民俗调查、地方声音与影像档案；
5. 普通家庭、工人、商贩、妇女、儿童等群体的生活记录；
6. 非欧美地区、尤其中国及亚洲地方社会的生活史资源，避免以欧美大型博物馆馆藏代表全球日常生活。

这些是下一轮第06类的具体研究方向，不是本轮资源失效或研究失败。

## 7. 下一项具体任务

继续第06类，重点从“博物馆藏品”转向“日常生活的一手记录”：

- 历史食谱、菜单、食品和餐饮；
- 家庭与消费、商业目录；
- 劳动、生产、农业、交通；
- 民俗、口述历史、声音与动态影像；
- 中国及亚洲地方生活史资料。

优先寻找官方图书馆、档案馆、博物馆、民俗与口述历史机构；核查真实对象、许可、访问和替代路径。完成这部分后，再判断第06类是否达到必要调查覆盖，不提前宣布准出。
