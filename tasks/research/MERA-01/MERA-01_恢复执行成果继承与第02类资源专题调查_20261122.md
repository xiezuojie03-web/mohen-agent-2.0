### 2.6 18 次获取尝试的真实证据分层

P0 的 18 条尝试记录不能按“成功/失败”简单汇总：

| 证据类型 | 记录 | 当前可得结论 |
|---|---|---|
| 历史成功转述 | A0003、A0005 | 旧报告称 505/505 页或若干书目补查成功，但无原始 HTTP 日志/文件字节，不是当前 PASS |
| 历史失败已处理转述 | A0004 | 旧报告称处理了频繁访问响应，但无本轮原始日志，不作当前运行证明 |
| 资源入口或环境未连接 | A0001、A0002 | PDF获取/图像获取失败；原因未完全确认，不归因于资源方 |
| 明确本地 DNS 环境失败 | A0006—A0013 | 请求未建立 HTTP 连接、未到资源方服务器，确认为本地环境问题 |
| 自动化挑战阻断 | A0014 | Cloudflare JS Challenge；不得绕过，需用户控制的交互式浏览器或合规人工路径 |
| 工具路由结果被官方证据反证 | A0015 | 工具报404，但官方 manifest 存在该 URL，独立读取也成功；不能认定源站404 |
| 仅提取文本，未取得原件 | A0016 | OCR文本可读，但无原始文件字节、官方MD5或原件SHA256 |
| 二进制读取器不支持 | A0017 | 读取器对 binary/octet-stream 返回400，不代表源站拒绝 |
| 下载工具失败且原因未分类 | A0018 | 无DNS/HTTP状态证据，不得归因于LOC |

**关键结论：截至当前 P0 记录，18 次尝试中没有一条能够作为已核验的当前原始文件字节取得成功。** 这不否定历史资源调查成果，也不阻断其他类别资源研究；它只说明 MERA5 原件实测尚未准出。

### 2.7 P0 记录状态的含义

46 条原资源记录的状态包含 `IDENTIFIED`、`ACCESSIBLE`、`DISCOVERED`、`HISTORICAL_UNVERIFIED` 等不同层级。它们不能统称为“已验证资源”，更不能等同于已下载、开放许可或可商用。29 条方法记录保留版本差异，例如 M0004 有不同版本；不得为了表面整齐而删除历史版本。

## 4. 本轮已启动并完成的实质研究：第02类历史图像与影音资源

本轮先处理第02类，是因为 P0 原有 Smithsonian、LOC 等记录已有基础，但历史图像/影音仍缺少跨机构、对象级和权利分层的完整调查。以下为官方证据核查，不代表已取得原件字节。

### 4.1 Library of Congress — Prints & Photographs Online Catalog（PPOC）

**官方入口：** https://www.loc.gov/pictures/  
**官方资源说明：** https://www.loc.gov/research-centers/prints-and-photographs/researcher-resources/prints-and-photographs-online-catalog/  
**官方 API：** https://www.loc.gov/apis/additional-apis/prints-and-photographs-api/  
**PPOC API 文档：** https://www.loc.gov/pictures/api

**资源实际提供内容**

- 静态图像包括照片、版画、绘画、海报、建筑与工程图等。
- 官方研究者说明称 PPOC 目录记录覆盖该部门约 95% 的馆藏，数字化图像约 150 万；但目录并非全部馆藏清单，部分记录只有组级/指南级描述，部分组记录无数字图像。
- 每个页面可提供 JSON 表示；PPOC 有独立 JSON HTTP API，官方同时说明该 API 仍属 work in progress。
- 某些对象在馆外只显示缩略图；更高分辨率 JPEG/TIFF 可能仅在馆内或通过复制服务取得。

**对象级验证样本：上海外滩照片**

- 题名：`China - Kiangsu province - Shanghai. The Bund`
- 官方对象页：https://www.loc.gov/pictures/item/2001705635/
- 年代：约 1890—1923 年
- 描述：拥挤的码头场景
- 来源集合：Carpenter Collection
- 页面列出 JPEG 约 37KB、TIFF 约 1.6MB 下载选项。
- Rights Advisory：`No known restrictions on publication`。

该样本对墨痕的价值不只是“有一张老照片”：它可连接上海近代港口、滨水空间、交通、商业活动、城市公共生活和历史地图研究。它是一个可继续追踪的对象级资源，不是整个 LOC 馆藏的权利代表。

**权利判断**

- LOC 通常不拥有其馆藏材料的版权，也不为所有材料授予统一使用许可。
- `No known restrictions` 是目录中的权利提示，不等于 CC0，也不保证所有司法辖区、商业场景或第三方权利均已清除。
- 作品实际展示或商业使用前，应根据单件 Rights Advisory、原始来源、创作者、年代和用途做具体判断。

**墨痕推荐利用方式**

- 优先用于城市史、建筑史、交通史、社会生活史和视觉文化研究。
- 以网页/JSON 元数据发现与引用为主；只对具体选中的对象进一步判断是否可下载或需要馆内/复制服务。
- 不进行全库抓取，不把所有图片都视为开放许可。

**初步优先级：高。** 对中国城市史和日常生活主题有直接对象级价值；但权利必须单件判断。

### 4.2 National Archives and Records Administration（NARA）— National Archives Catalog

**官方目录：** https://catalog.archives.gov/  
**API 条款与文档：** https://www.archives.gov/research/catalog/help/api  
**官方数据集说明：** https://www.archives.gov/developer/national-archives-catalog-dataset  
**特殊媒介权利说明：** https://www.archives.gov/research/motion-pictures/permissions

**资源实际提供内容**

- 联邦档案描述、机构/人物/主题/地理等权威记录。
- 数字对象元数据、图像、视频、OCR 文本和公众贡献信息。
- 特殊媒介包括照片、航空照片、地图、建筑/工程图、电影胶片、视频、声音记录和数据集。
- 官方 AWS Registry 数据集说明称数据量超过 261GB，包含档案描述和权威记录，以及超过 1.48 亿个数字对象 URL；页面称数据截至 2026-03-01，并计划每年更新两次。
- 官方页面同时列出文件名带 `2026-09-14` 的数据包，日期口径需要后续核对，不能未经核实就将其当成数据快照的确定日期。
- AWS 数据集支持按全部描述、记录组、集合和权威记录类型分段获取；这比通过 API 全量抓取更符合官方提供的路径。

**访问与利用条件**

- Catalog API 需申请 API Key；默认每个 Key 每月 10,000 次查询，可按研究需求申请更高限额。
- API 条款禁止通过 API 抓取或下载全部目录数据，并明确要求不得缓存或存储 API 返回内容。
- 全量或分组元数据另由官方 AWS Registry of Open Data 提供；AWS 公共数据集的访问方式与 API 响应条款不能混为一谈。
- 网页目录可免费检索；API 申请 Key 不等于取得媒体原件许可。

**权利判断**

- 美国联邦机构公务形成的政府作品在美国通常不受版权保护。
- NARA 馆藏并非全部公有领域，尤其特殊媒介可能包含捐赠材料、第三方版权、合同/捐赠契约限制、表演权、隐私权或肖像权。
- NARA 不为所有对象确认版权状态，也不授予统一出版或商业使用许可。
- 必须逐件查看 `Use Restrictions`、来源信息及捐赠/权利文件；未知项保持待核。

**墨痕推荐利用方式**

- 用 NARA 作为照片、电影、视频、声音和联邦历史档案的发现入口，尤其适合战争、外交、移民、城市建设、科技、交通和社会生活研究。
- 不下载 261GB 全量数据。先按主题、记录组、机构或年代筛选；必要时只研究官方提供的元数据子集。
- 对单件媒体再回到对象页检查权利与数字对象链接；必要时联系 NARA 特殊媒介权利联系人。
- API 不作为可长期缓存的墨痕数据源；如需持久化元数据研究，优先评估官方 AWS 数据集路径及其适用条款。

**初步优先级：高（发现与目录层）；中（媒体再利用层）。** 资源广度大，但对象权利复杂，API 条款也限制了直接持久化利用。

LOC 当前目录列出约 20,150 条 1900—1925 年录音，类型包括流行音乐、民族音乐、歌剧、古典、音乐剧、宗教、幽默歌曲等；语言和目标听众覆盖多种族群。LOC 说明约 6,000 条录音已可下载，其余部分可在线流媒体播放。

**访问路径：** National Jukebox 网页按录音、年代、类型、语言、表演者和唱片标签检索；Citizen DJ 提供从 Jukebox 选出的公有领域音频子集及批量样本。适合研究早期大众文化、音乐传播、语言、娱乐、商业录音和日常声音环境。

**权利判断必须区分三层：**

1. Jukebox 免费流媒体由权利人许可 LOC 提供，不等于允许复制、剪辑、再分发或商用。
2. 美国《Music Modernization Act》下，1923 年以前出版的录音已进入美国公有领域；1923—1946 年录音保护 100 年，1947—1956 年保护 110 年。需按具体录音的出版年份和对象级权利记录判断。
3. Citizen DJ 中明确标记为公有领域的选定子集，可复制、修改、分发和商用；但隐私、宣传权和文化敏感性仍需考虑。不能将 Citizen DJ 的开放状态外推到 Jukebox 全库。

**本轮判断：** National Jukebox 是第02类值得纳入的影音重点资源；它补充了第02类的历史声音材料，但不代表历史电影、电视和非音乐口述影音已经完成调查。
