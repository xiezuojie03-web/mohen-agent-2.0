# MERA-01｜第07类学术研究与专业知识资源专题调查

**核查日期：** 2026-11-22  
**资源类别：** 07｜学术研究与专业知识  
**依据：** MERA-01 V1.1 唯一任务书及 2026-11-22 Owner 恢复执行指令  
**归档性质：** 既有专项的专题研究增量，不是新任务书，不建立平行资源主库

---

## 1. 本类研究定位

第07类不是“搜索学术论文的网站列表”，而是为墨痕建立一套可组合的学术知识发现与证据支撑环境：

- 学术专著与章节：提供系统性研究成果和理论脉络；
- 期刊论文与研究报告：提供专题研究、史料辨析、方法与学术争论；
- 学术元数据与引文关系：支持人物、机构、主题、时间、学科和研究传统之间的关联发现；
- 开放获取全文与许可：明确哪些可阅读、下载、机器分析、引用、再分发或商业利用；
- 付费/订阅资源：识别其学术价值、访问条件和必要性，不将“免费浏览”误判为开放许可。

本轮重点调查 JSTOR、DOAB、OAPEN 和 OpenAlex。四者职责不同，不能互相替代。

## 2. 重点资源调查

### 2.1 JSTOR Open Content / Early Journal Content / Open Access Books

**官方入口：** https://www.jstor.org/  
**Open Content 说明：** https://support.jstor.org/hc/en-us/articles/115004681927-Open-Access-Content-Free-Content-on-JSTOR  
**使用条款：** https://about.jstor.org/terms/  
**Text Analysis Support 条款：** https://about.jstor.org/terms/text-analysis-support/  
**Open Access Books：** https://guides.jstor.org/for-librarians-books/oaresources

#### 实际提供内容

- 学术期刊、学术专著、章节、图像与历史原始资料。
- Open JSTOR Collection 包括 Early Journal Content、Open Access Content、Reveal Digital 等。
- JSTOR 支持说明称 Early Journal Content 包含 200 多种期刊的 50 万篇以上公有领域文章；具体纳入范围按滚动年限判断：美国出版内容早于最近 95 年，国际出版内容早于最近 143 年。
- JSTOR Open Access 电子书超过 9,000 种，来自 University of California Press、University of Michigan Press、RAND 等学术出版社；可与期刊和原始资料交叉检索，并由 Portico 保存。
- JSTOR 还包含 Open Artstor、Reveal Digital 等图像和历史资料资源。

#### 访问方式

- Open Content 可免费访问；部分用户可通过免费个人账户读取有限数量的可访问内容。
- 机构订阅内容仅向有授权的机构用户开放；JPASS 等个人付费服务另有访问范围和限制。
- Open Access 电子书可免费阅读/下载；每本书的 CC 许可类型需在对象页面核对。
- Early Journal Content 全文文本分析可通过 JSTOR Text Analysis Support 申请；该支持不是面向所有内容的开放批量下载接口。

#### 开放与权利判断

必须区分：

1. **免费阅读：** 个人账户或特定免费访问额度不代表可复制、再分发或商用。
2. **Early Journal Content：** 按 JSTOR 说明纳入的旧期刊内容具有公有领域基础，但仍需遵守平台条款和其他适用权利。
3. **Open Access 电子书：** 每本书有明确 Creative Commons 许可，按 CC BY、CC BY-NC、CC BY-ND 等具体条款使用。
4. **机构订阅内容：** 需要订阅/授权；不能因为某个用户能阅读就将内容纳入墨痕可复制资源。
5. **Text Analysis Support：** 仅用于非商业学术/教育研究；不得用于商业目的，不得用于训练、微调或增强 LLM。官方说明允许在符合条款的学术研究中使用 LLM 做文本分析，但这不等于可以把全文内容喂给墨痕的商业生产链或模型训练。

#### 墨痕推荐利用

- 作为历史研究、学术争论、史料解释和研究脉络的发现入口。
- 重点使用明确开放许可的电子书、Early Journal Content 和对象级开放资料。
- 对受订阅限制的研究成果，优先使用书目信息、摘要、合法引用和链接；必要时通过机构订阅或作者开放版本访问。
- 不把 JSTOR 全文作为默认可持久化、可商业再利用或可训练模型的语料来源。

**优先级：高（学术发现）；中低（全文再利用与商业生产）。** 学术价值高，但权限分层复杂。

### 2.2 Directory of Open Access Books（DOAB）

**官方入口：** https://www.doabooks.org/  
**元数据与 API：** https://doabooks.org/en/librarians/doab-metadata  
**官方 FAQ：** https://doabooks.org/en/researchers/faq

#### 实际提供内容

- DOAB 是开放获取学术图书的目录与发现平台，重点为学术出版社出版、经过同行评审的开放获取专著。
- 提供书名、作者、出版社、主题、出版时间、语言、DOI/持久链接、开放许可及全文入口等元数据。
- DOAB 主要负责发现与链接，不等于它本身托管所有书籍全文；全文通常由出版社、OAPEN 或其他知识库提供。

#### 访问方式

- 元数据可通过网页、下载数据源、OAI-PMH、选择性导出和 API 获取。
- 官方元数据可下载为 MARCXML、KBART、ONIX、JSON、CSV 等格式。
- OAI-PMH 入口为 `https://directory.doabooks.org/oai/`。
- 元数据整体按 CC0 1.0 发布。

#### 开放与权利判断

- DOAB 元数据 CC0，可用于墨痕资源发现、索引、主题分析和目录整合。
- 书籍本身的版权和许可由出版方/作品对象决定；DOAB 的目录收录不意味着所有书籍均采用同一种 CC 许可。
- DOAB 不托管全部全文；需跳转到具体出版社或知识库检查许可、下载方式和版本。

#### 墨痕推荐利用

- 用于寻找历史学、考古学、艺术史、文化研究、地理、人类学、社会史等开放学术专著。
- 对某个主题先通过 DOAB 建立书目候选，再进入全文托管方核对版本、许可和完整性。
- 利用 CC0 元数据形成跨出版社的学术专著索引。

**优先级：高。** 对开放学术专著发现和元数据整合价值高；全文权利须回到具体出版物。

### 2.3 OAPEN Library

**官方入口：** https://library.oapen.org/  
**元数据与批量服务：** https://oapen.org/librarians/metadata  
**服务说明：** https://oapen.org/librarians/services-libraries  
**出版社准入说明：** https://oapen.org/publishers/join-oapen-library

#### 实际提供内容

- OAPEN 提供经过质量控制的开放获取学术图书，重点为学术出版社和同行评审专著。
- 与 DOAB 相比，OAPEN 不只是目录，还托管书籍全文和长期保存服务。
- 可检索书籍及章节；官方元数据中区分有全文下载链接与无全文下载链接的记录。

#### 访问方式

- 提供 MARCXML、KBART、ONIX 3.0、JSON、CSV、RIS 等元数据。
- 支持 OAI-PMH，基础 URL 为 `https://library.oapen.org/oai/`。
- 提供选择性导出，可按出版社、主题、语言、出版类型等筛选；该导出适合不超过约 500 种标题的集合。
- 官方元数据服务说明称数据源每日更新；元数据 feeds 按 CC0 1.0 提供。

#### 开放与权利判断

- 元数据 CC0。
- 图书全文按具体出版物的开放许可使用；不能因为收录于 OAPEN 就把全部全文统一认定为 CC0。
- 书籍是否可下载、使用何种 CC 许可、是否允许商业利用，应以该书对象页和出版方许可为准。
- OAPEN 的质量控制和同行评审准入提高了学术发现价值，但不能替代对单本书学术质量、方法和史料来源的判断。

#### 墨痕推荐利用

- 将 OAPEN 作为开放学术专著全文的重点入口。
- DOAB 负责跨出版社发现，OAPEN 负责其中一部分全文托管与元数据维护；两者互补，不重复登记为同一个平台。
- 对全文下载和商业利用逐本读取许可；可持续使用的元数据优先通过 CC0 feeds/OAI-PMH 获取。

**优先级：高。** 开放专著全文、元数据批量访问和长期保存能力较强。

### 2.4 OpenAlex

**官方入口：** https://openalex.org/  
**API 文档：** https://help.openalex.org/api/  
**Snapshot 说明：** https://help.openalex.org/access/snapshot/  
**许可字段说明：** https://help.openalex.org/data/licenses/  
**开放获取字段说明：** https://help.openalex.org/data/works/open-access/

#### 实际提供内容

- OpenAlex 是全球学术研究系统的开放目录/知识图谱，覆盖 works、authors、sources、institutions、topics 等实体及其关系。
- 默认核心语料包含 3 亿以上 works；`corpus=all` 可包含更大的扩展语料，官方 2026 年说明约增加 60%。
- 记录包含作者、机构、出版物、日期、DOI、主题、引文、参考文献、开放获取位置、许可、基金等信息。
- 它是学术元数据与关系网络，不是所有论文全文的托管库。

#### 访问方式

- REST API 免费使用，无需 API Key；免费 API Key 可将每日预算提高 10 倍，更高用量采用按量计费。
- 可按作者、机构、期刊、主题、年代、DOI、开放许可和引文关系筛选。
- 完整 Snapshot 可从公共 S3 桶匿名下载，无需 AWS 账户；JSONL 或 Parquet 两种格式。
- 2026 年 9 月 Snapshot 约 626 million records；压缩 JSONL 约 745GB，Parquet 约 770GB，解压后更大。
- 免费公共 Snapshot 每季度更新；每日同步属于付费服务。对墨痕而言不应默认下载整个数据库，优先 API 定向检索。

#### 开放与权利判断

- OpenAlex 自身学术元数据以 CC0 发布，可用于商业和非商业用途。
- OpenAlex 的 OA 字段描述的是作品某个可访问副本的许可状态；许可属于具体 location，不是作品整体统一许可。
- 它识别 CC BY、CC BY-SA、CC BY-NC、CC BY-ND、Public Domain/CC0，以及 `other-oa`、`publisher-specific-oa` 等类型。
- `other-oa` 或 `publisher-specific-oa` 表示开放状态存在但具体许可不能简单归类；不能一律推定可商用。
- 全文链接和全文档案是另一层服务；不能把 OpenAlex 元数据 CC0 扩展到其链接的 PDF 内容。

#### 墨痕推荐利用

- 作为全球历史人文研究的学术发现、作者/机构/主题关系和引文脉络入口。
- 对某个人物、事件、地方、器物或制度主题，利用 OpenAlex 找研究者、主题、文献、机构和研究变化，再回到出版社/知识库核验全文。
- 用 API 做定向查询和小范围增量更新；不下载 700GB 级全量 Snapshot。
- 对 OA 文献逐个读取 `primary_location` / `locations` 的 license 字段，决定可否复制、分析和商用。

**优先级：极高（发现与关系分析）；中（全文利用）。** 数据开放程度高，但学术元数据不等于全文开放，且 Snapshot 体量巨大。

### 2.5 Zenodo

**官方入口：** https://zenodo.org/  
**开发者 API：** https://developers.zenodo.org/  
**许可说明：** https://help.zenodo.org/docs/deposit/describe-records/licenses/

Zenodo 是 CERN 与 OpenAIRE 支持的全球开放研究成果仓储，接收研究数据集、出版物、软件、报告、海报、视频和其他研究对象。记录可分配 DOI、保留版本、提供引用信息，并通过 REST API、OAI-PMH 和数据服务被发现。

**实际内容与利用：** 适合发现考古项目数据、历史GIS、数字人文数据、研究软件、图像/影音和研究报告；可按主题、作者、机构、DOI检索。每个记录有独立元数据、版本和文件清单。

**权利边界：** 元数据按 CC0 发布；文件许可由上传者选择，可能为 CC BY、CC BY-NC、CC0 或其他许可。记录也可能处于 embargo、restricted 或 closed 状态。不能把元数据 CC0 扩展到文件。

**墨痕利用：** 作为跨学科研究数据和软件的发现入口；优先读取 DOI、具体版本、文件级许可和访问状态，再决定引用、下载或商业利用。

**优先级：高。**

### 2.6 Harvard Dataverse

**官方入口：** https://dataverse.harvard.edu/  
**API 指南：** https://guides.dataverse.org/en/latest/api/  
**数据集管理：** https://guides.dataverse.org/en/latest/user/dataset-management.html

Harvard Dataverse 是研究数据仓储平台，覆盖社会科学、人文、考古、地理、历史和跨学科数据集；全球大学和研究机构也部署 Dataverse 实例。

**实际内容：** 调查数据、GIS、统计数据、考古数据、文本编码、图像、音频、研究代码和文档；支持数据集 DOI、版本管理、文件级元数据、引用、API、OAI-PMH 和长期保存。

**访问方式：** 网页检索/下载、Dataverse Search API、Native API、OAI-PMH；文件可开放、embargo 或 restricted。

**权利边界：** Dataverse 可采用 CC0，也允许发布者选择其他许可或自定义条款；不同数据集和文件访问级别可能不同。商业再利用必须按数据集/文件许可和附加条款判断，不能将平台默认选项当作全库许可。

**墨痕利用：** 特别适合发现研究者公开的考古、历史GIS、社会史和定量人文数据；对每个数据集单独检查 DOI、版本、文件、访问状态和许可。

**优先级：高。**

### 2.7 OpenAIRE Research Graph / Explore

**官方入口：** https://explore.openaire.eu/  
**Graph 文档：** https://graph.openaire.eu/  
**开发者 API：** https://develop.openaire.eu/

OpenAIRE 将学术出版物、研究数据、软件、项目、组织、资助者和研究人员连接为研究成果图谱，支持从论文追踪关联数据集、软件、项目和机构。

**访问方式：** Explore 网页检索、REST API 和 Graph 数据转储；部分开放全文仍链接到原始仓储或出版方。

**权利边界：** OpenAIRE Graph 元数据采用 CC BY 4.0；底层论文全文、数据文件和软件许可由原始仓储/出版方决定。元数据开放不等于全文开放。

**墨痕利用：** 适合从历史人文论文发现关联数据、软件、资助项目和研究机构，建立“研究成果—数据—软件—项目—机构”关系；全文回源核权。

**优先级：高。**

### 2.8 Directory of Open Access Journals（DOAJ）

**官方入口：** https://doaj.org/  
**API：** https://doaj.org/api/v2/docs  
**公共数据转储：** https://doaj.org/docs/public-data-dump

DOAJ 是全球开放获取期刊和文章发现目录，提供期刊级/文章级元数据、出版商、DOI、许可和全文链接；有期刊收录标准与质量筛查，支持 REST API、CSV 和数据转储。

**权利边界：** DOAJ 元数据采用 CC0；期刊/文章内容许可由出版商和具体文章决定，可能为 CC BY、CC BY-NC、CC BY-ND 或其他许可。DOAJ 是索引，不托管全部全文，收录不代表每篇文章都可商用。

**墨痕利用：** 用于发现开放获取的人文、历史、考古、地理和艺术史期刊；先核期刊收录和出版商，再核文章级许可及全文版本。

**优先级：高。**

### 2.9 CORE（Connecting Repositories）

**官方入口：** https://core.ac.uk/about  
**数据集说明：** https://core.ac.uk/documentation/dataset  
**开放基础设施原则：** https://blog.core.ac.uk/2022/05/23/core-our-commitment-to-the-principles-of-open-scholarly-infrastructure/

CORE 聚合全球机构仓储、学科仓储和开放期刊的论文与元数据。官方页面称约收录 449M 篇开放获取文章，来自约 15,000 个数据提供方；提供搜索、开放版本发现、CORE API、批量数据集和 FastSync。

**访问方式：** 网页检索；申请 API Key；使用批量数据集和 FastSync；CORE 通过 OAI-PMH 采集仓储内容。

**权利边界：** CORE 聚合数据转储采用 ODC-BY；但论文全文仍受原始仓储、作者和出版商许可约束。CORE 对商业伙伴提供服务许可，不意味着所有全文都可用于商业作品或再分发。

**墨痕利用：** 先用 CORE 找到论文的开放版本和来源仓储，再回原仓储核对全文、版本和许可；元数据/聚合数据许可与全文权利分开管理。

**优先级：高。**


## 3. 九项资源的职责分工

| 资源 | 主要角色 | 可持续利用优势 | 主要限制 |
|---|---|---|---|
| JSTOR | 学术期刊、专著、历史期刊与原始资料发现 | 学术深度高，Open Access书籍和Early Journal Content有明确开放区 | 订阅内容多；免费阅读不等于开放；Text Analysis Support非商业且禁止LLM训练 |
| DOAB | 开放学术专著发现目录 | 元数据CC0、多格式导出、OAI-PMH/API | 不托管所有全文；书籍许可由出版方决定 |
| OAPEN | 开放学术专著全文与保存 | 全文托管、同行评审准入、CC0元数据、每日元数据更新 | 每本书许可不同；部分记录无全文下载链接 |
| OpenAlex | 全球学术元数据与关系图谱 | CC0、免费API、作者/机构/主题/引文关联 | 不是全文库；OA许可按副本/位置区分；全量快照极大 |
| Zenodo | 开放研究成果仓储 | 数据集/出版物/软件/报告DOI、版本和API | 元数据CC0，文件许可由上传者选；记录可受限/embargo |
| Harvard Dataverse | 学术研究数据仓储 | 历史/考古/GIS/社会科学数据、DOI、版本、API | 数据集/文件级许可与访问限制不同 |
| OpenAIRE | 学术成果关系图谱 | 论文—数据—软件—项目—机构关系，API/Graph dump | 元数据CC BY 4.0，全文和数据文件回源核权 |
| DOAJ | 开放获取期刊索引 | 期刊/文章元数据、API、CC0数据转储 | 全文由出版方托管，文章许可逐项核验 |
| CORE | 全球开放论文聚合 | 机构仓储全文发现、API、ODC-BY数据转储 | 全文保留来源许可，商业服务授权不等于全文商用许可 |

## 4. 对墨痕知识生产的实际价值

| 研究主题 | 优先资源 | 优先寻找什么 |
|---|---|---|
| 历史人物与思想 | OpenAlex、JSTOR、DOAB、OAPEN | 研究者、学术专著、论文、思想史脉络和学术争论 |
| 城市与地方史 | JSTOR、DOAB、OAPEN、OpenAlex | 地方史专著、城市研究、历史地理、考古和社会史论文 |

## 5. 重要风险与使用原则

1. **学术元数据开放不等于全文开放。** OpenAlex、DOAB、OAPEN 的元数据许可和全文许可必须分开记录。
2. **开放获取不等于 CC0。** CC BY、CC BY-NC、CC BY-ND、CC BY-SA 等许可的商业和改编限制不同。
3. **免费阅读不等于可复制。** JSTOR 免费账户、订阅访问和 Early Journal Content 不是同一权限。
4. **Text Analysis Support 有明确边界。** JSTOR 该服务仅供非商业学术/教育研究，不可用于商业目的，也不可用于训练或微调 LLM；不能作为墨痕商业生产链的默认全文输入渠道。
5. **OpenAlex Snapshot 体量过大。** 2026 年 9 月完整快照约 745GB 压缩 JSONL；墨痕应优先使用 API 定向检索，不因“开放”就下载全量。
6. **学术目录不是质量保证。** 收录、同行评审、开放许可和学术观点可靠性是四个不同维度；对关键结论仍需追溯原文、研究方法、史料基础和出版信息。
7. **学术知识要保留时间性。** 记录出版日期、修订版、勘误、撤稿/更正、引用关系和版本，避免将旧研究当作当前共识。
