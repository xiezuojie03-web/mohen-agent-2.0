## 1. 本类研究定位

第03类不只是“历史地图图片”。墨痕需要同时建立四种互补资源：

1. **历史地图图像：** 古地图、城市图、地形图、航海图、专题地图及高清扫描；
2. **地理空间数据：** GeoTIFF、GeoJSON、KML、Shapefile、栅格/矢量图层和地理配准；
3. **历史地名与地点知识：** 古今地名、异名、地点类型、坐标、时间范围和地名沿革；
4. **跨时期空间关联：** 将不同历史时期的地点、行政区、交通、聚落、边界和文化景观联系起来。

本轮在继承 P0 已有 LOC、CHGIS、Virtual Shanghai 的基础上，新增调查 David Rumsey Map Collection、World Historical Gazetteer、Pleiades 和 Harvard Geospatial Library。

## 2. 重点资源调查

### 2.1 David Rumsey Map Collection

**官方入口：** https://www.davidrumsey.com/  
**地理配准地图：** https://www.davidrumsey.com/view/georeferenced-maps  
**版权与许可：** https://www.davidrumsey.com/about/copyright-and-permissions  
**Google Earth/Maps 应用：** https://www.davidrumsey.com/view/view

#### 实际提供内容

- 当前馆藏检索页显示约 152,373 张地图与图像。
- 覆盖全球不同地域、尺度和历史时期，既有城市图、区域图，也有地形图、航海图、专题图和地图集。
- 一部分地图已进行地理配准，可叠加到现代地球/地图上进行历史空间比较。
- 部分地图可通过 Google Earth/Maps 浏览和叠加；选定地图提供 KML 链接。
- 对象页的 Media Information 可显示地图出版者、作者、年代、馆藏来源和下载选项。

#### 访问与利用方式

- 网页地图检索和在线浏览；
- 对有下载按钮的地图，可通过 Export 或 Download 1 下载全分辨率 JP2；
- 选定地图提供地理配准、Google Earth/Maps 叠加；
- 不是所有地图都允许下载：没有 Download 按钮的地图仅可在网站展示，除非另行取得原出版者/遗产权利人的许可。

#### 开放与权利判断

- 馆方版权说明允许网站图像在个人使用及印刷/数字出版物中免费使用，包括营利和非营利出版物。
- 作为独立商品销售的地图传真品/复刻品需要另行许可。
- 1929 年之后出版的地图仍可能受版权保护；用户需核对原出版者和地图本身权利。
- 对象没有下载按钮时，不能将在线可见图像当作可复制资源。
- 馆方要求标注 “David Rumsey Map Collection, David Rumsey Map Center, Stanford University Libraries”。

#### 墨痕推荐利用

- 用于全球历史地图发现、城市空间变迁、交通、边界、地貌和历史景观研究。
- 优先选择可下载、已地理配准且权利信息明确的对象。
- 对历史地图进行古今叠加时，保留原地图、配准信息、坐标参考和误差说明，不能把配准结果当作历史原始测量精度。
- 可用于“站在一个地方，看历史发生变化”的空间叙事，但地图图像的出版许可与地理配准数据的权利应分开记录。

**优先级：高。** 全球地图数量、地理配准和高分辨率图像价值突出；权利需对象级判断。

### 2.2 World Historical Gazetteer（WHG）

**官方入口：** https://whgazetteer.org/  
**API 文档：** https://docs.whgazetteer.org/content/technical/apis.html  
**许可与来源归属：** https://docs.whgazetteer.org/content/license.html  
**FAQ：** https://docs.whgazetteer.org/content/v4/user-guide/troubleshooting/faq.html

#### 实际提供内容

WHG 是跨时间、跨语言连接历史地点记录的地理知识平台。其数据包含：

- 历史地点、古今地名、异名和地点类型；
- 地点几何、坐标、时间范围；
- 来源地名库、来源记录和外部关联；
- 地点之间的连接、数据集、集合和时间段实体；
- 地理编码、名称匹配、空间查询和 reconciliation 服务。

其来源并非单一数据库，包含 GeoNames、Getty TGN、Wikidata、CHGIS、D-PLACE、Digital Gazetteer of the Song Dynasty 等不同地名库/数据集。

#### 访问与利用方式

- 网站可无账户浏览历史地点索引；
- v4 Entity API 可取得 Place、Dataset、Collection、Area、Period 的完整元数据、名称、类型、几何、时间和链接资源；
- Reconciliation API 可用于名称匹配与跨数据源实体对齐；
- API 大多数端点需要用户 Token；只读公开地点数据另有无 Token 的 MCP 访问路径；
- 旧 v3 `/api/index/`、`/api/db/`、`/api/spatial/` 等接口已弃用，新的 Entity/Reconciliation API 是当前方向；
- 2026-09-21 文档新增 503 服务不可用状态，必须与 404“地点确实不存在”区分；503 不能作为缺失记录缓存。

#### 开放与权利判断

- WHG 不对聚合数据整体声明统一许可。
- 每个来源地名库/数据集保留自身许可，例如 GeoNames CC BY、Wikidata CC0、OpenStreetMap ODbL、Getty TGN ODC-By，另有非商业或机构自有条款。
- WHG 的聚合/编辑工作有自身许可，但只能与原数据源许可并列，不能替代原数据源许可。
- 每次 API 响应可能同时包含多个许可来源；必须读取 attribution 和 source namespace，按记录来源保留署名和许可。
- 文档/界面本身的 CC BY 4.0 不等于全部底层地理数据 CC BY 4.0。

#### 墨痕推荐利用

- 作为历史地名、古今地点匹配和跨地域历史空间关联的重要入口。
- 对同名异地、地名变迁、古今地点对应、历史地点空间定位等任务，先用 WHG 进行候选匹配，再回原始地名库核对。
- 与 CHGIS、Pleiades、Getty TGN、Wikidata 等结合，建立多来源地点实体关系。
- 对每条地点记录保留来源命名空间和许可，不能只保留 WHG 的聚合结果。

**优先级：极高。** 对墨痕时间—空间关系和跨语言地名关联价值突出；API与许可来源必须严格管理。

### 2.3 Pleiades Ancient Places Gazetteer

**官方入口：** https://pleiades.stoa.org/  
**数据下载：** https://pleiades.stoa.org/downloads  
**API：** https://pleiades.stoa.org/api  
**数据使用说明：** https://pleiades.stoa.org/help/using-pleiades-data

#### 实际提供内容

- Pleiades 是古代世界地点的学术地名库和关系图谱，包含地点、位置、名称、连接、时间、地点类型和书目引用。
- 2025-05-28 的编号发布版本 4.1 包含 41,480 个可引用地点资源；2026-11 的更新日志仍显示持续新增和修订地点。
- Pleiades 不是单纯的坐标列表，而是包含古代名称、现代名称、位置、空间几何、相关地点和文献引用的学术资源。
- 适合古希腊、罗马及更广泛古代地中海和周边世界的历史地理研究。

#### 访问与利用方式

- 无需登录即可搜索、浏览、链接、打印和下载已发布地点资源；
- 单件资源可提供 JSON/GeoJSON 等序列化；
- 完整数据可下载为 JSON、GIS CSV、KML、RDF 等；
- JSON 是包含地点、名称、位置和连接对象的完整数据导出；
- 每日发布最新 JSON 快照；RDF 导出每周更新；季度编号发布适合学术出版和可复现研究；
- 旧版 Legacy CSV 已标记弃用，新项目应使用 JSON 或 GIS CSV。

#### 开放与权利判断

- Pleiades 数据采用 Creative Commons Attribution 3.0（CC BY 3.0），允许分享、改编和商业使用，但必须署名。
- 贡献者保留其贡献内容的版权，平台以 CC BY 分发。
- 对于静态学术研究，优先引用带版本号的季度编号发布；对需要最新地点信息的动态查询，使用在线数据和每日快照。
- 数据集的版本日期与在线实时版本不同，不能把旧发布版本当作最新状态。

#### 墨痕推荐利用

- 作为古代世界历史地点和地名关系的高优先级底图/地名资源。
- 与 WHG 结合：Pleiades 提供古代地点的专业知识和来源，WHG 提供跨地名库的匹配和跨时期连接。
- 与 CHGIS 结合：对中国历史地名和古代世界地点建立跨文明、跨时期比较。
- 对地点的历史名称、地理位置、年代范围和书目证据分别保留。

**优先级：极高（古代历史地理）；中（全球全时期覆盖）。** 数据开放、更新频繁、学术引用体系成熟，但其核心覆盖仍以古代世界为主。

### 2.4 Harvard Geospatial Library（HGL）/ Harvard Map Collection

**官方说明：** https://library.harvard.edu/collections/geospatial-and-mapping-data  
**地图馆藏：** Harvard Map Collection

#### 实际提供内容

- Harvard Map Collection 是哈佛大学地理空间数据和地理配准扫描地图的重要收藏机构。
- 官方说明称其持有全球各地、不同尺度的 TB 级地理空间数据。
- 数据类型包括人口、自然地理、专题地理数据和历史地图。
- 数千张扫描纸质地图可作为 GeoTIFF 使用，其中包括许多公有领域历史地图和现代全球地形图。

#### 访问与利用方式

- Harvard Geospatial Library 是查找和下载 GIS 数据的主要入口；
- 部分数据可直接下载；
- 受许可、版权或格式限制的资料可能不进入 HGL，需要通过 HOLLIS 目录在 Map Collection Reading Room 查阅或申请；
- 需要区分数字数据下载、馆内访问和实体地图调阅。

#### 开放与权利判断

- 部分历史地图属于公有领域，可供研究和再利用；
- 现代地形图、商业数据和部分授权资源受版权/许可限制；
- HGL 并非全库开放下载，具体数据集要看其许可和获取条件。

#### 墨痕推荐利用

- 用于全球历史地图、地理配准 GeoTIFF、人口/地形/专题 GIS 数据研究。
- 对 P0 已有 LOC、CHGIS 和 Virtual Shanghai 资源形成补充。
- 优先选可下载且许可明确的历史地图；需要馆内查阅的资料保留为“可发现、需到馆/申请”，不强行转为下载任务。

**优先级：高。** 地理空间数据和历史地图价值突出，但访问权限分层。

### 2.5 国家地球系统科学数据中心（NESSDC）

**官方入口：** https://www.geodata.cn/  
**数据资源入口：** https://www.geodata.cn/main/  
**代表性数据条目：** https://www.geodata.cn/data/datadetails.html?dataguid=1505511&docId=15

NESSDC 依托中国科学院地理科学与资源研究所等单位建设，是国家科技资源共享服务体系中的地球系统科学数据中心。官方简介称其覆盖大气圈、水圈、冰冻圈、岩石圈、陆地表层、海洋和外层空间等 18 个一级学科，建立 115 个主题数据库；官方 2020 年简介统计为开放共享数据集 3.5 万余个、数据资源量 2.14PB。该数量是历史统计基线，不作为当前实时总量。

**实际提供内容：** GIS 矢量、遥感影像、Landsat、DEM、河网、流域边界、气候、水文、生态和地表数据；具体条目有数据时间、空间范围、贡献者、DOI/CSTR、数据文档、样例、引用方式和相似数据资源。

**访问路径：** 网页检索；查看数据样例；加入数据订单并填写使用用途；审核后在线下载完整数据。部分条目有直接下载。数据中心提供 DOI/CSTR 和标准引用方式。

**权利边界：** 平台通用使用声明明确：科学数据仅限科学研究使用；未经平台书面许可，不得复制、修改、抄录、传播或销售；使用成果须标注来源并按规定引用，公开成果需提交平台。不同数据集还可能有贡献者的额外条款。不能把“可申请下载”当成开放商用。

**墨痕价值：** 对长江流域河网、水系、地貌、遥感、DEM和环境考古有直接价值。它是重要的中国地理/遥感数据入口，但对墨痕商业作品使用需逐项取得书面许可。

**优先级：极高（研究数据发现）；中低（商业复用）。**

### 2.6 代表性样本：长江（九江湖口至长江口）1970—1979年时间序列遥感数据集

**数据条目：** https://www.geodata.cn/data/datadetails.html?dataguid=133440016654530

该数据集覆盖长江九江湖口至长江口，时间为 1970—1979 年，数据量约 358MB，主要为 Landsat 产品。官方说明称数据由课题组购买的影像和公开下载影像按年份整合，并提供数据文档、DOI、引用信息和在线订单。

**研究价值：** 这是长江中下游近现代景观变化研究的直接影像入口，可用于观察河道、岸线、湖泊、水网、圩田和城市扩张的变化。它可以与历史地图、地方志、历史照片和考古遗址环境联系起来。

**权利边界：** 影像来源混合，不能推定全部影像属于公有领域；适用 NESSDC 科研使用限制。商业使用和再分发须核原始影像权利并取得平台书面许可。本轮仅核查元数据和访问条件，未下载 358MB 数据。

**优先级：极高（研究价值）；低（直接商业再利用）。**

### 2.7 代表性样本：长江流域河流水系数据集（2020）

**数据条目：** https://www.geodata.cn/data/datadetails.html?dataguid=8828927&docid=15

该数据集由海南大学贡献，数据时间为 2020 年，数据量约 478KB，元数据于 2026-03-25 更新，提供 DOI 10.12041/geodata.8828927.ver1.db 和 CSTR 标识。数据包含长江干流、各级支流、湖泊连通水道及主要人工河道，描述河网空间分布、走向和连通关系。

**研究价值：** 可作为当前河网空间基线，与历史地图、1970年代遥感、地方水利志、古河道记载和考古聚落分布进行比较。它不是历史河网复原，不能将 2020 年河网直接投射到古代。

**权利边界：** 在线订单获取；适用 NESSDC 科研使用限制，未经书面许可不得复制、修改、传播或销售。

**优先级：高。** 对长江水网和聚落空间关系研究有直接价值。

### 2.8 中国·国家地名信息库（2022版）

**民政部官方公告：** https://app.www.gov.cn/govdata/gov/202212/25/495555/article.html  
**访问入口：** https://dmfw.mca.gov.cn/

民政部公告称，2022版国家地名信息库在2021版基础上更新了标准地名信息，包括：新增外国地名标准译名 8.74 万条、国际海底地名 89 条、南极地名 362 条、月球地名标准译名 873 条；更新行政区划调整信息 2,130 个、行政区域界线 103 条、界桩 242 颗；新增地名 20.45 万条、注销地名 19.4 万条。

**研究价值：** 可用于现行标准地名、地名编码、拼写、类型和行政区划核对，为历史地名实体消歧提供现代标准参照。

**限制：** 这是标准地名信息库，不等于完整历史地名沿革库。官方公告没有提供统一 CC/商业许可或批量下载说明；本轮未验证 API、批量导出和 2022 版之后的新版本。只能先作为权威地名核对入口。

**优先级：高（标准地名核对）；中低（历史地名研究与批量再利用）。**

### 2.9 民政部历史地名查询

**官方查询页：** https://app.gjzwfw.gov.cn/jmopen/webapp/html5/lsdmcx/index.html

国家政务服务平台民政部窗口提供历史地名查询页面，字段包括地名名称输入和验证码；结果结构包括序号、地名名称、地名编码、罗马字母拼写和类型。本轮页面可访问，但默认显示“查询无结果”，尚未完成带具体地名的查询验证，也未发现 API 或批量导出入口。

**当前判断：** 只能登记为已发现的官方查询入口，不能认定其历史地名数据已经可用或可批量获取。后续应选取明确历史地名做定向查询，确认结果、年代、来源、更新和权利条件。

**优先级：中（待验证）。**


### 2.10 全国地理信息资源目录服务系统

**官方入口：** https://www.webmap.cn/main.do?method=index1

该系统由自然资源部主管、国家基础地理信息中心（国家测绘档案资料馆）运行维护，是国家级基础地理信息资源目录和测绘成果资料入口。

官方页面列出全国 1:25 万公开版地形要素数据，覆盖全国陆地及主要岛屿和邻近海域，共 816 幅标准图幅，现势性达到 2012 年；采用 2000 国家大地坐标系、1985 国家高程基准。公开版包含省/市/县行政区、行政境界线/点、居民地地名、自然地名等 7 类要素，居民地地名约 716,785 条，自然地名约 648,565 条。部分 1:25 万公开版数据可免费下载。

**墨痕价值：** 可作为全国基础地理、地名、行政区划、水系、交通和居民地空间定位的近现代基准，适合与历史地图、CHGIS、地方志和河网数据叠加。

**限制：** 该数据现势性为 2012，不应作为当前精确底图；网站声明未经许可不得复制或镜像，部分数据免费下载不等于可商用或再分发，需按具体数据产品核权。

**优先级：高。**

### 2.11 天地图（Map World）国家地理信息公共服务平台

**官方入口：** https://www.tianditu.gov.cn/  
**自然资源部2025年平台解读：** https://www.cgs.gov.cn/tzgg/tzgg/202504/t20250424_805126.html

天地图是国家级地理信息公共服务平台，提供矢量底图、影像底图、地形晕渲、地名注记、全球境界、行政区划、地名搜索、地理编码/逆地理编码、道路和水系要素等服务。

自然资源部2025年4月资料称，平台注册开发用户超过124万、累计授权应用超过100万、日均地图服务接口访问超过10亿次；企业和公众可调用多类基础地图和API服务。

**访问路径：** 开发者注册/实名认证、创建应用、申请 Key；提供地图API、网页API、WEB服务API和数据API，并实行调用配额管理。

**权利边界：** 官方资料说明基础地图服务和部分API可免费调用，但不等于开放数据下载或离线再分发权。商业应用、缓存和再发布应按具体接口、账户类型和省级节点条款核验。

**墨痕价值：** 可用于现代地名定位、道路/水系基准、地理编码和未来地图服务；它是现代地图服务，不是历史地图资源。

**优先级：高（服务接口）；中（历史研究直接证据）。**

### 2.12 天地图·上海

**官方入口：** https://shanghai.tianditu.gov.cn/  
**关于与服务条款：** https://shanghai.tianditu.gov.cn/map/views/about.html?type=3

天地图·上海由上海市规划和自然资源局主办、上海市测绘院承办，集成国家、省、市测绘部门及相关机构的地理信息服务。首页和服务目录提供矢量地图、卫星影像、地形晕渲、地表覆盖、山影地图、多时相影像、标准地图、地图API、网页API、WEB服务API、数据API和专题频道。

**墨痕价值：** 可作为上海现代地理信息、多时相影像、地名、地表覆盖和空间定位的官方入口，与 Virtual Shanghai、CHGIS、NESSDC 和历史地图进行对照。

**权利边界：** 上海节点服务条款禁止利用平台散布广告和其他商业化宣传；数据持续更新但不担保及时性。API Key、调用配额、底层数据权利和离线再分发条件需逐项核验。不能把节点在线服务当作开放商用数据。

**优先级：高（上海现代空间基准）；中低（历史原始证据）。**

## 5. 本类尚未覆盖的关键缺口

1. 中国及东亚历史地图的可下载、可地理配准数据仍需继续扩展；NESSDC、全国地理信息资源目录和天地图补充了现代基准与服务，但不能代表历史行政区、历史地籍和古河道。
2. 中国历史地名、历史行政区、古代交通路线、河湖水系和聚落点位需要更多权威来源。
3. David Rumsey 地图虽然丰富，但不是全部地图均可下载或商用；地图图像权利和地理配准数据权利应分开核。
4. WHG 数据许可复杂，必须按 source namespace 和 attribution 逐记录保存，不能只存聚合结果。
5. Pleiades 对古代世界非常有价值，但不能覆盖中世纪、近现代全球地名体系。
6. Harvard HGL 的部分数据受机构订阅、版权和馆内访问限制；需要继续评估必要性和替代来源。
8. NESSDC提供长江1970年代遥感和当前河网数据，但平台通用条款仅限科研使用，商业作品需要书面授权；国家地名信息库和历史地名查询的批量接口/许可尚未确认。
7. 需要继续补充全球历史行政区划、历史地名词典、地理编码、地名消歧、历史地图配准和空间不确定性评价资源。
