# CEI-01｜产品入口与交互体验研究

本目录存放墨痕 CEI-01 专项的研究任务书、研究报告、设计规格、原型与证据。

## 权威与边界

- `CEI-01_Taskbook.md`：GitHub归档中的唯一现行任务书。
- 本目录仅用于研究资产归档，不进入应用运行目录、不参与构建，不改变 M5 工程施工计划、状态或权限。
- 研究归档不代表设计准出、GitHub工程继承审查通过或工程实施授权。
- 研究任务书和设计成果以Owner裁决及上位 MHKA/专业合同为准；历史版本仅供追溯，不与现行版并列。

## 目录

- `reports/`：研究与评估报告。
- `design-specs/`：产品架构、交互与工作面设计规格。
- `prototypes/`：浏览器原型及其必要说明。
- `evidence/`：测试、核验、裁决及归档证据；历史任务书放入 `evidence/archive/`。

## 归档规则

- 只归档可确认版本、来源和状态的成果；不以文件存在代替验收。
- 更新现行文件时原位替换，并在提交说明中列出变更；仅在架构/准出标准变化时增加正式版本。
- 使用 `main` 分支，按阶段成组提交；提交后核对路径、内容和commit。
- 任务书保持简洁，过程流水、重复回执和过期状态归入证据档案，不累积在正文。
