## 0. 本文件的用途与效力边界

本文件记录Owner于2026-11-24确认的V0.2后续研究路线。它的作用是让后续研究有连续、可检查、可验收的标准，避免概念反复讨论、样本与页面脱节、视觉表达先行，以及过早生成视觉概念图。

本文件属于CEI-01研究报告/方法规范，不写入、不修改CEI-01正式任务书。若后续研究发现上位任务书、MHKA或已批准设计合同存在约束，应遵循上位文件，并在研究成果中说明冲突，不得以本文件覆盖上位约束。

1. V0.2已形成“发现情境”概念定义、六项检查要素和A/B/C/D视觉组织构想；不再重复开展同一层面的概念定义和理论方案讨论。
2. V0.2之后进入“HOME结构深化与视觉设计方法研究”，而不是立即进入视觉概念图制作。
3. 研究按R1—R5五个阶段依次推进：样本验证、整体信息与空间组织、视觉表达语言、视觉概念图制作方法、制作准入评估。

## 2. 通用研究与证据标准

### 2.1 研究材料的身份必须清楚

所有样本、图像、案例和内容材料应标注其身份，不得混淆：

| 身份 | 定义 | 可用于什么 |
|---|---|---|
| 真实来源材料 | 可追溯到馆藏、档案、典籍、考古报告、可靠出版物或其他明确来源 | 内容结构验证；权利允许时用于后续视觉制作 |
| 真实题材的设计样本 | 以真实历史对象/主题为对象，但当前仅用于结构和体验测试，尚未达到墨痕正式发布资格 | 结构、信息层次和表达方法研究；必须标明设计测试身份 |
| 示意材料 | 为说明布局、比例、关系或视觉方法而制作，不声称是历史原件 | 线框、方法验证和示意构图 |
| 生成材料 | 由生成工具制作的图像或文字，不是历史原件 | 仅用于明确标识的氛围/构图探索；不得冒充史料或文物图像 |
| 待核材料 | 来源、内容、年代、身份、权利或解释仍未核清 | 只能作为待核问题，不得承担事实证明 |

每项关键材料至少记录：名称/对象、来源或出处、可核验链接/书目信息、内容身份、证据成熟度、权利状态、可用范围、限制说明。没有的信息写“未知/待核”，不推测补齐。

### 2.2 事实、解释、策展命题与设计假设分开

- **事实性陈述**：必须有与陈述相匹配的来源依据。
- **研究解释**：说明解释者、依据和不确定性，不得伪装成原始事实。
- **策展命题**：用于引导观察和组织材料，可以提出问题，但必须能说明为何把材料放在一起。
- **设计假设**：关于布局、视觉层级、浏览行为和体验效果的假设，必须通过样本或原型验证。
- **视觉示意**：只证明表达方式或布局意图，不证明历史内容本身。

### 2.3 研究结论必须标明证据等级

建议使用以下状态：
- `CONFIRMED`：有直接证据或已完成明确验证。
- `SUPPORTED`：有多项证据支持，但仍存在适用边界。
- `HYPOTHESIS`：待验证的研究假设。
- `DESIGN_PROPOSAL`：设计提案，尚未验证。
- `UNKNOWN`：目前无足够信息。
- `NOT_TESTED`：尚未执行测试。

不得将设计偏好、一次讨论或单个示例升级为普遍规律。

### 2.4 研究成本控制

- 只读取与当前阶段直接相关的V0.2、C步报告、V1.8.3/统一原型和必要的上位约束，不进行无目标的全仓库扫描。
- 不重启已关闭的竞品研究；仅在视觉表达或制作方法确有未知问题时，定向查阅少量高质量案例。
- 不为“显得完整”而制作大量文档、截图、重复版本或长篇理论综述。
- 同一结论只保留一个权威位置；阶段记录写结论和证据索引，避免多份文档复制相同正文。
- 先使用可编辑、可追溯的结构卡、表格、线框和规则文档；不以高成本视觉包装代替研究。

## 3. R1｜发现情境样本验证

### 3.1 研究目标

验证V0.2的发现情境定义和六项检查要素，是否能组织具有明显差异的历史文化内容；检验A/B/C/D组织构想在真实题材下的适用范围；识别哪些内容不能被统一模板表达。

本阶段不再重新定义“发现情境”，也不再抽象讨论A/B/C/D的理论优劣。研究以样本为依据。

### 3.2 样本选择要求

选择六组有明显差异的真实历史题材。建议覆盖以下类型，具体题材由研究者依据可获得、可核验的材料确定：

1. 地点/空间及其历史变化：如河流、城市、街区、交通或聚落。
2. 人物/事件及其历史情境：有可追溯文献或档案依据。
3. 器物/考古材料：可观察的实物、考古发现或馆藏记录。
4. 普通人日常生活：饮食、居住、出行、生产、贸易、节俗等。
5. 时间演变：某一制度、城市、文化现象或生活方式的纵向变化。
6. 跨地域/同时代比较：同一时期不同地区、文明或社会生活之间可说明比较理由的材料。

以上是样本覆盖方向，不是首页六个固定栏目。样本可以跨越多个方向，但六组之间必须具有足够差异，不能只是六个相似地点或六件相似器物。

### 3.3 样本准入要求

每组样本在进入结构验证前，至少应具备：
- 一个明确、可理解的具体入口；
- 一个有意义、可追问的发现命题；
- 至少一项可追溯的真实来源或明确标识的设计测试依据；
- 能识别哪些内容是事实、解释、比较问题或待核事项；
- 对图像、文本和其他材料的权利状态有初步记录；
- 不把待核关系、编辑联想或生成素材写成历史事实。

如某一类型暂时无法取得合适资料，应明确记录样本缺口和替代方案，不得用虚构史料填充。

### 3.4 每组样本结构卡标准

每组只制作一张结构卡，至少包括：

| 字段 | 填写要求 |
|---|---|
| 样本ID/名称 | 稳定编号和简明名称 |
| 内容类型 | 说明其主要内容特征，可多选，不等于固定栏目 |
| 具体入口 | 用户能理解并愿意进入的地点、人物、器物、事件或问题 |
| 发现命题 | 进入后有可能发现什么，为什么值得关注 |
| 内容组合 | 需要哪些材料、对象、时间/空间/人物/生活信息；说明组合理由 |
| 可信依据 | 来源、证据类型、可核验信息和当前成熟度 |
| 权利与使用状态 | 原件图像、文本、地图、摄影等的可用范围；未知项标记待核 |
| 延展线索 | 可继续追问、细读、联系或比较的方向 |
| EXP交接 | 带入EXP的焦点对象、当前问题、已知材料和证据边界 |
| 六要素检查 | 逐项标记满足/部分满足/不满足/未知，并说明原因 |
| 表达限制 | 哪些关系不能断言、哪些视觉表达会造成误解 |
| 样本结论 | 该样本对发现情境定义和页面组织的启示 |

结构卡不是最终首页卡片设计，不要求把全部字段展示给用户。

### 3.5 A/B/C/D样本比较标准

对每组样本分别判断：
- A编辑式组织是否能清楚呈现策展秩序，是否会造成传统杂志化；
- B空间化组织是否真正有空间关系支撑，是否会把非空间内容勉强地图化；
- C时空交织组织是否能揭示变化/比较，是否会制造无意义的时间轴或空间叠加；
- D复合式组织是否能按内容选择表达方式，是否因此变成缺乏统一规则的任意拼贴。

每个判断必须写出“适用/部分适用/不适用/证据不足”的理由。不得因为V0.2将D列为主候选，就预先给D更高分。样本可能支持D，也可能要求修订D的定义或缩小其适用范围。

### 3.6 R1交付与完成判据

交付：
1. 六组样本结构卡；
2. 样本来源、证据与权利状态汇总；
3. 六项检查要素的适用性记录；
4. A/B/C/D样本适用性对照；
5. 对V0.2概念和假设的修订建议（如有）。

完成判据：
- 六组样本类型确有差异，来源可追溯；
- 六项要素逐组有明确判断，不能只打勾不解释；
- A/B/C/D比较基于相同样本和同一评价口径；
- 真实事实、解释、策展问题和设计假设分层清楚；
- 明确指出定义适用范围、失效场景和仍未知的问题；
- 没有将样本测试误报为G5正式发布资产。

R1通过后才能进入R2。若样本表明V0.2定义存在缺口，应先定向修订V0.2阶段成果，再继续，不得带着已知缺陷进入页面构图。

## 4. R2｜HOME整体信息与空间组织研究

### 4.1 研究目标

研究多个不同发现情境如何共同组成一个完整HOME。重点不是把六张结构卡排成六张卡片，而是确定首页整体的信息层次、视觉空间、浏览节奏和发现路径。

本阶段需要回答：用户进入HOME后先看到什么、为什么先看到它；如何感知墨痕所覆盖的历史文化广度；如何从一个情境转向另一个情境；何时进入具体对象或EXP；如何在广度与深度之间切换。

### 4.2 研究内容

1. **首页整体秩序**：首页如何形成主次、主题焦点、内容层级和浏览节奏；是否存在明确的编辑逻辑。
2. **首屏职责**：首屏是否提供具体认知回报，而不只是品牌口号、装饰背景或单一大图；如何同时让用户感知还有其他探索入口。
3. **页面尺度关系**：主题场景、具体对象、材料细读、跨地域比较等不同尺度如何在同一首页共存。
4. **异质内容并置**：不同内容采用不同表达机制时，如何保持整体秩序、节奏和视觉连续性，而非随机拼贴。
5. **浏览路径**：用户主动浏览、偶然发现、按主题深入、切换观察视角、进入EXP等路径如何衔接。
6. **内容密度与留白**：不同区域的信息密度、阅读负担、视觉停顿和页面长度如何平衡。
7. **响应关系**：桌面端与窄屏如何保持内容关系和体验目标；不能简单把桌面多列压缩为单列而丢失层次。
8. **真实生长与更新**：只有存在真实新增材料、证据或解释变化时才呈现更新信号，不用循环动画制造知识增长感。
9. **V1.8.3继承映射**：明确哪些入口、交互和体验基因保留，哪些内容组织机制需要调整，哪些旧机制不再承担主结构。

### 4.3 页面组织研究方法

- 将R1六组样本作为统一测试内容，不临时更换成更适合某种布局的样本。
- 至少比较两种有实质差异的整体页面组织方案；不要求回到已经否定的固定目录或卡片流。
- 对每种方案检查：首屏认知回报、内容广度、情境差异、浏览路径、信息密度、EXP交接、移动适应性。
- 用完整页面线框/页面结构图表达，不用单张局部卡片代表完整首页。
- 对每种方案标明优势、代价、适用条件和失败风险。

### 4.4 R2交付与完成判据

交付：
- 首页整体信息结构和区域职责；
- 至少两种有实质差异的页面组织方案及对照；
- 完整首页低保真线框/页面构图（结构表达，不是正式视觉概念图）；
- 用户浏览与进入EXP的关键路径；
- V1.8.3继承/调整/弱化/新增映射；
- 桌面与窄屏适应原则。

完成判据：
- 六组样本均有合理位置或表达方式，不因页面布局而被迫删减/扭曲；
- 页面不是六张样本卡片的简单拼贴；
- 能解释首屏和各区域为什么这样安排；
- 主次、节奏、密度、浏览路径和EXP交接均可检查；
- 方案比较不是只比较审美偏好，而是比较内容承载与用户发现效果；
- 对V1.8.3的继承范围有明确证据和理由。

R2的线框是结构研究工具，不得以其已完成为由启动高保真视觉概念图。

## 5. R3｜视觉表达语言研究

### 5.1 研究目标

在内容结构和页面组织相对稳定后，研究“不同类型的历史文化内容应如何视觉表达”，以及如何在多种表达方式之间形成墨痕整体一致性。

核心原则：**整体统一不等于所有内容使用同一种卡片、同一种图片比例或同一种装饰风格；内容差异也不等于可以任意拼贴。**

### 5.2 重点研究维度

1. **内容与媒介匹配**：地图、历史照片、典籍页面、器物、考古遗址、人物、城市空间、日常生活、时间演变和跨地域比较，分别需要什么视觉表达。
2. **图像与文字关系**：图像是证据、主体、情境背景还是辅助说明；文字如何提供问题、解释和必要出处，不压过图像也不沦为装饰标题。
3. **时间与空间表达**：时间变化、空间位置、路线、范围、层叠、对照和关系如何按需表达；避免所有内容都被强行做成时间轴或地图。
4. **证据可见性**：怎样让用户感知材料身份和可信边界；首页只轻提示，详细出处和限制如何按需展开。
5. **视觉层级**：焦点、标题、说明、来源提示、延展入口的层级；不同内容类型如何保持可读性。
6. **视觉节奏**：大尺度场景、局部细节、文字停顿、并置对照和留白如何形成节奏。
7. **历史感与当代感**：避免把“历史感”简化为仿古纸张、棕褐色滤镜、古典字体和装饰纹样；研究如何让真实材料、空间关系和生活细节本身产生历史质感。
8. **整体品牌气质**：不同表达方式如何共享稳定的色彩、字体、网格、动效节制、图像处理和信息标识规则。
9. **可访问性与可读性**：文字对比、字号、图像说明、移动端阅读、动效偏好和交互可发现性。

### 5.3 视觉表达矩阵

R3应以R1样本为基础形成表达矩阵，至少说明：

| 内容特征 | 主要视觉任务 | 可考虑的表达方式 | 常见误区 |
|---|---|---|---|
| 地点/空间变化 | 让用户理解位置、范围或空间变迁 | 地图、历史影像对照、空间局部、路线/区域关系 | 只有地图装饰，没有可读的空间信息 |
| 人物/事件 | 让用户理解人物处境、事件过程和多方视角 | 人物材料、文献摘录、事件关系、时间节点 | 把人物故事做成无来源的影视海报 |
| 器物/考古 | 让用户观察实物形态、细节和考古语境 | 实物影像、局部放大、出土环境、观察注释 | 用生成图冒充文物原件，或把复原推测当实物 |
| 日常生活 | 让用户感知普通人的生活方式与环境 | 场景图、器物细节、空间与生活动作组合 | 只有怀旧氛围，没有生活证据 |
| 时间演变 | 让用户理解变化、延续和断裂 | 前后对照、分期、时间序列、动态变化示意 | 为了视觉形式强加时间轴 |
| 跨地域/同时代比较 | 让用户看见相同问题下的差异和联系 | 并置对照、地图定位、同尺度材料比较 | 只因相似就断言传播或因果关系 |

矩阵中的表达方式是候选，不是必须采用的模板。每种方式必须说明适用条件和证据限制。

### 5.4 R3交付与完成判据

交付：
- HOME视觉表达原则；
- 视觉表达类型矩阵；
- 统一视觉语言与异质表达的关系说明；
- 关键局部表达方法示例（可用文字、草图、线框或已有参考案例分析）；
- 禁止误用清单（例如生成图冒充原件、无证据关系可视化、仿古装饰代替内容）。

完成判据：
- 六组样本均能找到合适表达方式，且允许不同表达方式并存；
- 视觉形式由内容任务和证据性质决定，不由风格偏好决定；
- 统一性有可执行的规则，不只是“高级、雅致、有历史感”等形容词；
- 视觉表达不会夸大史料确定性、关系强度或素材身份；
- 已识别桌面与窄屏下的可读性和信息层级问题。

## 6. R4｜视觉概念图制作方法研究

### 6.1 研究目标

研究如何把R1—R3形成的样本、信息结构和视觉表达规则，转化为准确、可比较、可审查的视觉概念图。

R4研究的是制作方法和质量控制，不是开始制作墨痕HOME正式概念图。可以分析外部优秀案例、研究工具、制作局部方法测试，但所有测试材料必须标注“方法实验/非正式概念图”。

### 6.2 首先界定概念图要解决的设计问题

研究者必须区分至少四类不同表达目标：

- **整体结构表达**：解释首页由哪些区域组成、各区域承担什么职责、整体层级和节奏如何。
- **视觉气质表达**：解释整体图像、字体、色彩、材质感和品牌气质如何形成。
- **内容表达机制**：解释不同发现情境如何被视觉化，图像、文字、地图、时间和证据如何组合。
- **体验/交互表达**：解释用户如何浏览、聚焦、切换、继续发现和进入EXP。

研究应判断这些目标是否适合由同一张图承担，还是需要不同类型的概念图/设计视图组合。不得默认“一张漂亮的整页效果图”可以同时证明结构、内容、交互和技术可行性。

### 6.3 概念图类型与数量的研究

R4需要研究并确定最终制作所需的图纸类型，而不是提前锁定数量。候选表达形式包括但不限于：

- 完整首页整体视图；
- 首屏与关键页面区域的局部放大；
- 典型发现情境的内容表达样例；
- 关键浏览/交接体验的连续状态图；
- 视觉规则和组件表达示意；
- 桌面与窄屏的关键布局对照。

最终采用哪些形式，应根据R1—R3发现的设计问题决定。每一张图都必须有明确的审查问题和使用对象；没有独立审查价值的图不制作。

### 6.4 视口、比例和页面范围

研究并明确：
- 主要设计视口和目标设备范围；
- 整页展示与局部放大的关系；
- 页面长度、首屏边界、滚动位置和关键内容区域；
- 概念图中真实可见的内容密度与比例；
- 多张图之间的缩放、字体、边距和视觉尺度一致性；
- 如何避免只展示局部而掩盖完整页面结构问题。

若一张图无法同时清晰展示全局和细节，应采用有对应关系的总览+局部，而不是把全部内容压缩到无法阅读的画面中。

### 6.5 素材真实性、权利与标注规范

每个视觉素材必须标记：
- 真实历史原件/馆藏图像；
- 真实地点或场景摄影；
- 经过裁切、调色、拼接或其他处理的真实素材；
- 有明确依据的复原/重建；
- 设计示意图；
- 生成图像；
- 尚待核验的素材。

具体要求：
1. 不得用生成图像冒充真实历史照片、地图、文物、档案或考古发现。
2. 复原/重建图必须说明依据、推测部分和制作身份。
3. 真实素材必须记录来源和许可/权利状态；无法确认权利的素材不得默认可用于公开发布。
4. 研究测试可以使用明确标识的占位素材，但占位素材不能掩盖最终素材缺口。
5. 图片中的文字、地图标注、年代和地理关系必须可核验；生成工具生成的文字和地图细节不得直接当作准确内容。
6. 任何裁切、合成、颜色处理或比例变换不得改变材料的关键含义；必要时保留原图对照。

### 6.6 制作工具与分工研究

R4应基于具体任务比较工具，而不是先选工具再让设计迁就工具。需要研究的工具类别包括：

- **图像生成工具**：适合探索氛围、材质、非事实性背景和构图方向；对精确文字、地图、真实史料身份、复杂UI结构的控制有限。
- **界面/设计工具（如Figma）**：适合精确排版、组件、图层、布局、文字、状态对照和可编辑交付。
- **网页原型/HTML**：适合验证真实滚动、响应布局、交互、动效和内容密度；不应被静态效果图替代。
- **图像处理工具**：适合真实素材裁切、标注、色彩和细节整理；必须保留来源与处理记录。
- **文档/表格工具**：适合维护素材清单、来源权利表、评价矩阵和制作检查记录。

R4需明确各工具的输入、输出、适用任务、限制、复核责任和文件格式。必要时可以组合使用；不应为了减少工具数量而牺牲文字/地图准确性，也不应为视觉效果引入不必要的复杂工具链。

### 6.7 制作流程研究

建议研究以下可审查流程，并根据实际工具调整：

1. **冻结设计输入**：引用通过阶段审查的样本、页面结构、视觉表达规则和V1.8.3继承映射。
2. **建立素材清单**：记录素材身份、来源、权利、尺寸、质量、裁切限制和替代方案。
3. **确定概念图审查问题**：每张图明确要验证什么，不承担什么。
4. **建立精确结构底稿**：先确定页面网格、布局、比例、文本和图像位置，避免由图像生成工具决定信息架构。
5. **填充真实/示意素材**：区分事实素材和示意素材；生成素材只承担明确许可的非事实性任务。
6. **统一视觉规则**：字体、字号、间距、色彩、图像处理、边界和标识保持一致。
7. **多视图核对**：整体视图、局部视图、不同设备视图之间保持一致，不得互相矛盾。
8. **内容与史料复核**：核对文字、年代、地图、图像身份、来源、权利和关系表达。
9. **体验与设计复核**：检查首屏认知回报、浏览层次、情境差异、EXP交接和移动适应。
10. **版本与问题记录**：每轮只记录实质变化、未解决问题和审查结论，不累积无意义的截图版本。

### 6.8 概念图质量评价标准

R4必须形成可打分或逐项判定的评价表。至少覆盖：

| 维度 | 检查问题 | 不合格表现 |
|---|---|---|
| 结构忠实度 | 是否准确表达已确认的首页结构和区域职责？ | 画面漂亮但与已确认信息结构不符 |
| 内容代表性 | 是否能表达六组样本的差异和内容广度？ | 只展示最容易做图的一种内容 |
| 视觉层级 | 用户是否能识别焦点、次级信息和继续入口？ | 所有元素同等突出或信息过载 |
| 情境适配 | 不同内容是否采用适合自身的表达方式？ | 所有内容强制套用同一模板 |
| 证据可信度 | 史料身份、来源、年代和关系是否准确？ | 生成图冒充史料、待证关系被画成事实 |
| 可读性 | 文本、地图、图像说明在目标视口是否可读？ | 字体过小、标注混乱、图像无法辨识 |
| 整体一致性 | 多种表达是否仍具有墨痕整体视觉秩序？ | 风格彼此割裂或统一到单调模板 |
| 探索吸引力 | 是否让用户知道值得看什么、为何继续？ | 只有装饰效果，没有发现命题 |
| EXP衔接 | 是否能看出从HOME进入深入探索的合理路径？ | 只有展示，没有继续探索的入口或上下文 |
| 设备适应 | 桌面和窄屏的内容层级是否成立？ | 只在单一大屏尺寸成立 |
| 可实现性 | 是否能区分视觉愿景和实际交互/技术要求？ | 把静态图中不可实现的效果当作已完成能力 |
| 权利与合规 | 素材是否具备相应使用依据并正确标识？ | 来源/许可不明却被当作可发布素材 |

每个维度至少给出“通过/有条件通过/不通过/不适用”及理由。R4需确定哪些维度属于一票否决项；原则上，史料身份造假、关键事实错误、权利状态不明且拟公开使用、结构与已批准设计严重冲突，均不得以视觉质量高为由放行。

### 6.9 R4交付与完成判据

交付：
- 概念图表达目标与用途定义；
- 概念图类型选择依据及数量建议；
- 视口、比例、页面范围和总览/局部关系规范；
- 素材身份、真实性、来源和权利规范；
- 工具类别分工与制作流程；
- 概念图质量评价表及否决项；
- 方法实验记录（如开展），明确标注非正式概念图。

完成判据：
- 能说明每种概念图解决什么问题、不能证明什么；
- 工具选择基于任务能力和限制，而非工具偏好；
- 真实素材与生成/示意素材的身份边界清楚；
- 制作过程可编辑、可追溯、可复核；
- 质量评价有可操作检查项；
- 不需要依靠“看起来不错”作为唯一验收理由。

## 7. R5｜正式视觉概念图制作准入评估

### 7.1 研究目标

R5不是走流程，而是一次独立的证据和准备度检查。它判断当前研究成果是否足以启动正式视觉概念图制作。R5可以给出通过、有条件通过或暂缓三种结论。

### 7.2 准入检查表

| 准入项 | 必须具备的证据 | 不满足时的处理 |
|---|---|---|
| 发现情境定义 | R1样本验证完成，定义适用范围和缺口明确 | 返回R1 |
| 样本代表性 | 六组差异化样本及来源/权利/证据状态齐全 | 补充或替换样本 |
| 页面整体结构 | R2完成，整体信息层次、区域职责和浏览路径明确 | 返回R2 |
| 页面线框 | 完整页面结构可审查，非局部卡片拼贴 | 补齐页面线框 |
| 视觉表达语言 | R3规则和表达矩阵完成，统一性与差异化边界明确 | 返回R3 |
| 制作方法 | R4确定图纸用途、形式、视口、工具分工和流程 | 返回R4 |
| 素材准备 | 素材清单、来源、权利、身份及替代策略明确 | 补充素材或限定为示意 |
| 评价标准 | 质量检查表、否决项和审查流程明确 | 完善评价标准 |
| V1.8.3继承 | 保留、调整、弱化、新增有清楚映射 | 补充继承审查 |
| 交付边界 | 明确概念图不是工程实现，不暗示未实现能力 | 修订制作任务说明 |

### 7.3 准入结论定义

- `PASS`：所有关键准入项具备证据，可启动正式视觉概念图制作。
- `CONDITIONAL_PASS`：仅存在不影响核心结构表达的有限缺口；须明确限制、责任和补齐条件后，才可启动受限范围的制作。不得把条件通过解释为全部设计已冻结。
- `HOLD`：关键样本、结构、视觉语言、素材或制作方法仍不明确；不得启动正式视觉概念图制作。

R5结论必须由Owner审阅确认。研究者不能自行将`PASS`写成Owner已批准。

### 7.4 R5通过后的制作范围

只有R5通过后，才另行形成正式视觉概念图制作任务说明。该说明至少明确：
- 制作目的和目标审查问题；
- 最终需要的图纸类型及数量；
- 每张图所覆盖的页面/场景/设备；
- 使用哪些样本与素材；
- 哪些内容是真实材料、示意材料或生成材料；
- 工具与文件交付格式；
- 质量评价标准与审查责任；
- 修改轮次和版本归档方式；
- 明确不包含工程代码实现、正式发布或工程施工授权。

R5通过只表示可以制作概念图，不表示概念图已经通过验收，也不表示工程实施获批。

## 8. 正式视觉概念图制作阶段的独立验收原则

正式制作启动后，概念图应逐项对照R5通过的任务说明验收。不得因Owner认可某张图的视觉气质，就默认其他页面、内容类型、设备尺寸和交互状态均已解决。

至少进行三类审查：

1. **设计表达审查**：是否准确表达结构、内容组织、视觉层级和情境差异。
2. **历史内容与素材审查**：是否存在事实错误、素材身份混淆、证据夸大、来源遗漏或权利问题。
3. **体验与可实现性审查**：浏览路径、EXP交接、设备适应和交互意图是否清楚，静态画面与真实产品能力是否明确区分。

未通过的图应退回定向修改；不得通过新增大量装饰元素掩盖结构问题。
