## 1. 模块架构审查

### 1.1 结论：架构足以进入完整方案制作

综合修订报告已将HOME收敛为九项稳定职责。它们不是九个必须独立占据整屏的固定栏目，也不是九张卡片；概念图应把它们组织成一张连续的完整页面。

| 模块ID | 模块 | 必要性 | 制作时必须表达的内容 |
|---|---|---|---|
| HOME-00 | 全局导航与页面框架 | 必须 | 品牌定位、HOME/Explore/Watch/Create/Admin/Login等主要入口、当前定位 |
| HOME-01 | 主导发现/首要主题场景 | 必须 | 一个具体对象或问题、真实主体材料、发现命题、第一层认知回报、进入EXP入口 |
| HOME-02 | 次级发现/异质主题入口 | 必须 | 多种地域、时代、媒介和生活题材的不同尺度并置；不得做成六宫格或同款卡片流 |
| HOME-03 | 主题关系/编辑并置与比较 | 条件出现 | 只有存在明确共同问题和可说明的关系性质时才出现；比较维度和不可比项清楚 |
| HOME-04 | 材料观察/证据细读入口 | 条件出现 | 地图、档案、器物、遗址、制度材料的局部观察、来源身份与细读入口 |
| HOME-05 | 更广阔的时空与生活延展 | 必须具备该职责 | 将具体对象延伸至时代、地域、社会生活、同时代世界或当代地方经验 |
| HOME-06 | 继续探索/EXP交接与返回 | 必须 | 可嵌入多个内容模块；说明进入EXP时保留的对象、问题、来源、观察位置和返回位置 |
| HOME-07 | 墨痕Agent低干扰入口 | 必须可达 | 低层级入口、按需展开、当前内容上下文；不得默认覆盖页面或自动打开大聊天框 |
| HOME-08 | 页尾与全局补充信息 | 必须 | 安静收束、必要辅助导航和政策信息，不与知识内容争夺主视觉 |

**重要判断：**HOME-00/01/02/05/06/07/08是必须具备的体验职责；HOME-03/04按内容需要出现。HOME-06可在多个模块中出现，HOME-07可作为全局低干扰入口，HOME-03/04可以嵌入HOME-01/02。不得为了“模块齐全”把页面切割成九条彼此孤立的色块。

### 1.2 推荐整页顺序

完整概念图应从顶部导航连续展示至页尾，推荐阅读逻辑为：

1. 进入与定位：HOME-00；
2. 先发现一个具体对象/问题：HOME-01；
3. 感知知识世界的广度：HOME-02；
4. 在有依据时看见关系：HOME-03；
5. 需要时观察材料：HOME-04；
6. 从对象走向更大时空与当下生活：HOME-05；
7. 继续浏览或进入EXP：HOME-06；
8. Agent辅助与页面收束：HOME-07/08。

这不是强制线性漏斗。用户可从次级主题、已知对象或已有上下文直接进入；概念图应同时表现页面总体阅读节奏和可跳转入口。

### 1.3 六组样本覆盖检查

六组样本是内容表达压力测试，不是六个固定栏目。完整图至少要让评审者看出六种内容如何在同一视觉语法下共存：

| R1样本 | 主要视觉任务 | 建议在完整图中的表达位置 | 制作约束 |
|---|---|---|---|
| R1-01 上海两张地图 | 地图原件并置、图例/局部辨读、时间差异 | 主导发现或材料观察 | 不把地图差异直接说成城市实体变化；不得省略图幅/比例差异 |
| R1-02 林则徐与虎门销烟 | 档案原件、历史图像、现场遗物和事件脉络 | 次级发现或主导发现 | 历史绘画必须标为后世图像，不能冒充现场记录；奏折原件图像需权利核验 |
| R1-03 三星堆青铜大面具 | 器物整体、局部构造、出土语境和推断边界 | 主导发现或材料观察 | 必须对应2021年三号坑具体器物；其他三星堆面具不得冒充该件 |
| R1-04 庞贝街巷日常 | 街道、店铺、工具与劳动/生活证据 | 次级发现或生活延展 | 不能以无证据的怀旧场景代替遗址和物证；图像再利用有文化遗产限制 |
| R1-05 科举制度演变 | 制度机制、规则阶段、参与者和社会影响 | 主题关系或时空延展 | 时间轴只能辅助，不可代替制度解释；历史绘画需标明年代与身份 |
| R1-06 庞贝与东汉洛阳 | 同时代城市空间与公共生活的比较 | HOME-03关系比较或HOME-05延展 | 必须显示共同比较维度和材料不对称，不暗示两城存在直接联系 |

**模块架构审查PASS。**不需要再增加模块，也不需要把六组样本各自变成一个独立页面。

## 2. 素材可用性与权利审查

### 2.1 审查口径

本轮区分四件事，不把它们混为一谈：

- 来源可追溯：能够找到原始馆藏、考古机构、学术出版物或可靠图像记录；
- 图像可取得：有可访问的数字图像或可申请取得的图像；
- 版权/许可可用：具体文件的许可条款允许预定用途；
- 文化遗产/第三方权利可用：即使摄影者开放许可，也仍需核对文物、遗址所在地或机构的特别规定。

“能在网页看到”不等于“可下载、再发布或商用”；“CC0/CC BY”也不能自动消除另一个权利主体的限制。

### 3.3 制作流程与最小交付

正式制作时只需要一个方案任务卡和一张完整图，不再拆分多张正式概念图。

## 4. HTML设计级继承条件审查

### 4.1 结论：设计规格已齐备

现有综合修订已明确概念图与HTML原型的继承链：

`R1样本与证据 → R2模块架构 → R3模块视觉语法 → 一张完整HOME概念图 → HTML交互原型`

HTML原型不是重新设计，也不是把图片机械切成网页；它应继承完整概念图的结构与视觉决策，并把静态意图转成可操作行为。

### 4.2 稳定模块ID

HTML原型必须沿用：

- `HOME-00` 全局导航；
- `HOME-01` 主导发现；
- `HOME-02` 次级发现；
- `HOME-03` 关系/比较；
- `HOME-04` 材料观察；
- `HOME-05` 时空与生活延展；
- `HOME-06` 继续探索/EXP交接；
- `HOME-07` Agent入口；
- `HOME-08` 页尾。

模块可以在视觉上融合，但HTML必须保留可追溯的模块职责和ID；确需合并、拆分或重命名时，须记录概念图对应关系和原因。

### 4.3 每个模块的最小数据/行为字段

| 字段 | HTML原型必须能够表达的内容 |
|---|---|
| `module_id` | 稳定模块ID |
| `purpose` | 模块职责 |
| `content_type` | 地图/档案/器物/遗址/制度/比较/日常生活等 |
| `content_items` | 具体内容对象及其顺序 |
| `primary_expression` / `supporting_expression` | 主表达和辅助表达机制 |
| `evidence_identity` | 原件、摄影、研究图、处理图、复原、示意或生成 |
| `source` / `rights_status` | 来源和权利状态 |
| `actions` | 点击、展开、放大、切换、进入EXP等动作 |
| `responsive_rule` | 窄屏重排规则 |
| `motion_rule` | 动效触发、停止、减少动态效果时的替代 |
| `empty_or_unavailable_state` | 素材缺失、权利不可用或内容暂不可展示时的降级状态 |

### 4.4 HTML必须验证的行为

1. 完整页面滚动与模块顺序；
2. 主导发现、次级发现和关系模块的进入行为；
3. 材料放大、局部定位、注释展开和来源查看；
4. 比较/切换控件的状态和内容对应；
5. 进入EXP时传递对象ID、问题、来源、当前观察区域和返回位置；
6. Agent展开/收起及当前主题上下文；
7. 桌面与窄屏重排；
8. 键盘、触屏、焦点和减少动态效果；
9. 图片加载、素材缺失和权利受限时的降级状态。

### 4.5 现有HTML源码的证据边界

设计证据总盘点记录了当前统一HTML和独立HOME原型的文件名、大小及SHA256，但当前统一HTML未归档在GitHub主分支。本轮R5没有取得并重新读取这两个原始HTML文件，因此：

- 可以判定“概念图到下一阶段HTML原型”的设计级继承规范已经齐备；
- 不能判定“现有HOME V1.8.3或当前统一HTML的具体组件可以直接继承多少”；
- 不得把设计级映射PASS冒充现有代码继承审查PASS；
- HTML原型阶段启动时，应先取得证据总盘点所指向的准确源文件并校验SHA，再按概念图逐项决定`KEEP / ADAPT / REBUILD / DROP`。

**HTML设计级继承结论：PASS；现有代码继承审查：NOT_IN_SCOPE / NOT_STARTED。**

## 5. 正式概念图评审的硬性判据

正式图完成后，必须同时满足：

| 维度 | 通过标准 |
|---|---|
| 完整性 | 从全局导航到页尾连续呈现，不是首屏KV或卡片拼贴 |
| 模块准确性 | HOME-00至HOME-08职责清楚，条件模块和嵌入模块处理合理 |
| 信息架构 | 主导焦点、次级发现、关系、材料观察和时空延展有清楚层级 |
| 内容适配 | 六组样本得到代表性覆盖，且没有变成六个固定栏目 |
| 视觉表达 | 统一视觉语法成立，同时尊重不同历史材料的表达差异 |
| 历史真实性 | 图像身份、年代、来源、事实/解释/推断和关系语义准确 |
| 权利状态 | 实际使用图像均有许可记录；未授权素材只能作为明确标注的内部占位 |
| 交互表达 | 点击、展开、放大、切换、进入EXP、返回和Agent入口可被理解 |
| 动效边界 | 动效有明确功能、触发和停止条件；无自动轮播和装饰性持续运动 |
| HTML可继承性 | 模块ID、状态、数据、动作、响应规则可映射到HTML |
| 可读性 | 长页面在实际查看尺寸下可读，图内局部放大与标注可定位 |
| 成本 | 没有无必要的模块、装饰、动效和重复表达 |

一票否决项：伪造史料/文物/地图；关键事实错误；对象错配；未经证实的关系被画成历史事实；未授权素材被标记为可公开使用；概念图将尚未实现的功能描述成现有能力。
