# Codex HP02｜会话撤销与退出真实状态回执

基线 main@6b24f7f1c193bc03ca09453df7fa5e2ce5876d46。范围归 PLAN M1/HP02，不改架构、Gate或产品方向；本批不是M1生产准出。

## 实际问题与修复

旧logout仅清浏览器Cookie，复制令牌在到期前可重放；disabled→active也可能复活旧令牌。新增签名iat+jti、仅摘要的服务端撤销记录，以及账户安全字段变化时的单调失效时间。保持原Cookie及{uid,r}接口、当前角色查询与独立数据库签名分责。旧签名格式在候选开关关闭时兼容；启用后缺iat/jti的旧会话拒绝。

退出必须先获数据库持久化确认；DB异常或明确false返回503/no-store，不报成功。不保存原Cookie/密码/密钥。退出只撤销该次令牌，同账户另一独立登录保持有效。导航和Admin原本忽略退出接口失败而清空用户状态；现仅在HTTP成功且ok=true后切换，失败显示“退出未完成，请重试”，保留当前用户。

候选SQL由官方Supabase CLI v2.81.3 `migration new mab_web_session_revocation`生成，路径`supabase/migrations/20261103095024_mab_web_session_revocation.sql`。新增用户session_not_before及control.web_session_revocations；RLS只允许运行角色读写自身撤销记录，anon/authenticated/Producer/Signer无表访问，运行角色无UPDATE/DELETE；账户触发器为invoker，无新增definer权限面；Owner/摘要/过期时间均索引。该RLS隔离证据不等于生产Web数据库连接的最小角色已验收。

## 激活与回滚边界

`MOHEN_REVOCABLE_SESSIONS_ENABLED` **默认false**；仅在标记隔离环境置true并应用候选SQL。生产迁移/开关未执行。因此生产旧Cookie风险尚未因提交代码消除，M1仍HOLD。

生产需独立审批、备份、角色/时钟与故障验收后才可开启；新旧签名密钥/短时数据库身份边界保持原有要求。启用后禁止通过关闭开关或恢复旧auth代码回滚，否则会复活撤销Cookie；rollback候选只撤权限，保留撤销记录与单调失效边界。恢复旧备份还须保全/重放后续撤销记录或受控轮换登录密钥，未实测不得称恢复安全PASS。过期撤销记录未来可在令牌确定过期后按审批保留策略清理，本批未新增生产定时作业或成本。
