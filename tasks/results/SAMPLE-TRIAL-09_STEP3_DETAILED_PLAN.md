## 一、范围与主题（2026-10-17 受控修订）

- **范围**：金泽最小切片 `jinze-min-001`，**不扩到其它古镇**；金泽仅作为首轮数据生产工程验证样本，不代表墨痕长期方向限定为上海古镇。
- **主题**：《金泽古桥、寺院与水道：哪些历史关系能够证实，哪些仍有疑问？》——**不预设叙事结论**。
- **三类结果并存**：① 有充分证据支持的事实与关系；② 存在合理解释但仍需补证的候选关系；③ 证据不足、存在冲突或应拒绝建立的关系。
- **禁止**：不得为实现预定故事效果，强行建立桥梁、寺院、水道、人物之间的历史因果关系；原"一公里之内的南宋 / 桥寺为何相近"不得再作为预设成立的历史事实或必须证明的叙事结论。

## 三、三层递进（2026-10-17 受控修订，逐级准入）

### 第一层｜最低成本真实闭环
- 2–3 份来源明确、合法可读的文字/结构化材料，复用沪上经纬既有成果。
- 执行 D00→D05 + G0→G5 全链，最小方法集：C01（数字文本）→ H05/H04（方志/历史地理）→ W01/W02/W05/W09 → A01/A10 → P01–P07。
- **不使用 OCR、复杂舆图识别、大量模型调用**。
- 验收重点：真实数据逐阶段正确落库、证据可返源、合格成果真实资格判定、失败/不合格正确 HOLD 或 REJECT。

### 第二层｜视觉与空间能力验证
- 第一层成立后，有限加入古桥照片 + 必要历史舆图。
- 方法集补 C03/C04（舆图/照片）、H18/H25、W03（空间）、A07（跨模态共指）。
- 接通真实 `read_model` → 视觉舞台/Agent 消费通道，按 G5 资格 + consumer 分面读取，解决冻结 JSON 双事实源。
- 验收：真实前端看到数据生产链产出的历史关系、时空变化、证据解释（非漂亮图片）。

### 第三层｜历史认识边界与纠错能力验证
- 用金泽现有人工裁决 + 冲突素材。
- 方法集补 W08（来源谱系）、W09（冲突管理）、W10（一致性传播）。
- 检验保留不同说法、正确拒绝无依据关联、上游事实变化后管理下游依赖；**正确拒绝错误关系与成功发布合格知识同等重要**。

## 四、模型路由（DeepSeek 为主 + 视觉/感知切换）

| 阶段 | 任务 | 模型 |
|---|---|---|
| D01 文本/结构化 | 解析 | 确定性代码，无 LLM |
| D01 OCR | 古籍扫描件 | 本地开源 OCR |
| D01 ASR | 音频（本轮无样本，不测） | 本地开源 Whisper |
| D01/D02 视觉 | 舆图/照片 | 云端多模态（待实测选型） |
| D02 H01–H25 文本 | 史料观察 | DeepSeek 中档 |
| D03 W01–W10 | 世界建构 | DeepSeek 高档推理 |
| D04 A01–A12 | 人文发现 | DeepSeek 旗舰推理 |
| D05 规则类 | 发布 | 确定性代码（P04 组合走轻量 LLM） |

> **模型实施要求（2026-10-17）**：真实评测前**不得把 DeepSeek 某个具体型号或未经验证的价格认定为最终绑定**；模型评估必须记录实际模型版本、提示词版本、输入输出 token、重试次数、缓存命中、准确性及真实计费依据，区分一次性工程投入与持续生产成本；优先确定性处理、结构化数据复用、分步阅读、缓存；**未通过质量测试的低价模型不得仅因成本低被选用**。

## 五、落地约束（硬性）

1. **分步提示词 + 严格 JSON schema**：D02 按"分类→定位关键区→精读→结构化输出"分步跳读；输出严格对齐已补的 L2/L3 字段（`material_mentions`/`assertion_kind` 等），不合规即拒。
2. **本地缓存 + 指纹 + pgvector 从第一天建**：输入指纹（原文 hash + 提示词版本 + 模型版本）为缓存键，命中不重复调用。
3. **架构不变量**：各阶段只做自己的事，不越界补上一阶段；字段落点已闭环（42 表）。
4. **纪律**：合成测试不写真实历史、不伪造 G5 PASS；未实现方法诚实 HOLD。

## 七、验收终点（五类，同步任务书 §8.3）

1. **生产链技术验收**：D/L/G 真实运行、合法数据落点、依赖追溯、资格判定、完整执行记录（CodeBuddy 专业核验）。
2. **历史知识质量验收**：事实与解释分离、来源可追、独立证据核对、冲突保留、错误关系拒绝。
3. **前端体验验收**：真实 L5 成果驱动视觉舞台与墨痕 Agent，不用冻结演示数据冒充真实生产。
4. **成本验收**：真实样本的阶段调用量、成本、失败重试、缓存效果，能判断下一轮扩大生产是否经济。
5. **可视化与自检验收**：BR-M1 + 内容生产看板 + AI 自检看板，能观察从原始资料到历史解释的真实流转及阻断原因。
