## 一、K7：双评分 / 双篮 / 缺口报告

新增 `apps/web/lib/mohen-agent/material-score.ts`：

- **证据分 E**：资料类型（一手性）+ 来源权威 + URI/快照 + 时空粒度 + 可用性（excerpt/full_text）+ 权利清晰。
- **故事分 S**：细节密度（文本长度）+ 人物/场景关键词 + 引语 + 数字 + 图像 URL。
- **分级**：A≥75 / B≥55 / C≥35 / D<35；证据篮 = E≥55，故事篮 = S≥55，双低进 rejected。
- **缺口报告**：证据篮<5、故事篮<3、缺地名志/人物/书目/可读正文、权利未核条数；给出 6 条"下一步查什么"的建议检索词。

单测 `tests/unit/material-score.test.ts` 5 条通过（A/B/故事/缺口/rejected）。

## 三·补｜K4 人工导入（文本 + PDF + 本机 OCR）

- 新增迁移 `202610292100_imported_materials.sql`：`public.imported_materials`（owner/title/text/source_url/license/rights_declared）。
- 新增 API `GET/POST /api/studio/materials/import`：
  - 文本粘贴 / .txt / .md；
  - **PDF 文本抽取**（pdf-parse，Node external）；
  - **图片/扫描件 OCR**：调用 Windows 10/11 自带 `Windows.Media.Ocr`（中文识别器，经 `scripts/ocr-windows.ps1`）；
  - 非 Windows 415 `ocr_unavailable_on_platform`（明确平台边界，不冒充成功）；
  - 必须登录、文本 ≥20 字、必须勾选"有权使用"、默认仅自己可见。
- 资料台新增导入表单：标题/文件/正文/来源/许可/权利勾选；导入后服务端刷新，材料自动进双篮（`source_type=document`）。
- 实测：
  - PDF 导入 200 `kind=pdf chars=117`；
  - 图片 OCR 导入 **200 `kind=image-ocr chars=26`**（中文测试图识别成功）；
  - 未勾权利 400、匿名 401、资料台 200/307。
- **边界**：OCR 依赖 Windows 本机引擎；Vercel/Linux 需另接 OCR 服务（P2）。
