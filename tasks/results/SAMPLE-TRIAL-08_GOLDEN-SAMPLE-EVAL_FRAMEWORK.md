# 数据生产作业样板试验 · 金样本实测框架（样本集 + 评测口径）

> 日期：2026-10-17
> 性质：**只搭框架，不接 LLM**。目的是在真实接入前，用有"人工标准答案"的样本比较候选模型，再定最终绑定。
> 素材：金泽最小切片（jinze-min-001）现有数据（沪上经纬成果）+ 上海图书馆开放数据（SPARQL）。

---

## 一、为什么用金泽做金样本

金泽数据有别人工标注的 **ground truth（标准答案）**，是评测的稀缺资产：
- `jinze-knowledge-inventory.md`：15 实体 + 6 语义关系 + 5 新增 claim 的清单（人工盘点）。
- **HR-1~HR-6 冻结语义**（human-review 决策日志）：赵孟頫=legend、四十二虹桥=research、吕颐浩↔颐浩寺=candidate 等**不可改写的人工裁决**。
- `jinze-shl-knowledge-alignment.md`：上海图书馆 5 对象对齐 + 同名异地/同名异人消歧结论。
- 内置**冲突素材**：万安桥"秀州塘 vs 金泽塘"、赵孟頫生年 1271 vs 1254、天皇阁/天王阁异写、金泽放生桥 vs 朱家角放生桥。

这些"标准答案"让模型输出可被客观打分，而非凭感觉。

### 2.1 按三层递进安排（不要求每一层运行全部八项）
- **第一层（最低成本真实闭环，文字/结构化）**：样本 1（地方志）、样本 5（冲突）、样本 6（消歧）——纯文字，零 OCR/视觉。
- **第二层（视觉与空间）**：样本 2（OCR）、样本 3（舆图）、样本 4（照片）——验证跨模态与空间。
- **第三层（边界与纠错）**：样本 5（冲突）、样本 6（消歧）、样本 7（发现）、样本 8（组合）——验证边界/纠错/发布。

> 不足样本：C06 音频（金泽无音频素材，本轮不测）；H09 金石铭刻（金泽以方志/地名志/名录为主，无碑文铭刻素材，本轮不测）——均留待后续补样本，不强行凑。

## 三、评测口径（分阶段指标 + 门槛）

### 3.1 客观指标（可自动打分）
| 阶段 | 指标 | 说明 | 建议门槛 |
|---|---|---|---|
| D01 OCR | CER（字符错误率） | 模型识别文本 vs 人工校对 | 古籍 < 5% |
| D01 视觉 | 要素识别准确率 | 是否识别出"桥/寺/塘/图注" | 关键要素 ≥ 80% |
| D02 观察 | 字段级 F1 | material_mentions 人/时/地/物/数、assertion_kind | F1 ≥ 0.7 |
| D02 分类 | H 类型判定准确率 | 史料类别判对 | ≥ 90% |
| D02/D03 | JSON schema 合规率 | 输出严格符合 schema | 100%（不合规即拒） |
| D03 世界 | 实体/关系/事件抽取 F1 | vs 15 实体 + 6 关系 | F1 ≥ 0.7 |
| D03 冲突 | 冲突识别准确率 | 冲突是否"并列"而非"择一" | 关键冲突 100% 并列 |

### 3.2 主观指标（需人工/专家评估，LLM 无法自评）
| 阶段 | 指标 | 问法 |
|---|---|---|
| D04 发现 | 理解增量质量 | 输出是否"非平庸增量"（不是复述 B0 事实、不是换标题） |
| D04 边界 | 反证/竞争解释保留 | 是否守住 HR-2/HR-3 边界（不把 legend/research 升为 fact） |
| D05 组合 | 故事可读性 | P04 组合的故事是否可读、有内容可讲 |

### 3.3 评测流程（每候选模型同套样本）
1. 冻结样本 + ground truth（版本化，改样本要留痕）。
2. 模型按"分步提示词 + 严格 JSON schema"跑样本（提示词/schema 版本锁定）。
3. 客观指标自动打分；主观指标人工评。
4. 出分 → 对比候选模型 → 门槛筛选 → 定绑定。
5. 全链输入/输出带指纹，缓存命中不重复调用（从第一天就建）。

## 四、与"不盲信价格表"的衔接
- 本框架**不依赖任何市场价目表**：选型看"样本上的保真/准确率"，成本看"实测输入 token 数 × 接入时厂商实价"。
- 金样本跑通后，才能对 DeepSeek 主模型 + 备选（视觉/多模态）给出有依据的最终绑定建议。
