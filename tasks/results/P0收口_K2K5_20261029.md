## 二、P0-4：发布双条件（知识 + 权利）

`checkPublishEligibility` 现在按顺序检查：

1. 存在 submitted 修订；
2. `beats[].provenanceRefs` 至少一条（知识可追溯）；
3. 最新独立 Reviewer 决策 `approved`，且 **revision_id 必须等于当前提交修订**；
4. **媒体权利**：`content.media` 每项必须有 `license` 或 `rights_status=cleared`；无媒体时 `rights_acknowledged=true`；
5. **两把钥匙**：签核人不能等于发布人（`MOHEN_ALLOW_SELF_REVIEW=1` 仅限受控环境例外）。

新增集成测试 `tests/integration/publish-gate.test.ts`（隔离测试库）：

| 用例 | 结果 |
|---|---|
| 无出处 | `no_provenance_refs` ✅ |
| 有出处、未确认权利 | `no_rights_ack` ✅ |
| 出处 + 独立签核 + 权利确认 | ok ✅ |
| 签核人=发布人 | `reviewer_is_publisher` ✅ |
| 签核绑定旧 revision | `reviewer_revision_mismatch` ✅ |

## 五、K2：上海图书馆加固

- **分页**：实测端点支持 `pageSize` + `startIndex`（`page`/`limit` 被忽略），材料检索改为按页拉取（默认 10 条/页、每词最多 2 页）。
- **原始快照**：每页响应落盘到 `MOHEN_RAW_STORE_PATH/external/shl/`，材料带 `snapshot_path`，可复核。
- **修正假标注**：`content_availability` 不再一律 `full_content`：
  - 地名志 description / 人名注释正文 → `excerpt`
  - 古籍书目 / 方志书名 → `metadata_only`
- **权利字段**：材料新增 `license`、`rights_clear`（V1 为 unknown，逐条核）。
- **去重 + 重试**：`source_type|title` 去重；429/5xx 最多 3 次退避重试。
- 实网单测 `tests/unit/shl-materials.test.ts`：分页、快照、availability、去重全部通过（无 key 时自动跳过）。
