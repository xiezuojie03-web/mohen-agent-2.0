## 二、分阶段模型选型方案（框架沿用，具体型号/价格待实测）

### D01 感知层（C01–C08）—— 尽量不用生成式 LLM
- C01 数字文本 / C05 结构化 / C07 视频 / C08 实物：**确定性解析**，零 LLM。
- C02 扫描书影：OCR（本地开源 PaddleOCR 系优先，高难刻本补云端 OCR）。
- C03 历史舆图：GDAL/OpenCV + OCR，确定性 + OCR。
- C04 照片插图：视觉理解（云端多模态，Qwen-VL 系 / GLM-4V 系，待实测）。
- C06 音频：ASR（本地开源 Whisper 系）。
- 纪律：标准明确"原生结构抽取 > 保真格式转换 > 识别式恢复 > 视觉/语言模型候选"。

### D02 材料观察（H01–H25）—— 中档 LLM
- 1M 上下文吃长史料；分步提示词（分类→按结构定位关键区→精读→JSON schema 输出）。
- 严格 JSON schema 直接对齐本轮已补的 L2 字段（`material_mentions`/`reading_units`/`classification_decisions` 等），让 LLM 一次输出、不返工。
- 原文只在 D02 喂一次，关键段预筛，非关键段略读。

### D03 世界建构（W01–W10）—— 高档推理 LLM
- 强结构化 JSON 抽取 + 逻辑推理。
- W 十法"循环协同，非线性十关"：**一次 LLM 调用产出多方法字段**（identity/time/space/event/relation/change/claim/source/conflict/consistency 一次性 JSON），规则后处理分发，禁止一法一调。

### D04 人文发现（A01–A12）—— 旗舰推理 LLM
- 最强推理 + 领域知识；A 法"按问题选择，不按编号强制"，一次调用产出多字段。

### D05 可信发布（P01–P08）—— 规则化为主
- P01/P02/P03/P06/P07/P08：确定性代码（P08 已落地 `computePreciseInvalidation`）。
- P04 有界解释组合：轻量 LLM（唯一明确需 LLM 的发布方法）。
- P05 探索关系编排：图算法 + 规则化为主，可留轻量 LLM 做路线叙述。

## 三、成本评估框架（结构可靠，数字待校准）

### 3.1 成本结构（可靠）
- 成本大头 = D02–D04 的 LLM 调用；D01 本地开源 ≈ 0 API 费；D05 规则化 ≈ 0 LLM。
- 降本第一目标 = D02（长史料输入），用"轻量档初筛 + 高档深度"分级。

### 3.2 数字（待校准，不引用具体值）
- 真实成本须在"金样本实测"后，用**真实输入 token 数 + 实测单价**重算；首轮 ¥0.9/条 仅作框架示意。

### 3.3 本地优先（从样板试验第一天就建）
| 层 | 方案 | 约束 |
|---|---|---|
| LLM 响应缓存 | 输入指纹（原文 hash + 提示词版本 + 模型版本）为键 | 命中即不调用；改提示词/换模型即失效 |
| 中间结果落库 | D00–D05 分层落库（42 表已就位） | D03/D04 只消费上一层 |
| 向量检索 | pgvector（复用本地 PG，零新组件）+ 本地 embedding | 史料不出域 |
| embedding 模型 | 本地开源（BGE 系 / 智源系，待选型） | 本地算 |
