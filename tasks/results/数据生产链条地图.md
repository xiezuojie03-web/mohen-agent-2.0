## 1｜核心数据流路径（两条模式汇流成一条可信世界）

```
        【A · Discovery Research 开放发现】            【B · Directed Production 定向补证】
        入口：Discovery Intent / Research Scope         入口：T03 Narrative Gap / A 的 Selected

  D01 资料盘点 ─→ D02 内容读取 ─→ D03 Mention/Dependency
        │                │                │
        │                └─→ D04 关联扫描(信号/关联候选) ─→ D05 人文筛选
        │                                                  │
        │                              Long Tail：机器保留/合并/降级（不进人工队列）
        │                                                  │
        └────────── Selected Discovery ───────────────────┘
                                         │ 汇流点
                                         ▼
                           N01 源刷新 → N02 证据切片 → N03 候选抽取
                           → N04 确定性对齐 → N05 关系编织 → N06 门禁&投影
                                         │
                          G0–G6 Evidence Gate（R15 强制：标可用必有 evidence_gate_audit）
                                         │
                          AUTO-PROMOTE / HOLD / REJECT（零自动晋级是红线）
                                         │
                                         ▼
                          Truth Store（L0–L2 候选→ADJUDICATED→RUNTIME_ELIGIBLE→PUBLISHED）
                                         │
                          Projection（L4 只读，不反写 Truth）
                                         │
                                         ▼
                          Agent Skills（S01–S08）消费受控世界 → 用户体验 → 新缺口 ↺
```

**关键不变式**
- 共用控制面：Source Gate、Raw 保全、production-registry、run 归因、DRY_RUN/WRITE、安全停止、回滚、守卫、执行报告。
- 研究态 `truth_write_ceiling = 0`：**0 自动 Truth Promotion**；Research 与 Truth 双图分离。
- 只有 `Selected / Truth-Promotion / Narrative-Critical / Conflict-Critical` 才进 `review_queue`（三分：auto/hold/reject）。

### 6.2 C3 八层模型 ↔ 物理表（schema 分区建议）
| 层 | 语义 | 代表表 |
|---|---|---|
| **L0** Cultural Sources | 材料本身+来源身份（append-only） | `source_record` · `source_version` · `raw_item` · `ingestion_run` |
| **L1** Evidence & Provenance | 可定位最小证据单元 | `evidence_fragment` · `claim_evidence_link` · `human_review` · `conflict_set` |
| **L2** Cultural World | 人/地/事/物/关系/变化 | `entity` · `event` · `relation_claim`(=真库 `cultural_relation_claims`，R22 单一真源) · `change` · `visual_asset` |
| **L3** Meaning & Present | 解释层，与事实隔离 | `meaning_candidate` · `present_connection` · `open_question` |
| **L4** Discovery / Read Model | 派生·可重算·只读投影 | `discovery_candidate` · `world_projection` |
| **L5** Experience Runtime | 会话态·逻辑分区 | session / experience_state（仅持久化时） |
| **L6** Participation · **L7** Living Culture | HOLD（长期目标） | 暂未建物理表 |
| **Research Workspace** | 逻辑工作区（非第九层） | `research_observation` · `research_mention` · `research_source_dependency` · `research_signal` · `research_association_candidate` · `research_task` |

### 6.3 晋升闸门（R15，C3 §4.2）
- 通则：**任何表把一行标"可用/已发布"，必须在 `evidence_gate_audit` 有对应记录**，否则不得晋级。
- 形态：`create constraint trigger … deferrable initially deferred`（校验在 COMMIT）。
- 已落地：`claims_require_evidence`(claims) · `vel_confirmed_requires_evidence`(视觉链接) · `discovery_not_publishable_guard` · `review_queue_tier_c_guard` · `202610050011`(C6 扩到 10 个表)。
- 状态机（C3 §4.1）：`RAW → CANDIDATE → ADJUDICATED → RUNTIME_ELIGIBLE → PUBLISHED`（L3 及以下 HOLD/REJECT）。

```
   └─ entry: unattended-runner.mjs

        ├─ job unattended.candidate-extraction   → 写 entities/claims/...候选 (L2)
        └─ job unattended.deterministic-resolution → 写 entities 对齐 + legacy_mappings

mohen-knowledge-weave
   └─ entry: unattended-runner.mjs
        └─ job unattended.relation-weave → 写 relation 候选 + evidence 绑定 (仅 E1 确定性空间关系可晋级)

mohen-visual-asset
   └─ entry: unattended-runner.mjs
        ├─ job images-* / unattended.image-link  → visual_assets + visual_entity_links 候选
        └─ job unattended.external-visual        → visual_assets + links 候选 (Commons P18 取回)

mohen-research-intake / association-discovery / humanistic-selection
   └─ entry: pipelines/research/research-pipeline.mjs

        ├─ research.content-observation (D02) → research_observation

        ├─ research.association-scan (D04) → research_signal / association_candidate

```
