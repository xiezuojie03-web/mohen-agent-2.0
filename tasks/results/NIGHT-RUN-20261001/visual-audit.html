七、审查结论与处置建议

1. 位置对，但归属断。图片落在 visual_assets 符合 C3 §9；但 C3 §5.3 的内容关联/空间对应字段库中未实现，图片无法挂到实体/地点/锚点。
2. 质量主短板是授权与时间。741 条授权待确认 + 756 条无拍摄时间 + 727 条 depicted_period=unknown。
3. 元数据没落库。源侧 355 条 town_hint、0 条 date、53 条 desc 均未进入库内，白白丢失归属与断代线索。

建议（按优先级）：
① 补归属结构：为 visual_assets 补齐 entity_refs / place_refs / anchor_refs / correspondence_type / license / usage_scope（或建 visual_entity_links 关联表）—— 需你授权一次 DDL。
② 回填元数据：把 town_hint / date / desc 从源 JSON 回写，可立即让约 355 条图片具备归属能力。
③ 授权分级：741 条占位授权的图标记为「不可用」，只留 547 条真实 license 的进体验层。
④ 去重 15 条重复 URL。
⑤ 老照片/现代影像必须分开标注 depicted_period，避免史料误用。
