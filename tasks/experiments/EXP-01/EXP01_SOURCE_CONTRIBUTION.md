## 2｜三类入口各自不可替代的贡献

- **Legacy Lead：** 提供了金泽的「先验研究地图」——让我们知道该去查普济/万安/颐浩寺/吕颐浩，并预先标记了秀州塘冲突、42/21桥口径、吕颐浩同名异人三处坑。无 Legacy 则金泽检索会更盲目。
- **上海图书馆开放数据：** 提供了**文物名录级身份锚点**（市保/区保编号）、地名库水道名、家谱同名异人消歧——这些是 S1 级、可机器校验的身份证据，外部旅游文无法替代。
- **外部开放来源：** 提供了**跨三镇的桥寺市水实质内容**（古桥专文逐桥年代/结构、古镇朱家角漕港河分镇、章练小志市河轴线、陈云故居）——是 D02/D03/D04 的主体内容来源。

## 3｜贡献质量而非数量

- 抓取量：Legacy 旧库本就大，但本实验**未抓取**旧库任何整表，仅读 3 个既有切片摘要 → 符合「禁止大规模抓取/旧库迁移」。
- 上海图书馆：本环境无 API key，未实时大规模取回，仅复用 TASK-0011 已登记 S1 记录 → 符合「如 API 可使用才实时调用」。
- 外部：未扩到 11 镇，仅三镇定向检索 → 符合 Stop Rule。
