# MHKA-01｜墨痕价值战略与演化方向章程

**身份**：`K2_DESIGN_REVIEW_PASS_NOT_APPLIED` · 设计稿 V0.1 · 2026-10-30  
**批准的未来工程身份**：`governance/mhka/MHKA-01_Value_and_Strategy.md`（仅目标路径，本轮没有写入 GitHub）  
**唯一职责**：墨痕为什么存在、帮助谁、产生何种人文价值、何种发展选择可以长期被允许。  
**非职责**：不定义页面布局、知识 Schema、方法/Skill 算法、真实 API 和工程进度；后者按唯一 Owner 层负责。本稿不属于运行生效的产品战略文件。

## 1｜使命与不可收缩的价值

墨痕帮助人们**在广阔的历史文化知识中发现当下生活的乐趣与意义**。历史、地理、人文材料不是要出售或罗列的信息堆；它们应该让人重新理解当下所居住的地方、常见的文化习惯、人的选择、制度与空间的变化，在时间与空间的关系中发现值得继续研究和分享的事。

用户最终获得的不应只是“我又知道了一条知识”，还应能回答：“它为什么在这里发生？和其他地方、同时代有什么关系？它怎样塑造了今天？我现在能去观察、继续提问或比较什么？”准确性是底线，而非代替故事吸引力的前台叙事内容。

## 2｜服务对象与产品定位

面向愿意了解历史、文化、空间和生活关联的公众：可能是初识历史知识的普通人、希望用地图/视觉重看熟悉街区的人、研究文化遗产的兴趣者，也可能是愿意深入调查的作者。设计必须让非专业用户能够直接开始，不能要求其先掌握史料分级、GIS 操作、数据库、编导术语或工程命令。

墨痕不是应试平台、历史地图查询器、学术文献管理器、旅游 POI 列表、纯聊天机器人，也不是以证据审核界面为中心的专业后台。工具可以以其能力服务墨痕，但不能反向重塑其终极价值。

## 3｜近期内容主线与通史骨架

**近期优先**：以中国初中历史教材涉及的核心知识体系为选题主线，在中国史与世界史的通史框架中建立可被公众理解的时间—空间—叙事骨架。这是一个**选题组织原则**，不是按教材逐章复述、考试知识付费、只面向初中生或舍弃历史复杂性的决定。

骨架需要适度：先保证主要历史时期、文明地域、关键制度与社会结构、事件关系和变化线索可连接，再择要深挖对当代生活有解释力的地方/材料/人物/社会生活问题。没有足够材料支持的细节，应保留知识缺口，不以人工编造或模型猜测把全景填满。

历史世界不等于章节树：应让主题能够跨时间、空间、人物、地点、对象与材料类型复用。同一个地方可以被不同时期、不同解释主题联系；同一历史问题能从不同地域/文明的比较中获得理解增量。

## 4｜长期方法：通史骨架＋局部深挖＋可复用资产

知识建设采用两类互补路径：**通史骨架**形成视野、关联尺度和选题导航；**局部深挖**使具体历史情景、证据与解释有真正的密度。每次实际研究生产首先应争取形成经身份与资格区分的**长期可复用知识资产**；在题材、材料与发布条件适当时，再将其中的研究成果转化为面向公众可传播的作品。**作品与知识资产是两条相关但不互为前置的产出链**。

作品是文化传播的可消费成果，知识资产是以后继续研究、创作、比较和探索的基础。二者不能互相替代。作品可以下架、改版、授权变化，历史研究的合格知识对象仍要以独立身份、版本和资格维护；反之，知识对象丰富也不能自动证明产品好看、好懂、有用。

**产品价值与长期壁垒的定位**：EXP中自主发现历史文化与当下生活的联系，是墨痕长期希望实现的核心用户价值；Studio是针对早期知识覆盖不足、逐题依赖外部工程工具无法持续生产的现实问题而建立的自主研究、创作与资产积累能力；WATCH承接合法发布作品的阅读、观看与传播，可长期存在，但作品库不等于全部知识世界。Studio的研究可以先形成材料、候选与经既有资格流程形成的可复用知识资产，不以作品完稿或公开发布为沉淀前提；未合格候选仍不能冒充正式资产。**长期竞争壁垒主要是持续生长、可追溯、可关联、可复用的合格知识资产及其研究能力，不能以作品数量代替。**

初期由项目 Owner 选题、观察、审核产品方向，日常材料检索、研究、导演、草稿生产和局部改写应逐渐由墨痕 Agent 负责；正式知识生产需通过受控 Production Tool 调用既有 D00—D05/G0—G5，而非 Agent 自行写入史学 Truth；未来如实践成熟，才逐步吸纳有相同兴趣的参与者共同丰富知识宇宙。共享兴趣的社区、贡献回流、市场化服务是演化方向，**非当前已经获准实施的产品义务**。

## 5｜一间真正运行的人文研究室与创作编辑部

墨痕近期的核心目标是建立属于创作者的人文研究室与创作编辑部。对作者而言，“写一句自然语言委托”应能触发真实检索、整理、依据校验、导演判断、草稿形成与必要补证；作者主要负责选题、方向、局部修改与确认，而不需要每次先写代码、维护数据库和重画界面。

工程开发者提供工具、系统、运行能力和风险守卫，逐渐从每篇作品生产的必经步骤转为必要时的能力建设与维护者。这个劳动分工是产品长期价值和可持续性的条件，不能以“演示用 Agent 队列已出现”冒充自主研究真正成立。

**KAD1｜当前建设重点（非新“第一阶段”）。** 在不改变历史九段建设历程或K0/KAD编号的前提下，优先保障D00—D05可靠生产及长期知识资产、同题内外AI从首次真实任务协作、Studio真实研究创作、Admin可阅读具体知识条目、轻量WATCH消费合法作品。UXD-01暂停但未终止，EXP保持长期目标而不成为本轮工程的依赖；此排序不撤销MHKA-02原完整产品定义。

## 6｜产品成熟度路线：目标不随阶段缩减

产品长期拥有研究创作、观看、探索的完整体系以及运营治理工作面。**形成顺序**应体现资源和知识积累：

- 成熟度Ⅰ（非建设阶段编号）：使 Agent 真正能检索外部及已有知识来源、合法完成材料研究，驱动稳定的创作与可复用资产积累；Studio 是现实闭环的关键。
- 成熟度Ⅱ：可编辑的作品在经过运营审核、合法公开后，以 WATCH 实现有吸引力的沉浸式观看和阅读。
- 成熟度Ⅲ：随着知识库有效资产和关系足够丰富，EXP 的自主探索深度自然成长；资产稀疏时也应有诚实的低覆盖体验，而不是伪装已建成完整历史宇宙。
- 长期方向：参与、地方记忆、共同研究与持续运营，在真正的用户价值和治理能力得到验证后有界开放。

这是**成熟度与工作优先级顺序**，不是允许工程擅自删掉后续目标。WATCH 和 EXP 是相互独立的消费模式，不把 WATCH→EXP 作为 EXP 使用的前置入口。

**必须分清三种顺序**：①长期价值层级是“EXP探索发现为核心目的、Studio提供自驱动研究与资产生长能力、WATCH提供作品消费与传播桥梁”；②分阶段建设可以先强化Studio，再以WATCH提供近期内容体验，并逐步提高EXP深度；③用户进入路径始终允许独立进入Studio、WATCH、EXP，不设创作→观看→探索的必经漏斗。战略层不得因近期把Studio作为施工主任务，就把墨痕定义为以作品产量为终极目标的视频/内容生产平台，也不得因EXP初期知识稀疏而取消其独立体验目标。

## 7｜产品目标决定能力路线，不能被旧实现反向削弱

**既有工程资产优先复用：** 已迁移的六阶段数据生产、知识读模型、Agent和体验引擎，以及 Studio/WATCH/EXP/Admin 代码路径，属于战略投入而不是待从零发明的模块。未来需求先区分“现有功能”“需要深化”“必须安全整改”，不因旧能力限制减少五图目标，也不为新界面复制一套真相库、Stage 编排器或专业 Skill。实施证据以 K0-G/K1 固定提交和当前工程复核为准；历史样板 PASS 不代表公众体验全 PASS。

产品体验先提出用户真正需要的行为，再由知识世界与 Agent 专业能力评估其可靠性、成本、权利和补充条件，最后由工程实现为真实服务。若当前模型、GIS、OCR、数据或工程成本不支持某项体验，系统应提供明确的缺口报告、最小能力建设提议与合法降级选项，而不是悄悄删除产品功能、虚构数据或降低史学要求。

产品体验前置不等于先做华丽 UI 或绕过证据：历史事实、来源权利、独立 Gate、用户安全和真实可用性是必须同步成立的底线。长期战略以可复用能力和有真实材料的作品形成循环，不以“画面美观”替代实际研究深度。

## 8｜文化世界与人文表达的长期不变量

- 可信史料先于事实断言；事实与解释严格分离，认识不确定性可见但不占据叙事主线。
- 现代坐标不是历史空间；历史地图配准、空间重建与 AI 重建不能因为视觉相似就成为历史事实。
- 重视关系、变化、比较和当下连接，而不追逐历史名词数量和知识库规模。
- Agent 的智能应表现为世界/作品被真实而可追踪地改变，不是“不同措辞的聊天答复”。
- 当代观察、参与、记忆与新文化痕迹可成为未来研究线索，不能直接回写已批准历史 Truth。
- 用户价值、人文趣味、可信边界和可持续运营应同时成立；商业收入、订阅、旅游或知识交易不得成为反向塑造历史事实与体验的前提。

## 9｜商业化和开放共建的边界

顺序是：真实人文价值→核心体验成立→找到共鸣用户→形成持续使用/贡献→验证适度的运营与财务模式。不得因为短期现金流问题提前把作品生产转成应试辅导、知识售卖或广告流量系统。研究服务、文化导览、出版、共同建设等可作为有条件的未来可能，只有在新的 Owner 战略裁决与权利/成本方案成立后才成为产品要求。

开放贡献同样要有明确的身份、许可、来源、事实/观点身份和审核机制。开放程度由治理与用户实际需求决定，不以 L7/L8 已写入逻辑图谱作为已批准大规模社区工程的证据。


### KAD1-E｜专业能力必须持续服务战略，不以重命名代替价值形成

从旧成果转入本代规则时，必须检验每项能力如何服务“通史骨架＋局部深挖＋可复用知识资产”及当下生活的趣味和意义。历史研究可独立沉淀长期资产，不以完成作品为唯一验收；Studio用于可靠生产与创作，WATCH用于合法作品消费，EXP保留独立的长期探索价值。优先级变化不废止原人文有效方法，也不授权重做暂停中的UXD-01。六阶段生产专业规则不可为方便Agent表现而稀释，反之史料资格审查不得吞没前台叙事趣味。

## 10｜战略验收与未来迭代

每次重要作品或功能生产都应检查：是否有具体的人文理解增量？是否帮助理解今天的某个地方、生活或关系？是否可追溯到合格来源？是否留下日后可复用的资产？用户是否能不依赖作者/开发者重新写脚本而再次生产？长远是否扩大可探索的历史世界而没有污染其可信性？

战略是否达标由产品结果、真实体验和研究资产增长来衡量，不只用 D/L/G 管线的技术 PASS、模型调用次数、页面数量或仓库提交量衡量。指标和实验可以在下游文档定义，但不得更换这些判断的上位意义。

**设计任务的战略传递要求**：凡以五图、模块或前端UI为输入的体验专项，必须在进入页面设计前说明其如何同时支持“EXP连续发现的体验价值、Studio真实研究及资产积累、WATCH有价值的作品消费”，并将长期目的、近期建设顺序与用户路径分列核验；不得把“有三种模式入口”“能播放作品”“能输出聊天回答”当作这些价值已实现。

### 战略目标与专业上下文的分界

“用户只需自然语言委托研究”是产品目标；不意味着所有操作自动变成 Agent Skills、也不意味着取消已有生产 Stage Owner。工程维护、可信生产、Studio 创作与公众探索分属不同授权上下文；能力体系必须适应这一产品目标，同时遵守既有知识与版权资格。此为 R1/R3 已定职责框架的战略接口，不在 MHKA-01 再定义 Skill 细则。
