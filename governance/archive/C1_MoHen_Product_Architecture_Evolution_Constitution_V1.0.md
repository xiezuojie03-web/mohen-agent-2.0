# 0｜执行摘要：墨痕最终要成为怎样的产品

|                           |
| ------------------------- |
| 在广阔的历史文化中，重新发现当下生活的意义与乐趣。 |

墨痕帮助人从历史文化中发现与当下生活的连接。它把散落在典籍、地方、遗址、人物、器物、地图、考古发现、历史事件与现实痕迹中的知识重新放回时间、空间与关系中，通过证据、比较、发现与人文叙事，让人不仅知道过去发生了什么，更理解这些过去为什么与今天的自己有关。

|                                                 |
| ----------------------------------------------- |
| 从历史中理解当下，在当下重新发现历史，并在两者之间寻找文化根源、人文精神、生活乐趣与个人共鸣。 |

墨痕有两层长期北极星。第一层是不会因技术更替而改变的人本价值：帮助人从历史文化中重新发现当下生活的意义、乐趣、文化根源与个人共鸣。第二层是属于这个时代的长期探索命题：AI 时代，文化如何继续“活”在人、地方与日常生活之间。AI 不是终点，也不是品牌定义；即使未来技术形态变化，第一层价值仍然成立。今天之所以选择 Agent，是因为它第一次让“可信文化世界 → 关系发现 → 动态体验 → 现实行动 → 新文化痕迹”成为可以持续运行的产品闭环。

# PART I｜WHY：墨痕为什么存在

## 2｜产品北极星与个人价值

墨痕不是为了建立一个更大的历史数据库，也不是为了给历史世界做一个数字复制品。它要建立一个“活的文化关系模型”，帮助今天的人重新发现自己与过去的连接。

时间、地理空间、地图、时间轴、知识图谱、GIS、典籍、图像、AI、Agent 都是认知与表达手段，不是产品目的。真正的终点是：过去怎样塑造今天；哪些文化痕迹仍在；为什么我们成为今天的我们；历史如何重新进入普通人的地方感、旅行、审美、生活乐趣与精神世界。

## 3｜墨痕不是什么

| **不是**     | **为什么不是**                      | **可以怎样被使用**                        |
| ---------- | ------------------------------ | ---------------------------------- |
| 历史百科 / 内容站 | 知道更多不是最终价值                     | 作为 Source / Evidence / Context     |
| 历史地图产品     | 地图只是空间认知工具                     | 作为重要 Experience Surface            |
| 数字孪生历史世界   | 无法也没必要复制全部过去                   | 建立可信、可发现的文化关系世界                    |
| 旅游攻略       | 行动是理解之后的自然延伸                   | Route / Field Experience           |
| 知识图谱产品     | 结构关系不等于文化意义                    | 作为 Cultural World 的一种结构            |
| 聊天机器人      | 聊天不能代表 Agent-native Experience | Dialogue 只是 Presence 的一种状态         |
| GIS 工具     | 空间精度不等于历史真实性                   | Spatial reasoning / geometry claim |
| AI 内容生成器   | 生成量不等于文化价值                     | 辅助研究、重建、表达，必须有边界                   |

## 4｜用户真正经历的主链

|                                                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 当下地点 / 生活问题 / 兴趣 / 人物 / 器物 / 典籍 / 历史线索 → 墨痕理解探索意图 → 调用证据与文化世界 → 放回时间与空间 → 纵向追溯 / 横向比较 / 跨地域与同时代关联 → 发现关系与变化 → 组织地图、时间、图像、史料与叙事 → 用户追问与 Replan → 回到今天的观察、理解、旅行、行动或进一步研究。 |

用户不是来完成“学习任务”，而是来发现。墨痕要允许好奇心先于知识体系：从一座桥、一条河、一张旧图、一句典籍、一个地名、一个今天的生活疑问进入，然后让世界逐渐展开。

## 5｜核心产品承诺

| **承诺** | **意味着什么**                   |
| ------ | --------------------------- |
| 可信     | 关键判断可追溯；不知道就承认不知道           |
| 可发现    | 不是检索已知答案，而是找到值得继续追的关系       |
| 可理解    | 把复杂知识放回时间、空间、比较与关系中         |
| 可共鸣    | 最终连接今天的地方、生活、文化根源与个人经验      |
| 可继续    | 追问让同一世界展开，而不是每轮从零开始         |
| 可行动    | 理解可以自然转成观察、行走、阅读、旅行或研究      |
| 可生长    | 世界能跨主题/地域扩展，长期还可接受受治理的新文化痕迹 |

# PART II｜WHAT & HOW：墨痕靠什么系统成立

## 6｜总体系统：Stable World, Dynamic Experience

墨痕的底层世界必须相对稳定、可审计；面向人的体验必须根据问题动态组织。不能为了更“聪明”的界面让 Agent 随意改写 Truth，也不能为了数据库稳定把用户困在固定页面。

|                                                                                  |
| -------------------------------------------------------------------------------- |
| Stable Truth / Cultural World → Agent Judgment → Dynamic Experience Composition。 |

| **系统层**                       | **长期职责**                                                                                       | **专业分册**            |
| ----------------------------- | ---------------------------------------------------------------------------------------------- | ------------------- |
| Research / Production         | 把原始资料变成可治理的证据、对象、关系、意义候选                                                                       | C2                  |
| Truth & Cultural World        | 保存 Evidence、Object、Relation、Meaning、Present Connection 等稳定世界                                   | C3                  |
| Agent Read / Discovery        | 为 Agent 提供可推理、可发现的 World Projection                                                            | C2 + C3             |
| Agent Runtime                 | Sense→Understand→Goal→Plan→Act→Observe→Evidence Gate→Discover→Experience→Confirm→Memory→Replan | C2                  |
| Experience                    | ExperienceState / CompositionState / Controlled Surfaces / Presence                            | C4                  |
| Human / Field / Participation | 把线上发现重新带回现实生活，并长期形成受治理的新痕迹                                                                     | C1 长期演化 + C3 future |

## 7｜Humanistic Data OS：世界不是内容库

Humanistic Data OS 是墨痕共享、可增长的世界底座。它不是某个数据库产品名，而是从 Raw Source 到 Evidence、Humanistic Object、Cultural Relation、Meaning、Discovery、Experience 的统一生产与消费逻辑。

Developer Skills 是“造世界的方法”：研究、清洗、证据链、关系发现、空间研究、故事与体验编排等；Agent Skills 是“在世界里行动的方法”：空间探索、时空追踪、关系发现、典籍发现、证据核验、故事编织、体验编排、当下连接。两者必须分权：Developer Skill 可以在 Gate 与审计下写 Truth Store；Agent Skill 默认读取受控 World Projection。

## 8｜Evidence & Knowledge Constitution

  - Evidence before Knowledge：先回答“凭什么”，再把判断提升为知识。

  - Fact–Interpretation Firewall：事实、关系、意义、当代解释必须分层。

  - Geometry is a Claim：历史空间/几何同样需要来源与置信边界。

  - Historical Space ≠ Historical Geometry：知道“在哪里/与谁相关”不等于拥有精确历史坐标。

  - Source Type ≠ Perspective：来源类型、作者/编者、制度位置、叙事视角、后世解释不可混成一个字段。

  - Conflict Honesty：来源冲突不是脏数据，应结构化保存并克制表达。

  - AI Generation ≠ Evidence：AI 生成图文不能自动成为文化证据。

## 9｜Living Cultural World：关系必须有文化意义

对象数量不是世界深度。1000 个 POI 加 located\_in 关系仍可能是死的；少量对象如果拥有事件、变化、人物、制度、文本、实践、意义与今天的连接，就能形成 Living Cultural Relation Cluster。

|                                                                                           |
| ----------------------------------------------------------------------------------------- |
| Structural Relation 回答“它们怎么连”；Cultural Relation 还要回答“为什么这个关系帮助我们理解历史中的生活世界，以及为什么今天值得继续看”。 |

最小有效链可以是：Entity → Event → Relation → Change → Meaning → Present Connection。它必须能够被 Evidence Gate 支撑，并能进入 Discovery 与 Experience，而不是只停在数据库里。

## 10｜Agent-native Product Architecture

Agent 不是固定页面上的附加聊天能力。它的核心职责是：理解用户此刻真正想追什么，在可信世界中判断下一步值得组织什么，并让判断通过 ExperienceState / CompositionState 改变用户眼前的世界。

| **Agent 能力**             | **产品意义**                 |
| ------------------------ | ------------------------ |
| Sense / Understand       | 理解当前问题、地点、时间、用户行为与已有探索   |
| Goal / Plan              | 形成当前探索目标，而不是关键词检索        |
| Act / Tool / Skill       | 调用受控工具与 World Projection |
| Evidence Gate            | 决定哪些内容可以怎样表达             |
| Discover / Synthesize    | 发现值得继续追的关系、对比、变化、人文角度    |
| Experience Orchestration | 决定地图、时间、图像、证据、叙事谁成为主角    |
| Observe / Replan         | 用户追问/跳过/移动地图后继续调整        |
| Modern Connection        | 把历史重新连接今天的观察、生活与行动       |

|                                            |
| ------------------------------------------ |
| 真正的复杂度不是 UI 有多少组件，而是：墨痕凭什么知道下一步应该把什么组织到一起。 |

## 11｜Human Experience Constitution

C4 已冻结金泽《历史关系探索体验板》与 EXP-DESIGN-02 Round 2 为 Canonical Experience / Visual Baseline。未来 UI 可以改变形式，但不能在体验质量上低于基线。

  - One Moment, One Focus。

  - Show → Question → Reveal。

  - Space Before Text。

  - Evidence on Demand。

  - Agent Changes the World。

  - Patch-not-Replace。

  - Return to Present。

  - Canonical Non-Regression：未来体验只能在基线之上继续生长。

|                                                                 |
| --------------------------------------------------------------- |
| Human Experience Gate：这段过去有没有让用户重新看见今天？P1 重新看见；P2 与我有关；P3 继续行动。 |

## 12｜从 Experience 到 Participation / Living Culture

长期闭环不能停在“用户看完一个故事”。当理解真正进入生活，人会去观察、行走、比较、阅读、记录、分享、策展、贡献或重新实践。墨痕未来要研究的是：这些当代行为怎样形成新的文化痕迹，又怎样在不破坏历史真实性的前提下进入长期文化世界。

| **长期层**           | **可能内容**                                  | **当前态度**                                       |
| ----------------- | ----------------------------------------- | ---------------------------------------------- |
| L6 Participation  | 观察、行走、个人探索轨迹、记录、贡献、策展、分享                  | Vision 已成立；产品形态 HOLD                           |
| L7 Living Culture | 当代实践、地方记忆、新文化痕迹、受治理的回流                    | Vision 已成立；Schema / Community Engineering HOLD |
| Governed Re-entry | Provenance + Evidence Gate + Human Review | 长期硬边界                                          |

# PART III｜EVOLUTION：墨痕怎样从今天长成最终形态

## 13｜演化原则：体验驱动世界增长

墨痕不追求先把全世界历史数据做完，再开始产品体验。每一阶段都必须用真实体验暴露真实缺口，再最小补齐 Data / Visual / Spatial / Runtime。

|                                                                                                                                          |
| ---------------------------------------------------------------------------------------------------------------------------------------- |
| Experience Gap → Minimal Enrichment → New Capability → Human Validation → Generalization。不是 Data Factory → More Data → Hope for Product. |

因此，没有 DATA\_GAP 不启动大规模 World Enrichment；没有 SPATIAL\_GAP 不扩 GIS；没有 Runtime Blocker 不扩 Agent Runtime；没有真实用户信号不提前建设通用社区。

## 14｜长期 Evolution Horizons：成熟度地平线，而不是固定排期

以下七层为长期阶段地平线（H1–H7），不把未来伪装成已经确定的线性路线。H1–H2 是当前已知事实；H3–H4 是高置信方向；H5–H7 是需要真实用户与文化实践证据才能逐步确认的长期假设。后层可以被重排、合并甚至取消，但不得绕过前层 Gate。

| Horizon                                       | **目标**                                                      | **状态/出口**                                                                               |
| --------------------------------------------- | ----------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| H1｜Trusted World & Agent Runtime              | 建立 Evidence-aware World + Multi-Intent / Persistent Runtime | DONE：基础能力已成立                                                                            |
| H2｜Canonical Human Experience                 | 把金泽文化世界真正转成普通人可感知、可共鸣的 Agent-native Experience              | CURRENT · Human Experience Gate HOLD（数据优先阶段顺延，R18）；出口 = Human Experience PASS + Integration Gate PASS |
| H3｜Experience-driven World Growth             | 由真实体验缺口补 Data / Visual / Spatial / Research 能力              | NEXT：只补阻塞体验的最小切片                                                                        |
| H4｜Field Experience & Generalization          | 连接现实行动，并验证第二主题/地域能复用 World Model + Grammar + Gate           | FUTURE：金泽母体稳定后                                                                          |
| H5｜Human Resonance & Participation Validation | 验证谁持续使用、为什么回来、什么值得收藏/记录/分享/贡献                               | FUTURE：真实复访与参与信号                                                                        |
| H6｜Living Culture Loop                        | 让受治理的当代观察/记忆/实践形成新文化痕迹并回流世界                                 | FUTURE：Participation 证据稳定后                                                              |
| H7｜Sustainable MoHen                          | 在不牺牲产品精神前提下探索长期组织、运营与商业模式                                   | FUTURE：核心价值与忠实用户先成立                                                                     |

## 15｜商业化与增长的顺序

|                                                           |
| --------------------------------------------------------- |
| 精神价值成立 → 核心体验成立 → 找到产生共鸣的真实用户 → 验证持续使用与扩展能力 → 再探索可持续商业模式。 |

商业化属于长期架构，但不是当前优化目标。禁止用广告、流量或交易逻辑反向塑造 Cultural World、Agent 判断与 Human Experience。旅游、路线、餐饮、出版、研究服务、会员或其他模式未来都可以探索，但必须自然延伸用户已经获得的文化价值。

## 16｜Scale Architecture：金泽是母体，不是边界

金泽是 Canonical Experience 的第一实验场；上海古镇是第一批内容语境，而不是内容类型定义。墨痕未来可以进入城市、区域、中国乃至世界，也可以从地方史扩展到人物、典籍、考古、艺术、制度、思想、社会生活与跨文明比较。扩展时不复制页面，也不把“古镇”固化进底层模型；复用的是 Evidence、World Model、Discovery、Agent Skill、Experience Grammar 与 Gate。

| **尺度**          | **可能入口**           | **必须保持**                      |
| --------------- | ------------------ | ----------------------------- |
| 点 / 建筑 / 桥 / 遗址 | 现场痕迹、人物、事件、文本      | Evidence + Present Connection |
| 镇 / 街区          | 水系、产业、宗教、社会生活、空间演变 | Living Cultural Relation      |
| 城市 / 区域         | 跨地比较、制度与网络、迁徙、文化传播 | Multi-scale Relation          |
| 国家 / 世界         | 同时代比较、文明联系、全球流动    | 同一证据与解释边界                     |

- 具体阶段重心、HOLD 项与实时落点一律记在 `CURRENT.md`（状态层），不写进本宪法。

# PART V｜GOVERNANCE：哪些东西可以变，哪些不能随便变

## 21｜长期冻结原则

  - 最终价值：从历史文化中发现与当下生活的连接，并保持“生活的意义与乐趣”。

  - Evidence before Knowledge；Fact–Interpretation Firewall；Conflict Honesty。

  - Historical Space ≠ Historical Geometry；Geometry is a Claim。

  - Living Cultural World 的深度优先于对象数量。

  - Agent 不拥有 Truth；Agent 读取受控世界并通过 Gate 表达。

  - Stable World, Dynamic Experience。

  - Agent-native Experience：动态的是受 Contract 约束的体验编排，不是任意 UI 生成。

  - Patch-not-Replace / Persistent Experience。

  - C4 Canonical Non-Regression。

  - Human Gate：重新看见 / 与我有关 / 继续行动。

  - 用户贡献 ≠ 历史事实；AI生成 ≠ 文化证据；当代记忆 ≠ 自动等于历史真相。

  - 商业化不得反向破坏文化价值、Evidence 与 Human Experience。

## 22｜Architecture Reconciliation 触发器（方向 / 冻结原则级）

> 本表为**方向/冻结原则级** Reconciliation 触发器。通用治理级触发器见 **C0 §2.3**；专业域（代码/数据库/UI）触发器仅由 C2/C3/C4 在其域内列示，且**不得反向改写本表的方向/冻结原则**。三者分层、互不重复。

以下变化不能由 开发总工程师 或一次施工对话自行决定，必须提交项目拥有者确认：

  - 改变 C1 最终 Vision / Product Promise / Evolution Horizons / 演化逻辑；

  - 改变 Evidence / Truth / Interpretation / Geometry 的边界；

  - 新增或重定义 Cultural World 核心对象、关系或 Meaning 层；

  - 让 Agent 获得 Truth Store 写权限或绕过 Evidence Gate；

  - 改变 ExperienceState / Composition / Surface Contract；

  - 提出低于 C4 Canonical Baseline 的体验方案；

  - 引入 PostGIS、Vector DB、Graph DB 等会改变核心数据/推理架构的基础设施；

  - 启动 Participation / Living Culture 的正式 Schema 或通用 Community；

  - 从金泽扩展到第二主题/地域时发现现有 World Model / Grammar 无法复用；

  - 商业目标要求改变 Agent 推荐、Evidence 表达或文化内容排序。

# PART VI｜ACCEPTANCE：什么叫墨痕真的向前了一步

## 25｜多重 Gate

| **Gate**              | **回答的问题**                                    | **当前地位**   |
| --------------------- | -------------------------------------------- | ---------- |
| Evidence Gate         | 这个事实/关系/空间表达凭什么成立？                           | 长期硬门槛      |
| Runtime Gate          | Agent 是否真实理解、Replan、Patch 并保持 Contract？      | 基础已成立，持续回归 |
| Human Experience Gate | 普通用户是否感到世界因 Agent 判断而变化，并重新连接今天？             | 当前核心 HOLD  |
| Integration Gate      | 代码、证据、Runtime、Human Experience 是否同时达到合并条件？   | H2 出口      |

## 26｜最终验收标准

  - Vision：用户获得的不只是历史知识，而是对当下生活、地方、文化根源、人文精神的新理解、新乐趣或新共鸣。

  - Evidence：关键事实、关系、空间表达可追溯；未知不伪装成确定。

  - Agent：不同意图导致不同 Plan / Replan，而不是不同文案。

  - World：Agent 的重要判断改变地图、时间、关系、图像、叙事或行动状态。

  - Continuity：追问 Patch-not-Replace，Experience 与 Trail 持续存在。

  - Spatial Honesty：现代坐标、历史关系、历史地图、重建几何严格分权。

  - Human Experience：普通用户不读调试面板/长文也能理解变化；重新看见今天、感到与我有关并愿意继续。

  - Actionability：线上发现最终能连接现实观察、路线、阅读或进一步研究。

  - Scalability：换主题复用 World Model、Gate、Runtime、Experience Grammar，而不是复制页面。

  - Living Culture：长期参与如果发生，必须通过 Provenance / Evidence / Human Review 形成受治理的新文化痕迹。

# PART VII｜ARCHITECTURE MEMORY：为什么今天会这样设计

## 27｜关键架构演化里程碑

| **阶段**                                                     | **我们学到什么**                                             |
| ---------------------------------------------------------- | ------------------------------------------------------ |
| 从内容站到 Truth Store + Evidence Gate                          | AI 文化产品首先要可信，不能从“会讲故事”起步                               |
| Knowledge Weave                                            | 事实必须被组织成可推理关系，但结构关系仍不等于文化意义                            |
| Historical Space / Geometry 分权                             | 历史位置、空间关系、精确几何不是同一层级                                   |

| ExperienceState / CompositionState / Persistent Experience | Agent 应改变同一体验空间，而不是制造页面跳转                              |
| Evidence-aware Replan / Multi-Intent                       | 追问必须改变计划与世界状态，不只是换一段回答                                 |
| Runtime PASS 暴露 Human FAIL                                 | 技术正确不等于产品成立                                            |
| World Depth Stress Test                                    | 文化世界深度比对象数量更重要                                         |
| Candidate Reservoir / Runtime World / External World       | 候选资料、运行世界、外部研究必须分层                                     |
| Candidate Evidence Adjudication                            | 空间包含、同名、外部节点、解释边界必须经过证据裁决                              |

| Humanistic Data OS + Living Culture Vision                 | 最终系统从“理解过去”扩展为“AI时代文化如何继续活在人与地方之间”                     |
| Development Governance                                     | 用户不再做人肉 API；开发平台兼具实施与架构建议能力，治理从逐任务批准转向边界治理               |

## 28｜已经明确不能再走的路
