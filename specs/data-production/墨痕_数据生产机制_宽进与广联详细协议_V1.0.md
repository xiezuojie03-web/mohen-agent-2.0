## 0｜协议总则
> **核心定义**｜宽进不是“什么都抓”；广联不是“什么都连”。宽进的目标是让不同载体的历史资料都变成可定位、可读懂、可观察、可比较的 Research Material；广联的目标是在这些 Observation 之间系统地产生“值得研究的关系候选”，而不是直接产生历史事实。
| 层 | 允许的对象 | 禁止偷换 |
| 宽进 | Source、Page/Region、Observation、Mention、Visual/Map Observation | 文件标题 ≠ 内容；目录元数据 ≠ 证据；OCR 文本 ≠ 自动事实。 |
| 广联 | Signal、AssociationCandidate、Pattern、Conflict、ResearchQuestion | 共现 ≠ 关系；相邻 ≠ 历史联系；时间相近 ≠ 因果；相似 ≠ 同一对象。 |
| 精选以后 | **Research Discovery Candidate（Selected Discovery）** / Directed Research Task | 五母题开始作为解释透镜，不作为前置资料分类；**不得直接给用户**。 |
| 严证以后 | Evidence-backed Claim / Cultural Relation | 才有资格进入 Runtime Truth。 |
## 1｜当前实施范围：先把 Legacy Reservoir 读深
当前不要求立刻扩大外部抓取。第一轮验证对象是沪上经纬旧库：它已经包含 CBDB 人物、族谱索引、地方志与条目、诗词、事件、地名、文保资料、舆图目录与旧图抓取、Commons/Rumsey 图片、叙事候选与 narrative_assets 等多类资源。
压力测试的关键问题不是“能不能把旧 JSON 重新导入”，而是：能否把这些异构旧资源还原为内容级 Observation，并进一步发现原项目没有显式表达过的关联。
> **当前阶段出口**｜Legacy Stress Test 成功标准：至少形成一批“旧库原 relation/story 中没有直接写明，但由多源观察或非平凡模式触发、值得补证”的 Discovery Candidate。
# PART I｜宽进 Broad Intake
## 2｜宽进的四层合同
Source Discovery：AI 知道去哪一类资料中找，不把所有问题都交给通用网页搜索。
Source Acquisition：保留原始载体、版本、页码/图号/时间码/区域、权利和访问状态。
Content Reading：真正读取载体内容。文本要读句段；地图要读图；图片要读画面；表格要读行列；扫描书影要读页与区域。
Observation Transformation：把“看见了什么”转成可关联 Observation；Observation 仍不是 Claim。
## 3｜所有资料共用的 AI 搜寻上下文包
任何一次搜寻前先生成 Search Context Pack，避免 AI 用一个地名做宽泛搜索。Context Pack 是检索控制器，不是历史结论。
| 维度 | 内容 | 例 |
| 核心范围 | 地点/人物/器物/事件/主题、允许的空间尺度与时间范围 | 金泽镇 / 某桥 / 宋元至近代；不自动扩成整个江南。 |
| 名称簇 | 标准名、旧称、俗称、异体字、行政归属变化、外文/拼音变体 | 由已有 Source 与地名表生成，所有别名带来源。 |
| 行动词 | 建、修、迁、毁、运、售、祭、游、居、任职、通行、停泊、交易、学习等 | 行动词用于发现活动关系，不等于谓词已成立。 |
| 机构/功能词 | 寺院、会馆、仓储、桥梁、水运、市场、学校、官署、行业等 | 用来扩展“对象—活动—制度”检索。 |
| 时间表达 | 朝代、年号、民国/公历、约略年代、事件前后 | 保留模糊时间，不强制换成单年。 |
| 资料体裁词 | 志、图、谱、碑、录、记、集、报、档案、调查、考古、文保、照片、明信片等 | 用于精准锁定载体，而不是只搜主题词。 |
| 已知锚点 | 已有高置信对象、事件、来源、坐标/水系/机构 | 用于二跳检索和消歧。 |
| 开放问题 | 当前不知道什么 | 搜索任务必须服务于问题或扩大候选世界；不把“资料越多”当目的。 |
## 4｜AI 精准搜寻的 Query Matrix
AI 不生成单一查询，而生成“名字 × 时间 × 行动/功能 × 资料体裁 × 关系对象”的查询矩阵。执行时先精确锚点，再扩展同义/旧称，再做跨源二跳。
| 检索轮 | 模板 | 目的 |
| Q1 精确锚点 | “{对象标准名/旧称}” + {体裁词} | 确认对象在某一类来源中的直接出现。 |
| Q2 活动扩展 | {对象/地点} + {行动词/功能词} + {时期} | 从“存在”转向“人在做什么、对象起什么作用”。 |
| Q3 关系对象扩展 | {对象A} + {对象B/机构/人物/水系} + {时期} | 验证/发现两端是否存在显式或间接呼应。 |
| Q4 体裁反向检索 | {地方志卷目/专题章节/图名/馆藏类目} → 搜索对象 | 让资料结构引导发现，而不是只用已知关键词。 |
| Q5 二跳发现 | 从新发现的人名/地名/作品/机构反向搜索其他来源 | 扩大候选世界，寻找跨源呼应。 |
| Q6 冲突检索 | {对象/事件} + 异名/异说/旧址/迁建/重修/考证 | 主动寻找反证与不同传统。 |
> **防止再次窄进**｜禁止把五母题写进 Q1–Q6 的必填条件。母题可以在候选已经出现后用于“追问得更深”，但不能让搜索引擎只去找符合某个母题的资料。
## 5｜历史资料分类与载体转换协议
以下分类按“载体如何被读取与转成 Observation”组织，而不是按学科主题组织。一个 Source 可同时属于多种语义用途，但原始身份保持唯一。
| 类型 | 典型载体 | 宽进后的最小形态 | 主要关联价值 |
| T01 地方志/地方文献 | 县志、镇志、府志、乡土志、地名志、行业志等 | 卷目结构 + 原文/书影 + 条目位置 | 人物、地点、建置、物产、风俗、事件、制度、沿革的高密度综合源 |
| T02 古籍/文集/诗文/笔记/游记 | 文集、诗词、笔记、日记、游记、题记等 | 文本片段 + 作者/时代/作品语境 | 人物—地点—活动—感知与文化表达 |
| T03 档案/契约/账册/族谱/碑刻 | 公文、契约、账簿、名册、谱牒、碑记、题刻 | 记录级/行级/碑文区段 | 活动链、交易、制度执行、人物网络、修建/捐资/迁徙 |
| T04 报刊与近现代文献 | 报纸、杂志、广告、通讯、调查 | 日期/版面/栏目/文章片段 | 事件、行业、交通、社会生活与变化节点 |
| T05 现代研究/文保/考古报告 | 论文、专著、文保档案、测绘、考古简报 | 论断 + 引证 + 图表/测绘位置 | 解释候选、考证、年代、构件、机制；必须区分作者解释与原始证据 |
| T06 古代舆图 | 方志图、城图、山水舆图、河防图、驿路图等 | 地图整体 + 标签 + 符号 + 拓扑观察 | 空间关系、视觉层级、命名、路径/水系/边界线索；不自动等于精确 GIS |
| T07 近现代测绘/地籍/规划图 | 测绘图、地籍图、航运/交通图、规划图 | 坐标/比例/图例 + 要素 | 较强几何约束、变化对照、空间锚点 |
| T08 历史照片/明信片/影像 | 老照片、明信片、新闻摄影、航拍 | 画面对象 + 活动 + 视角 + 文字 + 时间 | 可见空间、生活活动、构件、环境、同景对照 |
| T09 绘画/版画/插图 | 风俗画、山水画、书籍插图、宣传画 | 画面语义 + 作品类型/目的 | 生活场景与文化想象；需警惕写意/程式化 |
| T10 器物/博物馆/考古图版 | 器物照片、铭文、标本、出土图版 | 对象属性 + 铭文/出土语境 + 视觉细节 | 物—人—制度—贸易—工艺—地方网络 |
| T11 现代现场与现状资料 | 现场照片、街景、航拍、文保现状、观察记录 | 今日对象 + 状态 + 可达/视角 + 时间 | Present Connection、遗存/复建/使用状态；不反推历史 |
| T12 结构化数据库/目录/开放数据 | CBDB、馆藏目录、地名/文保清单、开放 API、旧项目 JSON | 字段级记录 + provider/provenance | 高效率生成 Lead/Identifier/别名/索引；目录元数据本身通常不是 Evidence |
| T13 口述/记忆/活态文化（长期） | 访谈、社区记忆、实践记录 | 讲述者 + 时间 + 语境 + 同意/权利 | Living Culture / Memory；记忆存在与历史事件发生分开 |
| T14 旧项目 Story/StoryChapter/叙事资产 | 沪上经纬已上线故事、章节、人工候选、narrative_assets | 叙事陈述拆回对象/观察/来源线索 | 作为高价值 Research Lead；不能因曾上线就直接成为新 Truth |
### 5.1 T01 地方志：从“有一本书”到“可关联的条目网络”
地方志是墨痕最重要的综合载体之一，但“书名/目录命中”不能算完成。AI 必须先识别版本、卷目结构和相关门类，再进入页/条目级读取。
| 情况 | 处理协议 | 可进入关联池的产物 |
| 已有可靠全文 | 保留原文与版次/卷页定位；按条目/段落切 Observation；抽取人物、地点、机构、活动、时间、对象用途、变化词和限定词。 | TextObservation + Mention + Action + Time/Place Scope。 |
| 只有 PDF 书影，无可用全文 | ①保留原 PDF；②做页级类型识别（封面/序/目录/正文/图版）；③先读目录定位可能卷页；④对相关页做视觉布局理解；⑤按区域转写/摘要；⑥保存 page+region 定位与难字/不确定字符；⑦只对相关区域做语义抽取。 | ImageRegionObservation；转写文本是派生层，原书影区域仍是根锚点。 |
| OCR 很差 | 不得为了“全文化”制造大量错误文本。使用图像阅读 + 局部转写；保留 unreadable/uncertain；重要句人工复核。 | 部分 Observation + 明确缺口。 |
| 只有目录/题名/索引 | 登记为 Source Lead / Catalog-only，不创建“证据片段”；利用目录结构生成下一步取得正文的任务。 | SourceLead + AcquisitionTask。 |
地方志关联发现优先读取“建置沿革、桥梁水利、人物、寺观、风俗、物产、艺文、灾异、交通、镇市”等条目之间的交叉，而不是把卷目分类本身当作历史关系。
### 5.2 T06 古代舆图：必须“读图”，不能只认标题
舆图进入 Reservoir 后，AI 的第一任务不是配准，而是解释“这张图在表达什么空间世界”。地图的绘制目的、图式传统、方向/比例可靠性和符号语法决定它能支撑到什么程度。
| 读取层 | AI 必须产出 | 禁止 |
| 地图身份 | 题名、作者/编绘者、年代、来源、图幅/页码、地图类型、可能绘制目的 | 只保存标题和缩略图。 |
| 图面语义 | 方向、比例/测绘性判断、图例/符号、文字标签、题跋、边界、道路/水系/桥/聚落/寺观/官署等可见要素 | 把所有线都当道路，把装饰性山水当真实地貌。 |
| 拓扑观察 | 谁在谁旁、谁跨越谁、上下游/内外/沿线/围合/节点/中心等关系；标记“图上可见”与“现实推断” | 用现代坐标直接替代图中关系。 |
| 几何资格 | global/local registration / anchor / reconstruction / original-map narrative 的资格与理由 | 证据不足时强行全图 GIS 配准。 |
| 可关联单元 | MapLabelObservation、MapFeatureObservation、MapTopologyObservation、MapAnnotationObservation | 仅产生 visual_asset，不产生内容观察。 |
### 5.3 T08/T09 图片与绘画：进入库前先通过“内容级理解”
视觉资料不能再以“标题像相关”“文件名含地名”作为主要入库标准。任何进入 Association Pool 的图片，必须至少有一份 Visual Observation。
| 字段组 | 至少要读懂什么 |
| 身份 | 来源、作者/摄影者、创作/拍摄时间、描绘时期、权利、原始定位。 |
| 画面对象 | 可辨人物/建筑/桥/河/街巷/器物/标识；无法确定身份时只记“候选/类型”，不强认。 |
| 活动与关系 | 人在做什么、对象如何被使用、物如何移动、谁与谁同框、空间如何组织。 |
| 空间与视角 | 拍摄/观看方向（若可判断）、前后景、岸/桥/街关系、同景锚点候选。 |
| 图中文字 | 招牌、题记、碑铭、说明、印章等区域；保留区域定位和不确定字。 |
| 证据身份 | “图中确实可见”与“根据标题/馆藏说明得知”分开；创作性绘画与纪实照片分开。 |
| 叙事资格 | 是可当主角的原件、仅可辅助说明、还是只有目录价值；不合格图片不进入体验资产池。 |
> **图片宽进 Gate**｜视觉验收红线：100% 进入 Association Pool 的图片必须有内容级 Visual Observation；只有标题、文件名、自动标签而没有画面阅读的图片，只能停留在 Source Lead / Asset Pending。
### 5.4 T03/T04 记录型材料：优先抽取“动作”而不是只抽实体
档案、契约、账册、谱牒、碑刻、报刊的核心价值通常不是“又出现了一个人名”，而是它们留下了行为、角色、顺序、数量、地点、制度约束和变化。AI 抽取时必须保留 action/event 结构。
| Observation 类型 | 例示结构 |
| ActionObservation | actor / action / object / from / to / purpose / time / place / quantity / role / source_locator |
| TransactionObservation | party_A / party_B / item / amount / transfer / place / time / condition |
| InstitutionObservation | rule / institution / affected_actor / applicable_scope / time / observed_effect |
| ChangeObservation | subject / before_state / after_state / trigger_or_recorded_event / time / evidence_scope |
| GenealogyObservation | person / kinship / residence / office / migration / generation / source_scope |
### 5.5 T05 现代研究：把“作者解释”与“作者引用的史料”分开
论文、专著、文保与考古报告非常适合形成 Meaning/Mechanism Lead，但不能把研究结论自动当成原始历史记录。若研究者给出了明确引文/图表/档案号，应分别建立“研究者解释 Observation”和“被引原始来源 Lead”。
研究结论可以作为 Interpretation Candidate / Evidence Lead；进入事实层时仍检查其引证。
考古/文保报告的测量、年代判断、构件记录可形成高价值 Observation，但要保留调查时间和方法。
二手研究之间的分歧应形成 Conflict / Competing Interpretation Candidate，而不是强行合并。
### 5.6 T12 结构化数据库：先恢复“字段语义”和“原始来源依赖”
CBDB、开放目录、旧项目 JSON 等具有高结构化优势，但必须识别它们是“原始事实数据库、二次索引、目录、抓取缓存还是旧项目生成物”。不同性质决定它们只能产出 Lead、Observation 还是可进一步核验的 Evidence。
> **Legacy 专项修正**｜当前 Legacy Reservoir 应先按“来源性质 + 原始载体来源 + 可读内容程度”重新分类，而不是让所有 JSON 一律以 source_record → evidence stub → entity candidate 的同一方式处理。
## 6｜宽进后的统一 Observation Contract
不同载体最终都转成 Observation，但 Observation 保留模态差异。它记录“材料中看见/读到什么”，而不是“历史世界一定是什么”。
| 字段 | 含义 |
| observation_id | 稳定身份与版本。 |
| source_id + locator | 必须回到原 Source 的页/段/图号/时间码/区域。 |
| modality | text / map / image / table / object / audio / field 等。 |
| raw_excerpt_or_region | 原文摘录，或图像/地图区域引用；不能只留摘要。 |
| normalized_observation | 克制归纳“材料中出现/描绘/记录了什么”。 |
| mentions | 人物、地点、机构、器物、文本、建筑等 Mention；尚未 Resolution 也可保存。 |
| actions_events | 动作、事件、用途、状态变化；允许为空。 |
| time_scope / place_scope | 材料中明确或可推定的时间/空间，并区分确定、约略、未知。 |
| relation_signals | 显式谓词、拓扑、共现、顺序、角色、同名/别名等信号。 |
| qualifiers | 否定、传闻、据说、或然、范围限定、作者视角等。 |
| extraction_method + uncertainty | AI/规则/人工；不确定字符、视觉识别或实体消歧问题。 |
| **association_readiness** | 能否进入广联：`ready` / `limited` / `catalog_only` / `unreadable`。**禁止使用 `usable` / `published` / `verified` 等 Truth 资格词**（主协议 §1.3；C3 §2.9）。 |
## 7｜宽进验收标准
| Gate | 通过标准 |
| W1 来源完整 | 进入 Reservoir 的 Source 100% 有 provider/版本或取得时间/原始位置/权利或使用状态。 |
| W2 内容读取 | “已处理”必须意味着读取到内容层；catalog-only 单独计数，不能混入 Evidence 数。 |
| W3 定位可回溯 | 所有可关联 Observation 都能定位到页、段、图、区域、时间码或结构化记录 ID。 |
| W4 多模态真实读取 | 进入关联池的地图和图片 100% 有 Map/Visual Observation；禁止标题识别替代读图。 |
| W5 扫描资料降级诚实 | PDF 书影 OCR/转写失败时保留区域图像和 uncertain，不制造伪全文。 |
| W6 Observation Yield | 每批统计“Source → 有内容 Observation”的转化率；无产出要有原因分类，而不是补一条空 Evidence。 |
| W7 旧叙事回拆 | 旧 Story/StoryChapter 只作为高价值 Lead，必须能追到它依赖的旧 Source/Observation，追不到则保持待查。 |
# PART II｜广联 Association Discovery
## 8｜广联的目标对象：先生产 Signal，再生产 Candidate
广联层不直接写 Cultural Relation。它在 Observation Graph 中寻找信号，并把多个信号组合成 Association Candidate。Candidate 必须能回答“为什么被连起来”“哪些材料支持这个候选”“哪里可能只是巧合”“下一步怎样验证”。
| 阶段 | 对象 | 典型内容 |
| Signal | 单一关联信号 | 同段共现、同一活动、同一水系、时间连续、同名、图文对应、冲突等。 |
| Association Candidate | 多个 Signal 组合的候选关联 | A—活动—B；A/B 在独立来源反复共现；地图与照片指向同一对象；多个状态形成变化链。 |
| **Research Discovery Candidate** | 被判断为“值得追”的研究发现（**Developer-side，严证之前**） | 含 humanistic why、缺口、下一次检索方向、可能的五母题解释透镜。**与 Agent-side 的 Runtime Discovery Candidate 同名歧义已由 C2 §4.4 分离。** |
| Directed Research Task | 针对高优先 Discovery 的补证任务 | 找原文、核对象、核年代、找反证、取得原图、核现场。 |
## 9｜Observation Graph：广联的计算底座
以 Observation 为中心建立“研究图”而不是直接建立 Truth Graph。节点可包含 Mention、Resolved Entity、Action/Event、TimeScope、PlaceScope、Source、MediaRegion；边仅表示“在某 Observation 中共同出现/参与/描绘/定位”，不自动升级为历史事实。
> **双图原则**｜Truth Graph 保存已经证成的世界；Observation Graph 用来寻找可能的世界。两者不能混为同一张图。
## 10｜关联候选生成算法（第一版）
| 算法 | 具体做法 | 产出边界 |
| A01 显式谓词抽取 | 从句段/记录中抽 subject–action/predicate–object，并保留角色、方向、限定时间。 | 高价值种子；仍需实体对齐和 Evidence 范围检查。 |
| A02 跨源共现 | 同一对象对在独立来源/不同载体中重复出现；按窗口距离、来源独立性、实体稀有度加权。 | 发现“为什么总一起出现”的研究问题；单一来源重复不计独立支持。 |
| A03 时间重叠/序列 | 计算对象/事件有效期重叠；检测 before→event→after、迁移/重修/停用等序列。 | 形成关系有效期或变化链候选；时间相近本身不产生因果。 |
| A04 空间拓扑 | 从地图/文本/几何中识别 contains、crosses、adjacent、along、upstream/downstream、same_waterway、inside/outside 等。 | 优先拓扑与功能空间；纯 near 只做弱信号。 |
| A05 行动链/物的流动 | 将多条 ActionObservation 按 actor/item/role/from/to/time 串接；前一动作输出与后一动作输入吻合时形成链。 | M1/M3 的高价值入口；不得自动补未知道路。 |
| A06 机构/制度作用链 | 规则/机构 → 受影响行动者 → 行动变化 → 地方/对象状态。 | 形成机制候选；“制度存在”不等于实际产生效果。 |
| A07 跨模态共指 | 文本名/别名 + 时间相容 + 空间相容 + 图像/地图可见特征共同匹配。 | 把方志↔舆图↔照片↔今日现场放入同一候选组。 |
| A08 结构模式/聚类 | 在研究图上找 community、hub、bridge、反复三元组/链、同类设施集中与例外。 | M2 入口；必须同时保留观察范围和覆盖缺口。 |
| A09 变化链 | 同一对象/关系的多时点状态 + 事件/工程/制度记录串联。 | M4/M5 入口；离散两点不自动形成连续历史。 |
| A10 冲突/异说发现 | 同一 subject+attribute/relation 出现不同值、不同身份、不同位置、不同时间。 | 冲突本身成为 Discovery Candidate，不偷偷多数投票。 |
| A11 跨地域/同时代比较 | 把内部模式与其他地点/同一时期同类记录比较，识别相似、差异与传播/网络线索。 | 只作为比较候选；相似性不能推出影响关系。 |
| A12 历史—今日痕迹对齐 | 历史对象/活动/关系与今日位置、名称、构件、功能、实践、记忆分别对齐。 | Present Connection / M5；每个承接维度分开。 |
## 11｜具体评分：Association Value Score（AVS）
AVS 用于“值得不值得继续查”，不是历史真伪概率。第一版采用 100 分加权，可在 Legacy Stress Test 后校准。
| 分量 | 初始权重 | 评分说明 |
| Cross-source independence | 0–18 | 是否来自真正独立的来源/载体；转引链只算一个来源传统。 |
| Semantic specificity | 0–12 | 是否有具体动作/角色/属性，而不是“相关”“提及”。 |
| Temporal coherence | 0–10 | 时间是否相容、有效期是否明确、序列是否合理。 |
| Spatial/topological coherence | 0–10 | 是否存在有意义的空间拓扑/同一水系/范围关系，而非纯距离。 |
| Action / mechanism signal | 0–15 | 是否出现人的行动、制度作用、物的流动、用途或状态改变。 |
| Cross-modal reinforcement | 0–10 | 文本、地图、图像、表格/现场是否相互指向同一问题。 |
| Novelty / non-triviality | 0–10 | 是否超出旧库已有 explicit relation/story；是否能改变原有理解。 |
| Humanistic potential | 0–8 | 是否可能进入人的生活、地方结构、处境、生成、延续或其他有意义问题。 |
| Researchability | 0–7 | 缺口是否明确、是否存在可执行的下一步检索/核验。 |
| Noise penalty | 0 到 -25 | 泛化地名、高频公共对象、同源重复、title-only、near-only、embedding-only 等扣分。 |
初始分层建议：AVS < 35 仅保留 Signal；35–54 为 AssociationCandidate；55–69 可进入 Discovery Review；≥70 为 Priority Discovery。显式高特异关系可绕过总分进入 Review，但仍不得绕过 Evidence Gate。
## 12｜几个关键算法的更具体计算规则
### 12.1 跨源共现评分
对对象 i、j，按独立 Observation 求和：CoOccur(i,j)=Σ SourceIndependence × WindowWeight × RarityWeight × ContextSpecificity。
SourceIndependence：独立原始来源=1.0；明确转引/复制=0.2–0.4；同一抓取文件重复=0。
WindowWeight：同一句/同一表行 > 同段 > 同页 > 同章 > 同书；地图同一区域、图片同一场景可定义等价窗口。
RarityWeight：高频泛词（“上海”“桥”“寺”）按 IDF 降权；具体人名、旧地名、罕见机构升权。
ContextSpecificity：若共现同时伴随动作、角色、方向、用途或事件词，升权；纯名单共现降权。
至少两个真正独立来源，或一个来源中出现明确动作谓词，才允许升级为 Discovery Review。
### 12.2 跨模态对齐评分
MultiModalAlignment = 0.30 名称/别名 + 0.20 时间相容 + 0.25 空间/拓扑相容 + 0.15 可见特征/文字匹配 + 0.10 来源说明一致。
任何单一维度不能独立确认同一对象。尤其“图片标题相同”“地图上位置看起来差不多”只能形成 suspected alignment。confirmed alignment 仍需可审计依据。
### 12.3 行动链发现
从每条记录抽 actor / action / object_or_item / from / to / time / purpose / role。
若 Observation A 的 item/actor/to 与 Observation B 的 item/actor/from 在同一时间窗相容，则建立 chain_signal。
把链中的对象角色化：起点、交接点、存储点、许可点、终点等；角色仅在当前活动范围内成立。
若链条跨两个以上独立来源，产生 DiscoveryCandidate；若只有同一记录的多个动作，仍可形成局部 ActivityRelation Candidate。
路线/道路只有在另有道路/航道证据时生成；行动顺序 ≠ 几何路径。
### 12.4 结构/格局发现
先固定观察范围与纳入规则，再计算数量、密度、聚类、网络中心性或反复组合。算法必须显式输出“覆盖缺口”和“例外对象”；缺范围、缺分母、跨时代混杂时只生成“可能的结构信号”，不能生成格局结论。
## 13｜五母题在广联中的正确介入点
五母题不参与最初 Candidate Generation 的准入，而在候选形成后作为多标签“解释透镜”。同一 Discovery 可同时具有多个 lens potential。
| 透镜 | 对候选追加的问题 | 不是 |
| M1 | 这里是否存在由活动组织起来的对象关系？ | 关系候选的唯一类型。 |
| M2 | 大量局部信号是否形成有范围的结构/分布？ | 所有空间关系都必须归入 M2。 |
| M3 | 对哪个行动者而言，目的/限制改变了地点角色？ | 强制给每条关系加人物故事。 |
| M4 | 哪些阶段/机制改变了后续状态？ | 看到时间先后就认定因果。 |
| M5 | 历史与今天在哪些维度承接、变化或中断？ | 只要有古今图片就进入 M5。 |
> **母题防窄化规则**｜母题 Lens Score 只能表示“这个关联从哪个问题切入可能更有解释力”，不得被解释为历史可信度，也不得成为搜索入口的硬筛选条件。
## 14｜AssociationCandidate 最小合同
| 字段 | 要求 |
| candidate_id | 稳定身份与版本。 |
| seed_observations | 所有触发本候选的 Observation IDs；不得只留总结。 |
| association_type | explicit / cooccurrence / action_chain / temporal / spatial / multimodal / pattern / conflict / comparison / present_trace 等。 |
| objects_or_cluster | 候选两端或多节点簇。 |
| generation_method | A01–A12 及参数/模型版本。 |
| supporting_signals | 每个信号的来源、时间、空间、动作、独立性。 |
| counter_signals | 冲突、身份歧义、时间不相容、来源依赖等。 |
| avs_components | 各分量评分；非 Truth confidence。 |
| why_interesting | 为什么值得继续追；必须是具体问题，不得写“具有研究价值”。 |
| motif_lenses | M1–M5 及其他解释方向，可多选/为空。 |
| missing_evidence | 缺什么才能证成/否定。 |
| next_search_tasks | 下一次精准检索模板和目标来源类型。 |
| status | 研究态 disposition：`signal` / `candidate` / `review-worthy` / `selected` / `paused` / `rejected` / `promoted_to_research`（主协议 §1.3）。**不得出现 `usable` / `published` / `verified`。** |
## 15｜广联反噪声规则
| 噪声 | 处理 |
| 同一文件/同一抓取缓存重复 | 去重后只算一次来源信号。 |
| 二手文章都转引同一地方志 | 建立 source_dependency；不把 5 篇转引当 5 个独立支持。 |
| mentioned_in / belongsTo / same_source | 只作结构索引，不计高价值 Cultural Relation。 |
| near / 同一镇 / 同年代 | 只能作弱信号；没有活动/功能/结构机制时不得升级。 |
| Embedding 相似 | 只能用于召回候选，不可独立生成关系。 |
| 标题/文件名相似 | 只生成 Source Lead；不能当 Visual/Text Observation。 |
| 大地名/高频人物造成超级节点 | IDF 降权；必要时按具体活动/时期/子地点切片。 |
| 旧 Story 自己的内部引用 | 先回拆原始来源；Story 与其衍生数据不算独立多源。 |
| 模型常识补关系 | 允许生成“外部待查假设”，但不得混入 legacy-derived candidate 的支持信号。 |
## 16｜广联产出验收标准
| Gate | 第一版验收标准 |
| G-LINK-1 内容基础 | 每个 Candidate 两端/簇至少能回到内容级 Observation；title-only / filename-only 不得进入。 |
| G-LINK-2 非平凡性 | Priority Candidate 的主要依据不能只是 mentioned_in、near、same_source、same_period。 |
| G-LINK-3 可解释生成 | 每个 Candidate 可重放生成方法和支持信号；不能只给 LLM 一句“我觉得有关”。 |
| G-LINK-4 独立性 | 跨源 Candidate 必须识别来源依赖；转引链不得伪装为多重独立证据。 |
| G-LINK-5 研究价值 | 进入 Discovery Review 的记录必须写具体 why_interesting + missing_evidence + next_search_tasks。 |
| G-LINK-6 人审效率 | Legacy Pilot Top 30 中，人工判断“值得进一步查”的比例目标 ≥70%；低于 70% 优先调算法，不扩大抓取。 |
| G-LINK-7 新发现率 | Legacy Pilot Top 30 中，至少 40% 不能只是旧 relations/story 的直接复述，而应出现新的组合、跨源呼应、冲突或研究问题。 |
| G-LINK-8 跨模态质量 | 进入 Top Priority 的跨模态候选必须包含真实 Map/Visual Observation，不以元数据标题冒充图像内容。 |
| G-LINK-9 人工债务 | 只有 Priority / Narrative-Critical Candidate 进入人工核验队列；其余自动保持研究态、合并或降级。 |
| G-LINK-10 Truth 隔离 | 0 个 AssociationCandidate 自动晋级 Runtime Truth。 |
上述 70% / 40% 是第一轮 Legacy Stress Test 的工程目标，不是长期宪法常数。其作用是判断“关联引擎有没有产出值得人继续工作的东西”，而不是给历史事实评分。
## 17｜“精选”接口：广联何时结束
当 Association Candidate 满足下列任一条件时可进入“精选/Discovery Review”：
一个高特异显式活动/制度/变化关系，且对象身份基本可对齐；
至少两个不同信号族（如跨源共现 + 行动词；地图拓扑 + 方志记录；旧影 + 今日现场）相互加强；
出现重要冲突/异说，本身足以改变现有理解；
形成非平凡多节点簇/行动链/变化链，能够提出具体 Research Question；
能明确说明“如果补到哪类材料，就能证成或否定”，具备可研究性。
进入精选后，五母题与其他人文角度开始参与“解释潜力”判断；再决定是否开启 Directed Research。直到这一步，Evidence Gate 才从“研究提示”转为“Truth 晋级控制器”。

### 17.1 精选的出口与交接（2026-10-03 新增）

**精选不是终点，而是汇流点。** 出口有三条，且只有前两条会产生人工负载：

| 出口 | 去向 | 是否进人工队列 |
|---|---|---|
| **Selected Discovery（Priority / Truth-Promotion / Narrative-Critical / Conflict-Critical）** | 转入 **Directed Production**：Directed Research → N01–N06 → G0–G6（主协议 §12.1） | **是**（创建 `review_queue` 分诊行） |
| **Long Tail** | 保留在 Research Workspace，由机器合并 / 降级 / 暂停 / 淘汰 | **否** |
| **Rejected** | 隔离并记录拒收原因（可回放） | **否** |

**三条硬约束**：

1. **只有 Selected Discovery 才创建 Human Review / `review_queue`**（主协议 §3.3）；研究长尾不 1:1 制造人工债务。
2. **0 个 Association Candidate 自动晋级 Runtime Truth**（主协议 §4.1 `truth_write_ceiling = 0`）。
3. **交接必须携带**：`seed_observations`、`generation_method`、`supporting_signals` / `counter_signals`、`why_interesting`、`missing_evidence`、`next_search_tasks`——让 N 系列知道"该去补什么"，而不是从头再找一遍。

## 18｜LR-ADS-01：旧库关联发现压力测试
| 阶段 | 执行 | 交付 |
| P0 资料盘点 | 把旧 Source 按 T01–T14 分类，并标记 raw availability、content readability、provider、原始载体性质。 | Legacy Source Inventory |

## 19｜Legacy 数据优先适配顺序
基于当前 data-detail 可见的旧库类型，第一轮不需要平均处理所有 59 个 source 文件。建议按“信息密度 × 载体多样性 × 能否形成关联压力测试”排序：
地方志与条目：gazetteer_details、gj_fangzhi、mgts_* entries / town_hits 等。
人物与家族网络：cbdb_people、jp_persons_*、clans / clan_pdf_index 等。
事件与沿革：events_linked、hsly_events、jinze_evolution_raw 等。
诗词/作品：souyun_poems_by_person / by_place、works 数据。
古舆图与空间资料：commons_oldmaps、rumsey_maps、yutu_*、external_mapsource_probe 等。
视觉/叙事资产：commons categories、narrative_assets、旧 Story/候选文件。
现状/文保/地名：protection_index、geo_placenames、现状相关资料。
这不是重要性排名，而是为了让第一轮压力测试同时覆盖“文本—人物—事件—地图—图像—现状”几种不同关联路径。

## 21｜AI 运行时的停止条件
连续两个检索扩展批次只产生同源重复或低 AVS 候选时，停止扩展该方向。
无法取得原始内容、只有目录/标题时，降级为 Source Lead，不继续伪造 Evidence/Observation。
实体身份无法消歧且会影响关系含义时，停止合并并生成 identity task。
时间/空间明显不相容时，不为保持候选而“平均化”；降级或拆成不同对象/时期。
候选依赖模型常识而没有 Reservoir 信号时，标 external hypothesis；当前 legacy stress test 不计为成功产出。
Top 30 人工有效率低于目标时，先调关联与反噪声算法，不进入大规模外部抓取。

## 23｜本版冻结与待验证
> **建议冻结**｜建议冻结：① 宽进的最小成果是内容级 Observation，而不是 Source 行；② 地方志书影、舆图、图片必须按载体“读懂”后才能进入关联池；③ 广联先生成 Signal/AssociationCandidate，绝不直写 Truth；④ 关联算法必须可重放、可评分、可反噪声；⑤ 五母题后置为解释透镜；⑥ 当前先跑 Legacy Reservoir 压力测试。
待验证：AVS 权重、Top 30 的 70%/40%工程阈值、Observation 的最终物理 Schema、是否拆分独立 Research schema、图像/地图识读模型组合、外部 Source provider registry。以上应由 LR-ADS-01 的真实结果再决定，不在本版预先冻结。

**2026-10-03 追加的冻结与澄清**：

- **术语冻结**：研究态一律使用 `association_readiness = ready / limited / catalog_only / unreadable` 与研究态 disposition；**禁止** `usable` / `published` / `verified`。
- **命名冻结**：研究侧候选一律称 **Research Discovery Candidate**，与 Agent 侧 **Runtime Discovery Candidate** 分离。
- **责任冻结**：本细则只生产 Research World；**0 自动 Truth Promotion**；Selected Discovery 才进 N01–N06。
- **范围冻结**：第一验证场为沪上经纬 Legacy Reservoir；在 LR-ADS-01 证明关联发现价值前，不扩大外部抓取规模。
# 附录 A｜AI 宽进任务模板（人话版）
> **AI 指令骨架**｜给定一个 Search Context Pack，不要先选五母题。按资料载体分别搜寻；每得到一个来源先判断“能否取得内容”，再按载体读取。文本必须产出可定位片段，地图必须产出标签/符号/拓扑观察，图片必须产出画面对象/活动/空间观察。只有目录或标题时停在 Source Lead。所有 Observation 保留来源、locator、不确定性和提取方式。

AI 指令骨架｜只在 Observation Graph 上运行 A01–A12，不修改 Truth Store。每个候选输出触发信号、独立来源、时空相容性、反对信号、AVS、why_interesting、missing_evidence 与 next_search_tasks；near / same_source / mentioned_in / title-only 不得单独形成高优先候选。生成 Top 30 Review Pack；五母题只作后置解释透镜。
