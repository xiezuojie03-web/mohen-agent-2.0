### 写入、失效、审核及回滚顺序
- **事务A（世界修订）**：锁定主张族和受影响依赖，查G2证据快照；追加revision/identity/participation/dependencies；登记变更与受影响资格；把资格置为不可消费；提交。失败则整笔回滚。
- **事务B（G3独立审计）**：只基于已提交的一致输入快照评审；版本和指纹改变时不得写入活跃资格；独立写入不可覆盖审计事件与有范围的当前投影。
- **D04消费**：必须同时匹配`claim_revision_id, purpose, scope, input_fingerprint, rule_version`且未被失效；HOLD可展示为未决研究问题，但不可作为事实使用。
- **迁移策略**：先创建新旁路表和新选择器、做影子回放及差异检查，再逐用途切换；旧表及视图在验收前不删除、不改名。**回滚**先将消费者切回既有路径，禁止将新G3资格反写旧G3历史表；保留新增审计供问题追查。正式切换前须确认旧入口本身有无未经授权消费风险。
- **阻断**：缺少当前运行库`pg_catalog`快照、真实旧依赖清单、引用基数、迁移锁与数据量，不能批准最终DDL或运行SQL；P3设计准出已另行完成，实施资格仍待验收；以上ADD对象为列级目标契约而非可执行SQL。

| `conflict_id` | `uuid primary key default gen_random_uuid(), conflict_key text not null unique, object_type text not null, object_id uuid not null, variant jsonb not null` | 保留为原物理字段；须落实版本语义与G3用途投影 |
| `resolution_status` | `text not null default 'open' check(resolution_status in ('open','resolved','preserved_open','rejected')), resolution_note text, created_at timestamptz not null default now()` | 保留为原物理字段；须落实版本语义与G3用途投影 |

**本表十法映射与处理裁决：** 竞争主张与冲突类型及开放状态。

**不足项（需要独立持久化或受控扩展）：** 多候选关联、历史决策、重开理由。

**必须验证的否定条件：** 不得覆盖旧结论造成失去审计轨迹。


### 10.9｜跨表与旧Control的阻断项

- 原`control.gate_audits`有`unique(run_id,gate_code,object_type,object_id)`；新G3必须支持同一主张、不同用途/范围/证据版本的多次追加裁决，**不能只沿用旧唯一约束**。另旧`stage`及`gate_code`白名单与新D00—D05/G0—G5语义不完全一致。
- 原`world.claim_evidence_links`只有L2 `evidence_id`的普通外键；`claim_object_type + claim_object_id`属于多态指向，原DDL没有对每种world表的原生外键保证，必须补应用/触发器或改规范化关联的可检查约束。
- 旧`source.sources`和`evidence.material_evidence`不是新L0/L1/L2全部逻辑实体；不得因为旧表存在就假定新上游已部署。
- 原`world.entities`只有`maturity`，无法无歧义区分身份证据、身份合并/拆分的历次裁决与G3用途；不得靠覆盖当前行丢弃历史。

优先保留八张`world.*`核心表；下列记录**作为物理设计候选**，须在全阶段工程实施前接受DDL/回滚及性能审查：

**反向保守原则**：候选表不是全部必建，需逐项证明旧表受控字段/现有约束不能承载；但“为了不增表而牺牲身份、来源、审计或依赖”的方案应REJECT。

### L3事务语义（设计伪流程，非SQL）

```text
BEGIN logical world revision
  检查新G2输入资格与引用快照（失败→不构造可提交世界主张）
  保存候选历史世界对象或新的主张版本（旧版本只读保留）
  写支持/反证 + 来源独立性评估 + 冲突集合
  写W01—W10实际被调用的方法版本、判断结果及定向回退边
  写依赖与受影响下游用途集合（尚不授予PASS）
COMMIT（可重试；同一输入及算法版本保持幂等键；旧证据不被覆盖）
SUBMIT TO new G3 (world_revision, upstream_snapshot, purpose, scope)
NEW G3 auditable independent decision; never write PASS in above transaction
```

幂等建议键：`(research_run, world_object, claim_revision, input_fingerprint, method_version)`；该组合只是契约建议，需要后续证明不会将合法并行解释误合并。

## 7｜新G3七种用途：独立裁决、审计与失效契约

```text
已提交world_revision + 上游有效输入快照
  ↓ 必须校验代际隔离、对象身份、材料证据、权利、冲突、W10一致性
G3(purpose,scope)
  ├─ PASS → 存append-only audit + 构建有有效期的资格投影
  ├─ HOLD → 保留候选，输出具体缺口/允许的争议说明（不宣称事实）
  └─ REJECT → 记录违规代码；阻止该次用途消费
  ↓ 任意依赖版本变化→对应用途失效，再审后方可新PASS
```

| purpose | 最小必要条件 | 强制HOLD/拒绝越界 | 不得继承的用途 |
|---|---|---|---|
| `world.explain_bounded` | 身份/时间/主张/证据范围可审；有争议时明示双方 | 无效G2、隐匿重要反证 | 现代定位/无争议解释 |
| `world.show_original_region` | 原资产/许可、L1区域可逆定位、L2描述对应 | 不可合法展示、未找到原区域 | 高清下载、历史身份属实 |
| `world.map_anchor_link` | 可证明的图面对应、历史有效期和空间歧义 | 只有同名/相近位置 | 全局配准、现代导航 |
| `world.map_registered_overlay` | S01/S02真实参数、控制点、误差、局部/全局有效界、权利 | 控制点未审核、误差未报告 | 全图所有位置均精确 |
| `world.reconstruct_bounded` | 几何推理分段依据、替代候选、重建说明 | 只凭创作视觉生成形状 | 历史原貌确证 |
| `world.change_compare` | 同对象、可比较状态属性、两端时间证据、未知区间 | 未核实同一对象、图像差异即变化 | 变化的历史原因或连续动画 |
| `world.relation_explain` | 角色、方向、有效期、原文活动证据 | 仅同页共现、缺发生证据 | 道路/行动者真实移动路线 |

**审计最小事件**：`audit_id, gate_generation, gate_code, purpose, scope, world_object_id, claim_revision, upstream_snapshot_ids, method_versions, ruleset_version, input_fingerprint, decision, reason_codes, checked_at, previous_decision_ref`。**有效资格投影**需要`current_audit_id, expires_at, invalidated_at, invalidation_reason, active_fingerprint`。不能依赖原SQL的唯一键模型。

**失效逻辑**：任何输入版本变动 → W10构建受影响闭包 → 标记所有受影响G3当前用途资格无效（保留历史审计） → D04查询返回`STALE/HOLD`而不是PASS → D05在展示/Agent读时重新验证 → 重新运行W子方法和G3审查。若即时传播有延迟，读取侧必须核验依赖指纹，采取fail-closed，不得缓存旧资格绕过。

## 8｜A01—A12逐项反向消费：需求→L3→G3→不支持时退路

本节的A方法用途按现行研究总纲与P3草案的名称映射，属于D04的**消费者契约**而不是提前实施D04算法。五母题、V0.9.1舞台及空间表达是横向验收条件，不要求每项A方法必对应一个母题或一个画面。

| D04方法 | L3最低可查询对象及关系 | 所需G3资格/范围 | 不满足时必须保留的边界 |
|---|---|---|---|
| A01 显式关系 | entities + directed relation_claims + actor_roles + evidence | `relation_explain`或`explain_bounded` | 只保留对象，不得凭共现画实线 |
| A02 共现与跨源 | 提及关联的合法L2输入、world identities、source groups | `explain_bounded`受限，仅候选发现 | 共现是问题线索，不是已证关系 |
| A03 时间序列 | events + time_scope精度 + temporal-order + changes | `explain_bounded`/`change_compare`视用途 | 时序不等于因果 |
| A04 空间拓扑 | historical_space_claims + relations + precision | `map_anchor_link`或`explain_bounded` | 无坐标仍可拓扑说明；不得配准 |
| A05 行动链 | events、参与角色、发生状态、关系方向 | `relation_explain`/`explain_bounded` | “拟议/命令”不等于“执行” |
| A06 制度机制 | 制度/事件/角色及责任的有据关系 | `explain_bounded`；因果须另有证明 | 关联推理不转为L3确定因果 |
| A07 跨模态共指 | visual_objects、entities、原件局部、对应主张 | `show_original_region` + `map_anchor_link`按需 | 展示原件不等于同一身份 |
| A08 结构聚类 | entities、关系类型、各自有效期及来源集合 | `relation_explain`等符合范围的资格 | 聚类结果属于D04发现，不能回填L3事实 |
| A09 变化链 | changes + before/after + event anchors + unknown gaps | `change_compare` | 不得自动补足中间状态 |
| A10 冲突发现 | conflicts、variant set、相反证据、来源依赖 | `explain_bounded`且显示争议限定 | 开放冲突不能筛成单一答案 |
| A11 跨时空比较 | 相容的实体/时空范围、属性、计量口径 | `explain_bounded`/`change_compare`按具体操作 | 不同统计口径不做可比断言 |
| A12 当下线索 | historic_space、identity continuity、today-location basis | `map_anchor_link`或受限`explain_bounded` | 位置对应≠原物/用途/生活延续 |

### 五母题反向缺口归因

- **M1关系世界**：缺活动发生证据→回W04/W05/W07；D04不得从共现生成事实。
- **M2地方结构**：缺对象集合完整性、空间覆盖和比较口径→查D02材料覆盖、W01/W02/W03和W07；不因为地图美观造几何。
- **M3生活地图**：缺行动者目的/限制→查原始材料是否支持、W04角色和W05关系；若仅推测则D04明示问题/候选。
- **M4生成过程**：缺因果和过程阶段→W04/W06/W07分别检查过程、状态和因果支持，不用视觉变换替代机制证据。
- **M5历史延续**：必须分别询问位置、材料、名称、制度、用途和实践；不同连续性不能共用一个`continued=true`。

### 舞台与Agent逆向约束

- **C01单景/C02对照/C03原件细读/C04关系观察/C05连续镜头**的素材及状态由下游选用；D03只提供对象、受限关系、素材锚点和相应资格。
- **S01全局配准/S02局部配准/S03锚点/S04重建/S05原图叙事**分别消费不同G3用途。S05可以在无现代坐标条件下成立；S01、S02缺合法配准依据时必须降级。
- Agent每次解释应能经`finding → world_claim_revision → G3 current purpose → L2 evidence → L1 region → L0 asset`回到原件，并保留用户探索上下文；D03不得预制Agent台词。

## 10｜HR3完整资格快照与消费复核（现行目标合同）

### 10.1 五态、认识状态与旧门隔离
目标G3独立五态：UNASSESSED未审、PASS限定可用、HOLD待证、REJECT不满足所申请用途、REVOKED原资格撤销。到期/指纹错配立即停止新消费，追加失效或撤销事件，不覆写审计。W09的candidate/contested等是世界认识状态，不是资格；旧V2数据库PASS/HOLD/REJECT三态仍如实记录，本节不宣称现行DDL已扩展。旧G2世界门/旧G3发现门不得冒充新材料G2/世界G3。

### 10.2 独立审计与有效时间
沿§7最小审计，补明确门合同/决策ID及版本、对象类型/ID/修订、生产与消费方法版本、规则版本、purpose/scope、当前G0/G1/G2依赖及资格快照、输入指纹、证据锚点、审核者/理由与前序审计。有效资格投影必须说明带时区有限区间[valid_from,valid_until)；缺截止且无长期依据/复审条件、非法区间、到期均不得默认永久PASS。历史事件时间(W02)与审核资格有效时间严格分开。长期资格也需可撤销并核当前依赖。

### 10.3 选择至D04提交的一致性
D03世界修订提交前核P2当前证据版本及G2用途/范围/时间快照；新G3独立审核读取已提交一致快照。D04选入和解释版本提交前再次匹配G3对象修订、用途、范围、消费方法及上游输入指纹；选入时合法不保证提交时合法。换版/撤权/到期先BLOCKED对应消费，再返回独立Owner重审，不能复活旧PASS；一个用途不外推其他用途。G3不授G4解释资格。

### 10.4 精准影响与P4契约接口
W10按实际证据/判断依赖找对象版本×用途×范围的受影响闭包。身份拆分使依赖旧合并的确定锚点/关系/解释停止使用；独立有效的原图观察及其他事实不自动失效。权利变化先限制相应用途，不自动否定事实。旧L3修订/G3审计保留；新评估追加，投影一致性/并发/物理FK由MIG-01验证。
