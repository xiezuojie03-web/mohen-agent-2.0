# 新G1独立质量门与旧门迁移（最终设计）


## 1. 正式定义
新`G1_TECHNICAL_READING_QUALITY`检查**新D01技术读取结果**，不检查历史资料所述是否属实。旧`G1_EVIDENCE_QUALITY_GATE`是历史证据质量门，候选对应**新G2**但需P2逐条再审，不自动编号平移。新G1必须是独立于读取执行器的裁决过程。目标合同按BR-M4采用PASS/HOLD/REJECT/UNASSESSED/REVOKED五态；前三为审核结果，后两为未审/撤权生命周期。读取成功不是资格PASS；旧库三态仅为迁移事实，不能省去五态。

## 2. 输入与裁决记录
`architecture_generation,target_stage=D01,gate_code=G1,gate_contract_version,decision_id,decision_version,production_run_id,read_run_id,raw_item_id,source_version_id,raw_input_sha256,upstream_g0_decision_id,upstream_g0_decision_version,upstream_g0_fingerprint,read_output_manifest_hash,consumer_method_id,consumer_method_version,methods,threshold_profile_id,threshold_profile_version,guard_rule_version,purpose,quality_checks[],allowed_extent,gaps,decision,reason_codes,evidence_refs,dependency_snapshot,valid_from,valid_until_or_explicit_recheck_policy,checked_at,supersedes_audit_id`。
选“有效PASS”要求以上身份与**当前**读取及上游新G0完全匹配，审计本身不可撤销修改，后来的HOLD可使此前PASS失效。

## 3. 必须检查的谓词
G1-A 按P0.3§2/§3.2及01§2核实上游新G0对于具体资产类型/ID/版本、拟消费C方法/版本、本次操作/范围/环境为当前有效PASS，决策/规则版本、时区有效区间、依赖与资格快照完整；G1-B 读取的输入hash与raw item一致；G1-C C方法路由与实际输出单元存在；G1-D 运行工具/参数/版本可追踪；G1-E 单元定位可逆并受原件范围约束；G1-F 完整性清单分母可靠且缺失范围显式；G1-G 有审批的质量profile并有独立质检证据；G1-H 所有高风险关键范围满足profile；G1-I 无未经许可的资产处理；G1-J 出口清单、交接范围与哈希一致。

## 4. 结果优先级（不可误判）
- `REJECT`：可证实输出来源或位置伪造、核查证据伪造、违反已确认的权利限制、不可逆篡改原证据；须有人工复核/机器可证明记录。禁止把普通OCR差错归REJECT。
- `HOLD`：任一硬谓词缺失；无有效G0、无量化质量profile、漏页、未声明未读区域、抽样不足、来源定位失链、服务暂不可用。允许纠正后新运行或新审计。
- `PASS`：所有谓词满足且测得值达批准profile；如有非关键缺失，须有**明确有界**`allowed_extent`并且缺失区永不流向D02。

## 5. 独立选择器原则（伪SQL条件，不是可执行迁移）
```sql
-- 与旧 control.g1_pass_evidence 明确隔离
SELECT r.read_run_id
FROM source.read_runs r
JOIN control.gate_audits_new g ON g.object_id=r.read_run_id
WHERE g.architecture_generation='target_2026_d00_d05'
  AND g.gate_code='G1' AND g.stage='D01' AND g.result='PASS'
  AND g.input_fingerprint=r.input_fingerprint
  AND g.output_fingerprint=r.output_manifest_hash
  AND g.guard_rule_version=:approved_rule_version
  AND g.is_current_decision=true
  AND g.upstream_g0_is_current=true;
```
`gate_audits_new`及`is_current_decision`都是**设计占位**，不是已存在表列；实际采用事件追加＋确定性最新裁决视图，不能允许并发竞争下两个当前PASS。更重要的是旧唯一约束必须排除对新追加历史的限制。

## 6. 旧门映射：明确保留代际
| 旧物 | 旧含义 | 新目标 | 处理 |
|---|---|---|---|
| 旧G0、旧`g0_pass_sources` | 旧D01来源准入 | 新G0候选语义包含来源准备 | 不自动平移；P0重审asset级准入 |
| 旧G1、旧`g1_pass_evidence` | 旧L1证据质量 | 新G2材料理解候选 | P2重审；不得给技术读取放行 |
| 旧G2 | 历史世界对象 | 新G3候选 | P3重审 |
| 旧G3 | 人文发现 | 新G4候选 | P4重审 |
| 旧G4 | 读取模型发布 | 新G5候选 | P5重审 |

## 7. 禁止的迁移捷径
不能根据旧`gate_code='G1'`无代际过滤查PASS；不能把旧`evidence.material_evidence`的主键映射成`read_run_id`；不能把旧最新PASS在输入资产变化后继续引用；不能把一个C方法通过视为整组C方法通过；不能用质量分数绕开来源授权。

## 8. 设计负例及后续工程验证
同一read_run从PASS到HOLD的追加裁决；资产SHA变化使老PASS失效；模型版本换代读出不同文字；C02完整而C03漏图例；C05分页重复而主键数不足；上游G0撤销；并发裁决和跨租户隔离。全部留待工程实施执行，不宣称现在已通过。

## 10. 判定粒度
G1裁决键：`generation + raw_item_id + source_version_id + read_run_id + output_manifest_hash + profile_id/version + purpose + allowed_extent_fingerprint + upstream_g0_decision_id + rule_version`。任何键值变化产生新的可审查判定，不覆盖审计。G1是独立资格裁决，Guard仅实施消费阻断，不是OCR工具自评。

## 11. 正式决策逻辑（规格伪码）
```text
if verified_fraud_or_confirmed_unauthorized_handling: REJECT
else if !current_new_G0_PASS(asset,purpose) or hash_mismatch: HOLD
else if !approved_profile(purpose,method,risk) or !all_required_metrics_defined: HOLD
else if !complete_scope_manifest or !reversible_locators or !independent_QA_evidence: HOLD
else if !all_hard_checks_pass or !metrics_meet_profile: HOLD
else: PASS(only_approved_extent, only_approved_purpose)
```
不得因单项优秀分数抵消来源不合法或定位缺失。一般OCR差错不能定REJECT；修正后再申请新裁决。

## 12. 有效PASS选择器
必须匹配当前上游G0、原件SHA、读取清单哈希、画像版本、Guard版本、用途和准入范围；选择追加审计链中确定性的最新有效裁决；同时核该裁决有效时间及复审策略，带时区有限有效区间为[valid_from,valid_until)，到期即停止，缺截止且无明确长期依据/复审条件不得默认永久许可。后续HOLD/REJECT或上游撤销将旧PASS排除；不同用途的PASS不串用；旧`control.g1_pass_evidence`永不可作为新G1的输入。选择后及读取输出提交前再核上游资格快照；撤权、到期、指纹或规则变更先阻断相关消费/提交，再交独立Owner重审，不能沿用缓存PASS。影响范围按实际版本×用途×范围依赖定位，未受影响的独立来源/用途不自动失效。并发时一个裁决对象只暴露一个当前版本；旧审计不可删除。

## 13. 不同用途反例（设计期合成用例）
| 编号 | 情况 | 预期 |
|---|---|---|
| 检索可用但引用未核校 | 某PDF已可检索但引文区未人工核对 | SEARCH按批准画像有界PASS；QUOTE HOLD |
| 定位锚点断裂 | OCR文本正确但页图bbox无法回指 | 两用途HOLD |
| 地图图例缺失 | 地图大多数标签准确，但发布所需一处关键图例无法辨认 | GEO_LABEL在该范围HOLD；无关区域可单独申请PASS |
| 音视频原始时基丢失 | 音视频时码显示秒数但丢失原始PTS | AUDIO_VIDEO_CITE HOLD |
| 数值字段精度丢失 | 表格总行数一致但金额列出现类型舍入 | STRUCTURED_VALUE HOLD |
| 读取输出发生换版 | 新OCR版本替换前一版本 | 旧PASS不再适用于新输出；重新质检 |
| 来源授权被撤销 | 上游G0权限变更失效 | 只有实际依赖该被撤销版本×用途×范围的当前G1资格失效；无关独立消费保留 |
| 自评准确率无独立样本 | 读取器自评98%但无独立参照样本 | 相关准确性审查HOLD |
| 阈值画像尚未批准 | 用途画像阈值仍是DRAFT/null | HOLD，不允许上线真实PASS |
| 疑字引用的有界裁决 | 高风险引文所有字均独立核校但存在标记为不明的字 | 只有明确按原貌呈现疑字且获批准的引用策略可局部PASS，否则HOLD |

## 视觉用途资格和定位保真裁决

新G1需区别`searchable_text`, `precise_quote`, `original_visual_region`, `map_label_read`, `audio_video_excerpt`, `structured_value`等具体用途；技术读取PASS不自动意味着历史图像可解释、现代坐标可配准或允许公开展示（展示授权由G0管控）。对完整原图、可读局部、技术变换可逆、可回到原件、图例/字幕覆盖、未知部位保留分别评审。原图丢失仅剩AI增强衍生图、页号无法回指、裁剪后坐标变换不可逆，应按用途HOLD。源资产撤权、新读取换版应使相关用途级资格失效。
