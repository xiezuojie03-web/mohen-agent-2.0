# D01统一技术读取机制与质量治理（最终设计）


## 1. 生命周期与边界
`新G0有效PASS→资产封存与用途核验→探测→方法路由(C01…C08,可多选)→读取版本→定位锚定→完整性盘点→抽样核校→新L1入库→独立新G1裁决→有范围交接D02`。
**D01只解决“原件上客观可观察到什么以及被读取成了什么”**，不解析文献体裁、不断言历史事实、不把视觉猜测当来源自述。D02负责篇章与内容观察，D03负责实体和跨来源历史世界裁决。

## 2. 输入、结果与事件的最低合同
输入：`source_id,source_version_id,raw_item_id,asset_sha256,asset_media_type,permitted_purpose,new_g0_decision_id,new_g0_input_fingerprint,asset_extent`是检索索引，不是完整准入条件。D00→D01完整输入以P0 `契约_P0.3_新L0_G0与D01交接_最终版.md`§2/§3.2为唯一上游合同；P1必须接收成果类型/ID/版本、生产方法/版本、G0决策/版本/规则、拟执行C方法/版本、请求动作及内容范围、定位命名空间、有效时间、权利证据/环境限制、已知缺损、有效依赖及资格快照。字段别名须显式映射；不能靠题名、URL、旧门PASS或缺值默认放行。物理列由后续迁移裁决，不把语义清单直接当DDL。

D01消费准入由本阶段Owner负责：先按P0.3核实当前资格，在读取启动和输出提交前再次核对同一资产版本/指纹、C方法版本、请求操作/范围、授权有效性及依赖快照；复合载体按实际子方法、子资产及范围逐项核对，主方法获准不替所有子方法获准。读取所需保存/转化/第三方工具等动作须在许可内，内部机器读取不自动获得公开展示权；授权限制未知则暂停相关消费。

资格失效或错配返回`BLOCKED`及原因；已有四种非PASS裁决保留原态，独立G0 Owner补证/重审，P1不得代批G0。反馈是控制请求，不创造新L0血缘。读出后失效仍阻断提交及新的下游使用，保留已有原件、读取版本和审计；按具体依赖版本×用途×范围传播，无关读取不自动失效。G1只裁读取质量，不代替G0权利资格。

若为尚未获取材料不准生产READ_RUN。可用`SIMULATED_ONLY`在设计测试中替代，但永不产生生产PASS。
运行：`read_run_id,architecture_generation,method_codes,tool_name,tool_version,config_hash,input_fingerprint,started_at,finished_at,status,output_manifest_hash,supersedes_run_id`。
单元：`unit_id,read_run_id,method_code,unit_kind,physical_locator,logical_sequence,raw_payload_ref,transcription_candidates,uncertainty,raw_correspondence,quality_flags,parent_unit_id`。
质量：`check_id,run_id,method_code,metric_name,denominator_basis,population_n,sampled_n,error_n,method_sampling,observed_value,threshold_profile_id,evidence_ref,result`。
交接：`handoff_id,read_run_id,output_manifest_hash,new_g1_decision_id,allowed_extent,known_missing_extent,locator_scheme_version,read_units_manifest,technical_uncertainty_ref`。
以上皆为合同逻辑字段，不等于现行数据库已经具备相应列。

## 3. 三类质量指标不可混用
- **完整性（coverage）**：实际处理的可枚举范围 ÷ 应处理范围。分母须从原件清单得出：页数／帧时长／频道／文件行数／对象清单／采集步骤；并区分未读取、已读取但不可辨、已读取且核校。
- **准确性（correctness）**：抽样单位的错误数或字符、字段、时标的误差。分母是人工核准样本，不能把模型置信度当实际准确率。报告抽样种子、分层方式、是否独立复核及纠正前后值。
- **可追溯性（traceability）**：每个被交接输出有不可变的原件指针、位置坐标体系、技术版本与映射。关键锚点缺失是硬性HOLD，不以高字符准确率抵消。

## 4. 阈值的治理：硬门槛与候选配置
**硬门槛（任何载体适用）**：上游新G0有效；权利与用途允许；源资产字节指纹匹配；运行工具参数可重放；所有交接单元有可回指的原件定位；已知未读范围明确；质检分母与抽样证据存在；输出版本固定；G1审计具有代际、规则版本、输入输出指纹。违反则不得PASS。
**研究候选，不作为未经校准的生产政策**：完整性要求关键区段100%已登记（登记≠100%识读正确）；非关键段容忍度由任务画像指定；精度至少以分层抽样发现率／错误率决定；关键引文、地图标签、数字金额与专名可采用逐项人工核验。任何profile无批准版本则HOLD。
采用`threshold_profile_id`绑定载体、用途、风险、质量定义、最小样本、容忍误差和批准人；G1不能使用随运行临时生成的阈值进行自我放行。小样本必须披露抽样不足，不能伪称达到统计置信。

## 5. 定位体系
文本：`raw_byte_start/end`加编码，Unicode code-point区间另外记录；不跨编码冒用偏移。书影：`physical_page_index0`、页图SHA、原图宽高、标准化bbox、栏与行序、印刷页码另存。地图／图片：原图坐标和尺寸、旋转与裁切矩阵，绝不擅自补现代投影。音频：采样率、声道、样本offset与毫秒；视频：原始PTS／timebase／track_id，秒数为派生显示。现场：设备原始坐标参考、误差半径、采集时间／方法。

## 6. 错误处置、重跑和有界PASS
失败分类：`ACQUISITION_INVALID`(退回D00),`FORMAT_UNSUPPORTED`,`PARTIAL_EXTENT`,`LOCATOR_BROKEN`,`ACCURACY_UNVERIFIED`,`TOOL_DRIFT`,`RIGHTS_REVOKED`,`INTEGRITY_MISMATCH`,`NONDETERMINISTIC_OUTPUT`。同一输入失败重试上限由执行策略定；相同指纹且无新方法信息则HOLD，不循环。
**有界PASS**只对批准的`allowed_extent`有效，禁止对缺失页、未见图角、未听声道进行下游推断；新读取版本使旧G1 PASS失效或不可被选择为“当前有效”。伪造来源坐标、故意伪造人工核验或确认无权读取→REJECT；一般技术质量不足→HOLD。

## 7. 外部校核与自动检测的分工
工具自动检查完整性、位置语法、范围重叠、文件格式、哈希和schema；人工或独立校验检查OCR错字、音频转写、图片真实可见对象、历史舆图标注。不得将“模型自评高分”当作独立样本验证。




## 9. 双重准入：硬前置与用途画像
硬前置（所有画像）：新G0对本资产/用途为当前有效PASS；输入SHA与原件一致；可枚举总体及漏读范围；定位可逆；执行器、配置与输出版本固化；质检样本、核校者和证据可回查；权利范围适用；G1规则版本获批准。任一不满足→HOLD，伪造/确定越权→证据充分时REJECT。

质量画像不可由执行器自行放宽。推荐配置模式：
```yaml
profile_id: P1_SEARCH_SCAN_V1
profile_version: 1
status: DRAFT # DRAFT / APPROVED / RETIRED
purpose: SEARCH_DISCOVERY # SEARCH_DISCOVERY / VERBATIM_QUOTE / GEO_LABEL / AUDIO_VIDEO_CITE / STRUCTURED_VALUE / GENERAL_OBSERVATION
methods: [C02]
risk: STANDARD # STANDARD / HIGH / CRITICAL
extent_policy: bounded
sampling:
  design: stratified_random
  strata: [layout, degradation, language, page_type]
  min_n: null # 须经校准批准；null不能生产PASS
  independent_reviewer: true
metrics:
  coverage_min: null # 待批准的正式阈值；不能把未知当100%
  cer_max: null
critical_zero_unresolved: false
required_evidence: [asset_manifest, read_unit_locations, sampling_protocol, correction_log]
owner_approval: null
```
正式批准须具备`profile_id/version, use, modality, scope, severity, population_definition, stratification, metrics and denominators, sample_size_calculation, tolerance, acceptance rule, exception policy, approver, effective_date, retirement`；任一必需阈值为空→不得生产PASS。

## 10. 用途准入矩阵（政策设计，不是已通过的实测结果）
| 使用目的 | 许可的L1输出 | 必需测量 | 不可放行情况 | 建议核校策略 |

| 全文检索 SEARCH_DISCOVERY | 可检索候选文字及不确定标记，须可回原件 | 覆盖率、CER/查询词召回测试、缺页率、定位成功率 | 不得宣称逐字准确或作为正式引文；漏页未知→HOLD | 按排版/字种/破损度分层抽样；关键检索词专项核对 |
| 原文引用 VERBATIM_QUOTE | **指定范围**的逐字核准转录及原文锚点 | 引文字数、逐字差错、漏字/异体字、标点添加情况、锚点回溯 | 未经独立逐字核校的引文不可放行，文字不清不得猜补 | 每条拟发表引文100%人工或独立原件核校；保留疑字原貌 |

“100%逐项”只作用于**选定的高风险发表/引用单元**，不等于要求整部古籍全文人工核校后才能用于发现用途。统计抽样不支持零错误承诺；拟发布引文必须逐条核校。

各C方法度量见`规范_P1_C01-C08载体与复合材料专业读取.md`；本主规只管统一画像批准、校准、失效和用途授权。

## 12. 风险与局部准出
CRITICAL：逐字引用、碑刻残字、古地图定点标签、金额/年代/日期、引发精确地图定位的锚点；HIGH：历史专名、机构名、地图对照、访谈署名；STANDARD：辅助发现与非关键候选。风险可上调不可由执行器自行下调。局部PASS需要`allowed_extent`明确且`excluded_extent`与缺失原因记录，消费者必须以范围过滤；不具条件时HOLD。

## 13. 画像治理
画像需专业责任人审核/签名，进入`APPROVED`后冻结。阈值改变产生新版本；读取结果与旧画像的PASS不可借新画像追认。模型输出自评不算独立核校。首次工程验收需使用真实经许可样本做误差分布校准后批准可用数值；在此之前无真实G1 PASS。


## 14. 运行时控制权
- 读取执行器不能批准自己使用的质量画像；画像批准者与独立核校人需要可审查身份。
- `DRAFT`和必填阈值为`null`的画像不能生产PASS。数值阈值须后续工程使用真实授权样本校准并经批准；设计期不能填想象数值。
- 一份材料可针对检索PASS、针对引文HOLD，允许范围与不允许范围明确存储。
