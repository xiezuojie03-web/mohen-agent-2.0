# 复合、嵌套文献与转引依赖阅读规范

## 一、三种身份必须分开
- **物理容器**：一册PDF、网页、方志扫描包，对应L0资产及L1技术读取。
- **文献工作单元**：一本志、其中的卷、独立碑文、图幅、附录文书，可以有不同H阅读策略。
- **来源声音与转引路径**：县志编者的话、引用的旧碑文、现代录入者的校注，分别标记，不当成三个独立历史目击者。

## 二、识别与执行
1. 在G1准入范围中确定容器与物理位置；记录边界是否可定位。
2. 按原书目录、版式题名、署名、图注、引文界标提出单元拆分。
3. 为每个单元记录`parent_unit_ref / embedded_unit_type / declared_source / actual_available_source`。
4. 为独立或半独立的引录材料安排相应H阅读策略；不因载体同为扫描书页而强制同一H。
5. 建立`quotes / paraphrases / recopies / comments_on / edited_from / unknown_dependency`候选依赖及依据。
6. 保留引用层数，若只见类书摘引而未见原书，不能宣称核验了原书全文。
7. 对来源未明、跨页界线丢失、影印断章、文献声音不清的单元HOLD，不影响无争议其他单元继续观察。

## 三、案例与否定测试（合成）
| 情况 | 正确做法 | 禁止 |
|---|---|---|
| 地方志收录碑文 | 县志作为承载/转引，碑文作为嵌入阅读单元，记录原碑未核验 | 同时把志文和碑文记为独立亲历证据 |
| 类书引某失传书 | 类书有可验证页位，失传书仅`reported_source` | 填写失传原书的虚构原文页码 |
| 文集中附舆图 | 书籍结构与图幅分开阅读，图面技术读取引用C03结果 | D02修改OCR/图像定位 |
| 数据库抄录契约 | 存数字记录与原契约之依赖关系；未知原件标记 | 认为数据库字段一定保留契约全部条款 |

## 四、去重原则
一条历史文字因扫描、OCR、转录、再版、类书引用产生多份数字对象，可能形成多个**技术记录**，不能默认成为多个**独立史料见证**。是否具有源头独立性供D03裁决；D02只把可辨依赖链完整传递。

## 五、V0.3交叉类型的唯一单元规则
同一容器可承载多个H工作单元，但**类型候选的数量不得决定材料证据条数**。父单元应记录`contains`，子单元仅在边界和原声可辨时建立；`recopies/quotes/edited_from`必须连接相关工作单元及其可见来源。具体H判别见02，本文件只规定嵌套、转引和依赖的一致记录方式。

最小例：`父县志 H05 → contains 子碑记 H09 → recopies 未见原碑`；父志编者说明与子碑文是两个可辨话语，**但同源历史见证不能自动计为两个**。同一近代新闻报道被多刊转载：每刊构成独立出版对象、允许不同评论观察，但所转载事件报道要有`recopies/wire_origin_candidate`依赖，不在D02认定几条独立事实证据。凡依赖链有缺口，保存`unknown_dependency`及`dependent_claim_unverified`，不编造上游原始载体。

## 八、V0.4复合现代资料依赖实例与反向校验

| 容器/子单元 | 结构所有者 | 转引/版本依赖 | 失效与重复防护 |
|---|---|---|---|
| H21报纸版面内H25照片 | H21刊期/版面；H25图像内容 | 原底片、报馆翻拍、后加图说分别挂依赖 | 版面与照片不可作两份独立目击证据 |
| H23发掘报告附H19简牍摹本 | H23方法/层位；H19原文释读 | 出土件、拍照、整理、公布版逐级连接 | 报告推断不覆盖释文疑字 |
| H24论文引H05方志 | H24论证与引证；H05嵌入引文 | 若未读方志原本，记录`secondary_citation_only` | 不生成“独立见志”标记 |
| H22口述采访附旧照片 | H22采访语境；H25影像描述 | 受访者对照片的辨认属回忆陈述 | 照片所见与讲述者记忆分开 |

跨文件复用时，03只定义依赖语义，不重复02专业读法；所需关系字段唯一归04，裁决归05。


## 原图、内嵌图说与二次转载关联

一本方志的古图、原编者图说、后来注释及当代馆藏元数据不应合并为一名“来源作者”。复合材料须同时保存父子阅读单元、图文配对范围、归属与依赖，以及原图/裁剪/题注的双向定位；图文不一致时保存冲突观察，不强行调和。转载照片、重绘地图、后期上色和解释性复原图必须标记与原件的依赖；同源转载不可作为多份独立历史见证。
