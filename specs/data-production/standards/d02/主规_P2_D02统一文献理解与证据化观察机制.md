# D02统一文献理解与证据化观察机制

## 1. 统一工作顺序
输入采用P1 `契约_P1_D01至D02可信交接.md`完整资格快照，核当前G0/G1版本、方法/用途/范围/时间、原件与read-unit定位和依赖；消费启动及材料观察提交前再次核验，不用一次静态PASS缓存代替当前资格。失败按具体用途BLOCKED并回独立Owner，不覆写L1。

**消费准入验证 → 确定作品/版本/嵌入单元 → H类型候选与理由 → 逐类篇章结构阅读 → 将话语声音、陈述类型、时间层次分离 → 逐项建立证据化观察及来源锚点 → 处理疑读/引述依赖 → 新G2独立审查 → 有界交接D03。**

## 2. 读懂一段材料的最低维度
| 维度 | 必须回答的问题 | 产物 |
|---|---|---|
| 文献身份 | 谁何时以什么目的编写/整理？ | 作品、版本、编修层次指针（复用L0） |
| 阅读单位 | 原书哪卷、哪篇、哪页、哪个嵌套项目？ | 单元路径与L1读单元引用 |
| 结构归属 | 该段在志目、世系、表、注、图说中的作用？ | 内容结构画像 |
| 话语声音 | 作者亲见、转引、传闻、官方规定、译者注释？ | source_voice+voice_basis |
| 时间属性 | 书成时代、书写时间、内容所指时代是否不同？ | 时间提及及其确定性 |
| 地域属性 | 记述何地？古地名是否歧义？ | 字面地名提及，不做实体合并 |
| 陈述性质 | 陈述、规范、愿望、意见、引述、虚构、假说？ | assertion_kind |
| 可证范围 | 原文支持哪一句话，不支持哪些推论？ | research_proposition + scope |
| 疑点 | 缺字、异读、史学争议、引文来历不清？ | 技术疑点引用+史学疑点分开 |

## 3. 输出级别（不可跳跃）
- **可读内容单元**：通过G1的来源片段，尚非历史证据。
- **材料观察**：明确材料说了什么、是谁说的、在哪里说的；允许存在待核问题。
- **证据候选**：附原文摘录、选用范围、版本、依赖、声源以及不确定性，等待新G2。
- **可交接观察**：G2对声明的用途与范围PASS，供D03进一步判定身份、时空和关系。G2 PASS只证明**文献观察质量**，不证明该历史陈述为真。

## 4. 质量优先级
原貌与定位不可牺牲；完整表述背景优于孤立关键词；时间、地点、数字原文保真；分离客观摘录与阅读者改写；转引不能当独立来源；对疑点明确HOLD及再阅读路径。

## 5. 示例（合成，非历史事实）
某县志写“旧传某桥建于某朝”。允许输出：县志X卷Y条记载存在此传说；`source_voice=旧传`；`assertion_kind=传闻`；桥名与某朝为提及；原文及页码指针。禁止输出“某桥确认建于某朝”或把此内容直接写入D03历史事件表。

## 6. V0.3分类冲突的统一消歧原则
H主类是**某个文献工作单元的专业阅读路径**，不是载体、主题或一条证据的永久本体标签。主类+次阅读策略+嵌入子单元+转引链四者需分别记录。新增近现代材料不能仅用“未收录于旧20类”证明必须加号；应按02的独有结构/方法/输出/反例门槛评估。类型可未决，原文观察不得因分类不明而被AI任意改写；其用途级G2决定见05。

## V0.4分类和持久化同步原则

H21—H25是对原有H01—H20内容功能分类的**增补**，不是载体分类或第二套上位分类轴；历史记录保持旧判定，新增类由版本化字典管理。阅读流程继续采用L1技术定位→D02最小单元分类与内容观察→G2用途级核验→D03消费，所有新类产出使用04的统一L2模型，不单独建设每类证据表。遇未可判定的材料，允许限定范围的`H-UNRESOLVED`并保留HOLD，不能强制归类。


## 图像所见、图说陈述与历史事实的三层区分

D02必须把**可见材料**（图内符号/线条/人物/建筑外观）与**原始文本或原件题注的陈述**（谁写/谁标/何时写）及**后加目录说明/现代整理者解释**分开观察；三者在L2保留不同`source_voice`、记录时间、素材与锚点。D02可形成“某图中出现某符号”“某图说称该符号为桥”的材料观察，不得推出“真实某桥即在现代某精确坐标”；最后一步属于D03。照片拍摄时间、场景所指时代、资料数字化时间不能互代。材料不足时仍允许输出确切的观察及HOLD其余解释。
