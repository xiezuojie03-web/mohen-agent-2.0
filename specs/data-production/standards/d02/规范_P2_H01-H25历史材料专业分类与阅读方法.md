# H01—H25历史材料专业分类与阅读方法（现行目标字典）

## 一、类型选路规则
H类别以**材料的知识组织目的、文本功能和原有编纂体例**为首要判别依据，不按PDF/图片/HTML载体决定。先保留主类型候选及证据，再识别次类型和内部嵌入单元。对不满足现行H01—H25的资料保留`H-UNRESOLVED`及有依据的增补提案，不硬套。类型判别与D02历史内容观察同时迭代，但分类不以预先指定主题替代。

## 二、H01—H25统一分类索引与阅读任务定位

- **最小结构化产出**：共同字段`source_version_ref`、`l1_unit_refs`、`reading_unit_path`、`verbatim_span`、`voice_basis`、`assertion_kind`、`source_dependency_refs`、`uncertainty`、`support_scope`；类型扩展字段：visible_elements、camera_viewpoint、cropping_state、caption_authorship、capture_date_basis、publication_date、inferred_vs_observed。物理字段唯一权威为文件04。
- **验收与G2/HOLD**：画面区域可返L1，裁切和标题来源可追；对画面外或不可辨内容保留未知；原图不明、裁切范围不明或配文来源不明时禁止据此精确定位/定年。G2仅裁决材料理解和可交接范围。
- **正例（合成）**：照片可见一座石桥与临河建筑，仅记录可见形态及图片来源，并留原件位置与来源依赖。
- **禁止性反例（合成）**：凭后来档案标签将模糊桥名直接认作某座特定历史桥。

## 四、跨类实际操作模板与设计验收

### 4.1 一次阅读的必要操作序列
1. 检查`G1`在当前用途/片段/读取版本的有效PASS；若只获检索授权，不得生成已核准的逐字引文。
2. 提取作品/版本（L0）、版面与字词（L1）引用；确认是否有图、表、注、录碑、附契约等内嵌单元。
3. 依据文本知识功能选择H主类和理由；必要时标记邻类、`H-UNRESOLVED`，不得用格式或研究主题先验代替类型判别。
4. 依上文对应H方法遍历结构树，逐段分辨“谁在何时何种语境下说了什么”。
5. 产出可见原文片段、限定释义、陈述性质、时间/地点字面提及、引述依赖、可证范围、误读风险。
6. 对跨页、跨图文、原件/转录异文及转引建立多L1片段和依赖边；不在L2复制整本OCR，也不凭同字同名合并历史实体。
7. 执行新G2的范围级质量审查：可追溯、话语分层、限定、依赖、不确定性；只将PASS范围交D03。

## 五、类型扩展的审查判据（已用于H21—H25决策）

- **报刊与期刊**：重点研究刊号、栏目、新闻报道/社论/广告、转载、发布日期与事件日期、摄影说明。应以“是否存在独立、可重复的专业读法及稳定成果结构”判断是否新增类型；本轮已批准H21设计目标，不把新闻材料硬套入H20。
- **口述史与访谈**：访谈时间、回忆事件时间、受访者与采访者声音、剪辑删节、转述链必须区分；已批准H22独立读法；说话人属性同时作为跨类型通用字段保留。
- **考古报告及器物著录**：考古工作记录、器物目录与古代出土文字属于不同对象；现代解释不能和出土原文混合。
- **现代学术研究与文保调查**：理论推论、田野测量、论文转引、作者观察需分开；不因有PDF而划到C01，也不能借H01误判为古代史料。
- **数据库、众包转录及数字校勘本**：要明确数据记录与底本的依赖及编辑责任，独立性不能按数据行数计。

**增类门槛**：明确不可覆盖的材料对象、专有阅读流程、和既有H类型的对照差异、可证据化输出与正/反/HOLD案例；H21—H25已经通过设计审查；今后若再增H26及后续类型，仍须单独满足上述门槛。

## 七、H类型交叉与冲突：判别、切分和裁决

### 7.1 基本裁决原则与决策流程
主类必须由**当前可独立引用的文献工作单元的组织目的**决定，不能由容器文件格式、研究主题、实体名称或“谁最容易处理”决定。所谓交叉可能是四种不同问题，必须先区分：

1. **同一材料多种功能**：同一部书兼具沿革与山川，主类仍按全书或独立单元编纂目的，其他功能用阅读策略/主题标注，不重复产生证据。
2. **容器含独立作品**：地方志中录碑、论文引用契约等，父容器与子文献建立`contains`及`quotes/recopies`，子文献可拥有独立H阅读路径，但**不自动拥有独立来源见证**。
3. **类型边界真实不清**：主类保留`unresolved`或候选及依据、判别问题；禁止随意强制选第一类或将全部类并列为主类。
4. **数字再表示**：古籍PDF、数据库转录、图片、音频是C载体差异或转录关系；并非新增H类依据。

具体流程：锁定L1可用片段及工作单元边界→辨标题/编者/成书目的/结构→生成不超过三个最有根据的H候选与反证→判断是否是嵌入作品或结构混合→确定`primary_h_type`或`unresolved`，辅以`applied_reading_strategies`→生成唯一观察，依赖来源分层→G2按用途核验。**多策略不等于多份独立证据。**

### 7.3 多类同用的存储与判别例（均为合成）
- **县志·艺文收《某桥碑记》**：单个志书父阅读单元H05、碑记子H09；`source_dependency = recopies`，证据观察选碑文在县志的确切页段；`original_inscription_observed=false`。可观察“县志抄有碑文”，不得声称“实地碑刻尚存”。
- **政书摘录县令批文**：H03父+H07子；规定与特定办文陈述分别抽取，不能由编者重述形成第二条独立见证。
- **数字方志库提取地名条目**：原条目H05，数据库行是来源再表示/索引；不可因此额外记一件“现代方志”。
- **一份现代考古发掘报告附墓志拓片**：现代报告使用现行设计目标H23；墓志H09/H19视原物和整理机制裁决，明确图像/录文/报告释读三级来源。

### 7.4 跨类冲突的HOLD与校正
有两类看似相斥的判定：一是**类型判定不确定**（例如同一卷到底是地理专著还是地方志），可保留限定用途观察并把分类本身标`HOLD`；二是**源声/依据冲突**（碑记被后人改写），如果影响引文字面与转引身份，则对应引用用途必须HOLD。类型改判需创建分类决策新版本和受影响观察的复核请求；不得直接修改已通过G2的历史审计。

## 八、扩展类型的生效与兼容边界

- H01—H25共同组成**当前设计批准的目标字典**，逐类方法在本文件第三章同等有效；实际数据库字典启用和真实证据验收仍属于后续工程验证。
- 分类按最小完整阅读单元执行；H21报刊含地方志转载时设H21父单元与H05子单元；H23报告附出土文献设H23父单元与H19子单元；H21期刊收研究论文依知识功能用H24子单元；H21报刊照片以H25子单元阅读。
- 数字目录、众包转录、数据库不因数字化形式新增H类；原材料知识功能决定H类型，来源与派生关系归L0/L2管理。
- H01—H20既存记录不自动重分类；如经复审改判，追加分类决策版本并检查下游证据有效性，不覆盖历史审计。分类未决允许`H-UNRESOLVED`用于不依赖确定H类的有限索引/字面观察；依赖特定专业类型的解释用途保持HOLD。G2按声明用途独立审查，未决类型不默认获得证据PASS，也不全面阻断其他独立观察。
- H字典设计版本与生产发布版本必须分离；本次为设计准出，不宣称H21—H25已进入真实生产。


## 跨H类型的原件细读与视觉证据共用要求

H01—H25的阅读方法应在必要时调用以下**共用而不新增H分类**的观察动作：①确认作品/页面/图幅及转引链；②区分图像直接可见、图例/题跋所述、后人附注、AI候选识别；③记录区域与引文、方向/比例/尺度能否解释及其年代；④保留图与文字何处一致、矛盾或没有明确对应；⑤标注原貌展示限制及下游不得推定的内容。适用典型：H05地方志中的图说与多次修志旧图；H18历史舆图和图谱；H21报刊图文与转载；H23考古报告图版、剖面与推断；H24文保调查中的现场照片/复原图；H25历史摄影与纪实图像。H类是材料性质与阅读策略；C02/C03/C04是载体读取技术；不能以两者相同外观互相代替。五母题是后续D04解释任务，不能在D02按母题筛去“不适合当前故事”的证据。
