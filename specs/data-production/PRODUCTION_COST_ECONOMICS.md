# 墨痕 · 数据生产成本经济性标准（分规模等级）

> 定位：数据生产「成本验收」（任务书 §8.3 第 4 类）的长期执行标准——指导不同规模等级下如何**经济地运行生产链**。
> 来源：`SAMPLE-TRIAL-07` 成本评估框架 + 样板试验真实 token 实测（SAMPLE-TRIAL-11 金样本 / SAMPLE-TRIAL-12 第一层 / SAMPLE-TRIAL-14 第三层）。
> 日期：2026-10-18。

---

## 一、成本结构（已实测确认，非估算）

- **成本大头 = D02–D04 的 LLM 调用**；D02 材料观察最大（长史料输入），D03 世界建构次之，D04 人文发现较小。
- **零 LLM 环节**：D00（来源）、D01（读取，本地 OCR/ASR/确定性解析）、D05（发布，纯规则化）——这三层不产生 API 费用。
- **实测基准**：单次真实 run 约 **1 万 token 量级**（2–6 份材料）；模型 `deepseek-flash`，价格以厂商报价为准。

---

## 二、分规模等级的经济性判断与选择

按「主题数 × 材料份数」划分三个等级，每级有明确的**判断口径**与**选型策略**，不得跨级套用。

### 等级 L0｜样板 / 最小切片（1 主题，2–10 份材料）

- **判断**：单次 run ≈ 1 万 token，成本可忽略（低档模型毫厘级）。
- **选择**：**全链单档直跑**（DeepSeek flash），不引入分级降本、不做单价核算；本级的验收目标是「管道正确性」，不是「成本最优」。
- **成本验收口径**：只记录真实 token（阶段分布 + 缓存命中 + 重试次数），判断「管道能跑通且不失控」即可。

### 等级 L1｜单主题完整生产（1 镇，10–100 份材料）

- **判断**：token 随材料份数线性增长，D02 长输入开始主导成本，需要第一轮降本。
- **选择**：
  1. **D02 分级**：轻量档初筛 + 高档档深度（只对关键段精读，非关键段略读）；
  2. **缓存指纹复用**：相同「原文 hash + 提示词版本 + 模型版本」命中即不调用（样板试验已实测命中率 66%→71%）。
- **成本验收口径**：缓存命中率 + D02 分级前后的输入 token 对比，判断降本是否见效。

### 等级 L2｜多主题规模化生产（多镇，100+ 份材料）

- **判断**：单靠缓存与 D02 分级不够，需系统性降本，并进入单价核算与预算控制。
- **选择**：
  1. **向量检索预筛**：pgvector + 本地 embedding，长史料只喂相关段，不整卷喂入；
  2. **D03/D04 批量调用**：一次 LLM 调用产出多方法字段（禁止一法一调）；
  3. **规则化最大化**：D05 零 LLM、D00/D01 零 LLM 保持不动，压缩 D02–D04 调用次数。
- **成本验收口径**：单位材料成本 + 单价监控 + 预算上限；触发「不经济」信号即回退等级或换路由。

---

## 三、降本优先级（所有等级通用，按序执行）

1. **规则化优先**：能用确定性代码（D00/D01/D05）就不上 LLM。
2. **缓存**：输入指纹为键，命中不调用、不重复计费。
3. **D02 分级**：轻量初筛 + 高档深度。
4. **向量预筛**：长史料只喂相关段（L2 起）。
5. **D03/D04 批量**：一次调用多字段（L2 起）。

---

## 四、等级升级触发条件

| 当前等级 | 升级触发 | 前置动作 |
|---|---|---|
| L0 → L1 | 单主题材料 >10 份，或 D02 单次输入 token 显著增长 | 先核算 L0 真实 token，判断 D02 分级是否必要 |
| L1 → L2 | 多主题并行，或材料 >100 份 | 先核算 L1 单位材料成本，判断向量预筛/批量调用是否经济 |

> 原则：**每次升级前，用当前等级的真实 token 数据核算，判断升级是否经济；不凭估算或市场价目表升级。**
