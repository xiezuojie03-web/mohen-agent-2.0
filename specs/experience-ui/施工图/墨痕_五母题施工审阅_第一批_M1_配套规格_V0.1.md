# 墨痕｜五母题施工审阅：第一批 M1 配套规格 V0.1

本稿配套《墨痕_五母题施工审阅_第一批_M1_V0.1.html》。主要成果是可操作的施工图册，文字用于解释图中的决策、材料条件及验收边界。

## 1. 本批交付与审阅顺序

本批完成五母题整体索引及 M1「关系世界」完整实例「一座仓屋背后的交接生活」。共 25 页施工图，每页提供 1440×900 横屏、390×844 竖屏，共 50 个画面视图。另检查 390×667 短屏下的 9 个关键状态。

建议先打开 HTML 的「M1 完整体验」，顺着墨痕走完 12 帧，再进入「逐帧图册」检查每帧横竖屏、变化与依据。点击「操作这一帧」可以检验具体交互；「手机操作」提供独立手机视窗。「五母题总索引」标明后续四个母题的编排输入，不把尚未画出的条目计为完成。

本批包含：12 帧主线、3 页依据、3 页材料条件测试、2 页跨母题交接、5 页共用状态。跨母题页只是问题与材料的交接边界，不代表 M3、M5 已完成。

承接《墨痕_UI架构与人文叙事_完整审查及后续任务_V1.2》的分批任务，以及《墨痕_五母题叙事与生产深化主稿_V0.1》的叙事与生产要求；保留 V0.9.1 的双组件方向。原 V0.9.1 与 01/03/06 联动原型未改动。

## 2. 从理解变化到可见画面

本故事的理解成果是：用户从辨认三个建筑／地点，转为理解一次交接活动怎样把它们组织起来，以及仓屋在其中承担什么作用。画面依次增加对象身份、记录、运入关系、临时存放、交付关系，再构成全貌；不是在同一张关系图上只换旁白。

F08 让用户对照「只有对象」与「放回活动」。F09 限定这是一次有记录的交接，不补写无材料支持的关系变迁。F10–F12 把理解带回今天的观察，同时区分位置对应、原物保存和持续使用。后两项在本例中没有证据。

## 3. 用户界面与审阅界面

HTML 顶部的图册、索引、帧选择属于工程审阅导航，位于产品边框之外。产品内部仅保留两个一级组件：视觉舞台与墨痕。

收起、展开、布局和大小统一位于产品顶部同一区域；没有第二个收起入口。舞台不放上一帧、继续看、编号步骤等通用按钮。用户可点击对象、关系或材料词语；相应的替代操作、推进、追问与依据入口放在墨痕内。

### 尺寸与状态

| 项目 | 本批规则 |
| --- | --- |
| 横屏分区 | 左舞台右墨痕；默认约 70:30，墨痕宽度可调 24%–44% |
| 竖屏分区 | 上墨痕下舞台；默认约 34:66，墨痕高度可调 28%–48%，最低 216px |
| 悬浮 | 舞台使用完整区域，墨痕叠放其上；可拖动标题区、调整尺寸 |
| 收起／展开 | 用户在统一控制区主动切换；叙事推进不自动改变 |
| 阅读 | 墨痕正文独立滚动，底部追问、记录与必要的返回入口保持可达 |
| 对照 | 横屏并置；手机 F08 同位切换，两侧不挤压成不可辨的小图 |
| 关系 | 横屏按活动展开，竖屏按活动顺序纵向组织；箭头表示活动方向，不代表道路 |

内容快照与用户布局偏好分别保存。快照包括当前帧、选择对象、对照侧、观察焦点、滚动和追问；偏好包括显隐、停靠、尺寸与悬浮位置。查看依据、返回原问题、回看轨迹不覆盖用户最新布局。图册的 U01–U04 是独立状态样板，其初态不强加给连续探索。
