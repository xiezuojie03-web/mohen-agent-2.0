## 本轮结论

总体方向没有失效，但工作路径已经出现局部偏移。此前逐步深入了局部交互如何严谨，却没有同步推进用户真正需要的五母题完整叙事、UI 施工和数据生产规范。局部联动原型与最终交付之间缺少明确的对应关系和完成路径。

纠正方式：保留已经得到的有效结论，结束不断向下拆分局部问题的探索，按附录 A、B 的完整范围收拢成果。01/03/06 原型保留，定位为附录 B 的局部交互样例，暂不继续打磨。

## 一 用户目标

第一轮纪要已经记录：附录 A 的五个母题九项内容均须深化到直接指导 UI 设计和数据生产；附录 B 的六条方法须转为生产规则，并形成五母题达到 V0.9.1 深度的逐页逐帧表达。母题关系、共同要素与组件复用的讨论，服务于上述交付。

最终要回答：换到一个具体地方，研究与数据生产人员知道怎样组织材料，UI 设计人员知道怎样呈现，代码执行器知道怎样实现；面对材料差异，也有明确调整规则。

要消除的是职责、输入、判断规则和表达要求的含糊；历史本身的未知应当明确保留，不预先确定所有地方的历史答案。

## 三 联动原型的意义与限度

原型意图检验：用户从对象怎样联系转问对某个人意味着什么，再查看依据时，能否继续使用同一套对象和材料，并保留探索上下文。

- 单元 01 呈现东码头与市场之间的活动联系。
- 单元 03 在相同对象上增加接货、交付与通行限制。
- 单元 06 核对具体判断，再返回原来的问题。

单元 06 是共用依据能力，不是第六个母题；单元 01、03 也不是 M1、M3 的完整叙事。它们只围绕一项区别展开。

可以提炼的规范：哪些对象、判断和状态需要共用；问题改变时舞台如何发生有意义的变化；依据绑定哪项判断；返回恢复什么、用户布局保留什么。

不能由此认定：五母题叙事完整；用户已理解母题区别；组件已适用其他内容；故事有吸引力并连接当下。上次只完成有限脚本和交互检查，未完成浏览器视觉验收，更未验证用户理解效果。

因此，原型归回附录 B 的局部交互样例，不继续成为深化中心。

## 四 路径偏移的四个方面

### 1 完整叙事让位于局部正确性

避免误连关系、不补造路线、不把先后当因果是必要规则，但逐渐占据主要篇幅。普通人为何愿意看、哪次发现值得停留、理解怎样展开、人物处境怎样可感知、如何改变散步旅行或审美体验，没有获得同等深化。

V1.3 第 7 节明确：解释可追溯、已知未知可区分是基础条件，不能替代好奇、展开、人的生活、理解变化和当下连接五项体验要求。后续工作必须恢复这一比例。

### 2 缺材料的检验场景承担了过多任务

S1—S7 特意保留缺口，适合检查材料不足的处理。第四轮承认 M2 只有成因线索，M4 尚未完成机制解释。这组材料不能独自承担五母题正常展开的全部示范，否则体验容易停留在不断说明不能确定。

后续分别设计材料足以支持解释时的充分展开，以及不足、冲突、反证时的调整。通用阶段可使用明确标注的假设条件；实际历史仍由实际材料决定。

### 3 组件复用提前成为主线

用户提出复用是为减少重复、保持一致。不能在尚未看全五母题需求时，围绕几个对象冻结组件。组件应从足够完整的叙事与画面需求归纳，避免只擅长桥、码头、市场，却不能承载结构、生成、延续或器物与跨地域联系。

### 4 缺少讨论转生产规格的步骤

判断有依据已讲清，但生产者仍需要知道记录什么、怎样填写核验、怎样交给画面。返回原问题仅解决一类交互，没有补齐采集、整理、解释、素材、画面的整体对应。

## 五 调整后的交付路径

成果收敛为一份独立深化主稿和一套配套施工审阅原型。五轮纪要保留为依据，不承担当前规范角色。

| 步骤 | 工作 | 交付 | 完成标准 |
|---|---|---|---|
| 1 | 归并五轮结论，分清采用、修正、待验证 | 目录、覆盖表、采用规则 | 重要结论有归属，缺项可见 |
| 2 | 五母题九项同深度深化，补齐完整展开、分支、当下连接 | A 独立深化正文 | 有可执行要求与示例，不仅是原则 |
| 3 | 落实 UI 与数据对应 | B 六条生产规格 | 画面知道需要什么数据，数据知道用于何问题 |
| 4 | 五母题主流程、分支、返回逐页逐帧绘制 | 达到 V0.9.1 深度的审阅原型 | 叙事连续，画面、墨痕、操作、数据对应 |
| 5 | 从样稿归并组件并结合材料检验 | 组件规格、缺口与验收记录 | 共用能力覆盖需求，特殊表达不被抹平 |

数据和画面相互校验。金泽材料盘点可在通用要求初步明确后并行进行，不必等所有标准定死；不能先选主母题再反向缩减五母题方法。

### 附录 A 九项深化要求

| 项目 | 实际提供的内容 |
|---|---|
| 核心追问 | 典型问题、子问题、回答范围和完成标准 |
| 适用与不适用 | 启动材料条件、适用场景、停止或调整方式 |
| 入口直觉 | 不同入口、好奇来源，不预设用户有误解 |
| 认知进程 | 节拍中的问题、发现、理解增加、依赖与跳转 |
| 判断与证据 | 各判断需要什么支持、核验办法及部分成立条件 |
| UI 表达与操作 | 舞台、墨痕、用户操作与变化逐节拍对应 |
| 数据生产 | 记录、口径、来源位置、缺失处理、核验和填写样例 |
| 不足冲突反证 | 触发条件、叙事调整、画面响应与返回 |
| 当下连接与验收 | 具体生活连接及理解、兴趣的检查办法 |

完整性表现为每个认知节拍都可追溯到判断、材料、画面和操作；不能九项分别很长但相互对不上。

### 附录 B 六条深化要求

| 原条目 | 具体成果 |
|---|---|
| B1 | 节拍与构图、空间表达、交互能力对应及选择条件 |
| B2 | 组件职责、输入、状态、操作、联动、返回、响应式规则；局部原型作为样例 |
| B3 | 来源到事实、判断、素材、画面的流程、填写模板和完成样例 |
| B4 | 五母题盘点表、覆盖判断、缺口与检索任务，不预选主母题 |
| B5 | 自然转入条件、携带上下文、新增判断、证据不足、新母题接入 |
| B6 | 方法、材料、UI、理解分别验收，有通过和不通过例子 |

先明确 B3 内容标准，再映射现有数据模型，不重建数据库，也不把含糊留给执行器。

## 六 当下决策

直接进入独立深化主稿编制，将五轮结论归位并展开五母题九项。不再以新的边界讨论作为启动前提；仅在编制中遇到会实质改变设计的问题时单独讨论。

01/03/06 原型保留，暂不继续打磨。由完整叙事和生产规格决定其后续保留或调整。
