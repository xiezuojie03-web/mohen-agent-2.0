## 一、讨论缘起与用户目标

用户认可“通用方法与场景验证”分为两层，但认为 V1.3 的附录 A、B 远不足以承担最终的通用方法成果。尤其需要明确：“五个母题应先达到同一深度的可审阅版本”，究竟指现有附录，还是下一步需要完成的成果。

用户提出的最终深化目标包含两层：

1. **深化附录 A 的九项内容。**以现有附录为基准，形成独立一稿。每个母题的九项内容都要继续拆解，达到直接指导 UI 设计与数据生产的深度，避免下游依赖猜测补齐关键含义。
2. **把附录 B 从方法论推进到施工与生产。**六条内容均认可，但需落实为具体设计。如果不能一步到位，可先细化六条，再据此完成五个母题各自达到《墨痕 · V0.9.1 施工审阅》深度的表达。

在上述工作之前，用户提出优先开放讨论：五个母题并不孤立，而是从不同角度理解同一个地方，也很可能对应未来用户不同的探索询问方向。按“第一性原理”的思路拆解，可能发现共同的构成要素，进而帮助设计归属于“视觉舞台＋墨痕”两个一级组件的二、三级组件。

本轮所说的“第一性原理”，作为拆解问题、寻找共同基础的工作思路使用，不作为某种已经论证完毕的组件理论。

### 1.1 当前成果深度的明确纠正

现有附录 A、B 只是**五母题方法框架的初稿**，尚未达到能够直接指导 UI 设计和数据生产的可审阅施工稿。

此前把“方法卡写齐”表述为“方法深化完成”，完成标准偏低。五个母题目前达到的是相近的提纲深度；九项内容没有逐项完全拆解，附录 B 也没有落实到具体画面、交互状态以及数据输入输出。

因此，“五母题达到同深度的可审阅版本”需要区分：已有相近深度的初步方法卡；用户要求的独立深化稿和施工深度仍属于后续工作，不能按已完成处理。

### 1.2 本轮最新决定

用户确认：

> 这次的探讨非常有价值，值得沉淀文档，避免聊天丢失；也非常赞同你最后一段的判断，先不急于深化附录 A、B，要把这轮问题辨清。

本轮据此只沉淀讨论。下一轮先辨清母题各自不可替代的理解变化、共同操作和特殊表达，再进入附录 A、B 的深化。

## 二、五个母题之间的关系

### 2.1 五种相互可进入的追问

五个母题可以理解为观察同一个历史生活世界的不同角度，共享大量对象、材料和理解操作。

| 母题 | 核心观察角度 | 在同一地方中着重追问什么 |
| --- | --- | --- |
| M1 消失的关系世界 | 联系 | 这些对象通过谁的什么活动发生联系？ |
| M2 一个地方为什么会长成这样 | 结构 | 为什么会出现这种分布、重复、差异和组织方式？ |
| M3 过去的人生活在怎样的地图里 | 行动者的视角 | 对不同的人而言，哪些地方重要、可达、有用或受限？ |
| M4 一个地方究竟怎样活起来 | 生成与变化过程 | 哪些条件和行动，使地方从一种状态变成另一种状态？ |
| M5 今天到底还剩多少过去 | 延续与断裂 | 这些对象、关系和生活方式，哪些延续到了今天，怎样延续？ |

这五种角度并不完全处于同一个分类层级。例如，M3 能为其他母题提供“从谁的角度看”的视角；M5 能接续其他母题，将理解重新联系到今天。这是本轮提出的关系判断，仍需在后续拆解中检验。

没有必要强求五个母题边界互斥，也不必要求用户先选母题才能进入。它们更适合作为墨痕组织问题的内部方法，而不是五个必须轮流浏览的栏目。

用户问“这里为什么有这么多桥”，可能从 M2 进入；接着问“当时谁需要经过这些桥”，转入 M3；再问“桥和附近市场是什么关系”，进入 M1。问题可以自然生长，界面不必表现为三次栏目切换。

### 2.2 不把当前五种追问认定为穷尽分类

五个母题是当前选定的五种有效追问，不必宣称它们已穷尽人文历史的所有问题。保留开放性，未来才可能自然容纳器物、人物、跨地域传播等方向。

“同一个地方”是此次讨论的重要观察范围，也不应因此成为墨痕全部内容的边界。时间、空间和关系服务于理解历史，最终仍须连接当下生活的乐趣与意义。

## 三、从共同构成到 UI：必须分开的三个层次

不能从“存在共同的数据要素”直接跳到“应该使用同一组 UI 组件”。需分别讨论：历史由什么构成、我们如何知道这些历史、人怎样发生理解变化。

### 3.1 第一层：历史生活世界本身

暂时不使用母题名称，需要理解的共同内容可以作如下候选拆分：

| 共同内容 | 要回答的问题 |
| --- | --- |
| 人与群体 | 谁在这里生活、行动？不同群体是否有不同处境？ |
| 对象与环境 | 他们面对什么建筑、器物、河流、道路及自然条件？ |
| 活动与目的 | 人们做什么，为什么做，受到什么限制？ |
| 联系与组织 | 人、物、地方通过什么发生联系？有哪些制度与组织方式？ |
| 时间中的状态与变化 | 某时是什么样，后来哪里发生变化？ |
| 与今天的连接 | 今天还能看到、使用、感受或重新理解什么？ |

时间和空间贯穿这些内容。一条联系须说明在什么时期、什么范围、通过什么活动成立。此表是共同内容的讨论性拆分，不是已经冻结的数据表或字段标准。

### 3.2 第二层：凭什么知道，以及知道到什么程度

地方志、照片、舆图是材料；“某处曾是交易节点”是一项判断；“交易活动促成周边街道发展”是进一步的解释。它们不能合并为未经区分的历史知识点。

五个母题共享的基础，还应保留：

- 材料究竟记载或显示什么。
- 材料支持哪项判断，支持到什么范围。
- 哪些属于解释，哪些存在分歧，哪些仍然不知道。

**共享同一材料，不意味着能够共享同一结论。**一张地图可能支持某时期存在一条河，却不能独自证明这条河承担了主要贸易功能。

### 3.3 第三层：用户怎样发生理解变化

这一层直接连接 UI。候选的共同理解操作包括：

| 共同理解操作 | 用户发生的变化 |
| --- | --- |
| 辨认与定位 | 从不知道看什么，到知道当前关注哪个对象 |
| 联系 | 从几个孤立对象，到理解它们如何发生作用 |
| 比较 | 从看起来相似或不同，到知道差异发生在哪个方面 |
| 局部与整体转换 | 从看到一个细节，到理解它在整体中的位置 |
| 追踪变化 | 从知道前后状态，到理解变化过程与可能原因 |
| 改换视角 | 从用今天自己的眼光看，到理解另一类人的处境 |
| 核对与修正 | 从接受一种解释，到知道依据及其边界 |
| 回到当下 | 从知道过去，到重新观看、体验或选择今天的生活 |

这些反复出现的理解操作，是可复用 UI 的重要候选基础。它们比按“桥梁组件”“寺庙组件”划分，或给五个母题各做一套页面，具有更强的复用潜力。

但目前尚未证明八项操作已足够、互不重复或均应独立组件化，下一轮仍须检验。

## 四、共用基础与母题独特性应同时保留

不能因为五个母题都能拆出人、物、时间、地点和关系，就认为它们没有区别。

相同材料和对象，在不同母题中承担的解释任务不同：

- M1 要证明联系怎样成立。
- M2 要解释为什么形成这种整体结构。
- M3 要理解对谁而言，这种空间组织有意义。
- M4 要解释变化怎样发生。
- M5 要辨别什么以什么方式延续下来。

例如，M2 和 M4 可以使用相同的分期地图。M2 用它们检验分布结构；M4 用它们识别变化阶段。**相同画面不自动意味着相同叙事；解释要求和验收标准仍然不同。**

未来定义每个母题时，应明确：从什么问题进入，重点关注哪些关系，需要完成什么理解变化，需要哪些证据支持，以及什么时候应当停止或保留未知。

这正是附录 A 的九项仍需深入的原因：它们规定各母题如何组织共同能力，不能被一个通用组件清单替代。

## 五、两个一级组件下的候选能力组织

### 5.1 先讨论能力，再决定组件边界

以下划分用于讨论，不作为最终施工结构；不据此新增永久面板、工具栏或数据库核心对象。

| 一级组件 | 可考虑的二级能力组织 | 可复用的三级表达或交互单元举例 |
| --- | --- | --- |
| 视觉舞台 | 对象与材料呈现 | 对象聚焦、图像细节、原文定位、空间范围 |
| 视觉舞台 | 关系与活动呈现 | 关系高亮、活动节点、方向与障碍、对象联动 |
| 视觉舞台 | 比较与变化呈现 | 对照视图、分期状态、差异标示、连续性层面 |
| 墨痕 | 当前问题与叙事引导 | 当前追问、简短解释、对已选对象的回应 |
| 墨痕 | 判断与依据 | 具体判断、来源片段、支持范围、冲突与未知 |
| 墨痕 | 探索与承接 | 后续追问、视角选择、探索回顾、返回入口 |

二级能力组织不意味着把墨痕切成三个永久面板，也不意味着给舞台增加三个工具栏。这些能力可以按当前问题组合，继续服从双组件体验。

已有五种舞台构图、历史空间表达方式与母题仍需区分。此处讨论的是共同能力，没有将三者按数量或名称一一绑定，也没有用候选列表替换既有舞台构图。

### 5.2 跨组件配合与探索连续性

有些理解任务必须由两个一级组件共同完成：

- 点击舞台中的一条关系，墨痕解释它为什么成立。
- 在墨痕追问依据，舞台定位到原件相关部分。
- 在墨痕选择另一类行动者，舞台突出与其活动相关的节点。

两者必须共同知道：当前问题、关注对象、时期、已看过的判断，以及用户从哪里进入这个分支。否则，即使单个组件做得漂亮，跨母题探索仍会断裂。

用户选择的分区、悬浮和尺寸继续保持稳定。变化的是容器内的观察内容和叙事组织。此处的能力复用不得成为自动改变用户布局的理由。

## 六、假设探索示例：共同能力如何承接不同问题

**以下仅用于检验方法，是假设示例，不是对金泽历史事实的判断，也不是已经验证的固定故事。**

入口：用户看到一座桥，问“为什么这个地方有这么多桥？”

| 用户接着问 | 当前探索重点 | 能复用什么 | 必须新增核验什么 |
| --- | --- | --- | --- |
| 桥真的很多吗，集中在哪里？ | M2：整体结构 | 对象定位、范围与分布 | 统计范围、时期、遗漏与保存差异 |
| 当时哪些人需要经过这里？ | M3：人的空间 | 同一批对象与空间 | 群体、目的、可达条件 |
| 桥和附近市场有联系吗？ | M1：活动联系 | 已关注的桥、市场与时期 | 二者之间具体活动的证据 |
| 这种联系是什么时候形成的？ | M4：变化过程 | 已建立的关系与判断 | 阶段、转折及机制依据 |
| 今天还能看出这些联系吗？ | M5：当代延续 | 历史对象、关系与材料 | 今日状态与连续性证据 |

这个例子说明：**问题可以连续，证据需要逐项核验。**前一个母题成立，不能默认后一个成立；转入另一个母题，也不能把用户刚建立的理解清空。这条路径不是五母题必经顺序，用户可以停留、跳转、返回或提出新问题。

用户最终获得的体验可以很轻：下次走到桥边，愿意多看看桥与街口的方向，想知道旧市场的位置，或产生一次绕路观察的兴趣。背后的研究组织可以严谨，前台不必变成研究工作台。

## 八、下一轮首先要辨清的问题

下一轮继续开放讨论，核心命题是：

> 五个母题各自不可替代的“理解变化”是什么；完成这些变化，需要哪些共同操作，又有哪些确实不能通用的特殊表达。

为使讨论能够逐渐落地，可按以下顺序推进。此顺序是对本轮结论的工作整理，不是已经冻结的任务书。

| 顺序 | 要辨清的问题 | 辨清后的可审阅结果 |
| --- | --- | --- |
| 1 | 每个母题让用户从什么理解，走向什么新理解？ | 五母题“原理解—理解转折—新理解”对照，避免只换标题而过程相同 |
| 2 | 哪些母题交叉，哪些作用不可相互替代？ | 重叠、差异及自然转入条件；允许一个问题涉及多个母题 |
| 3 | 完成这些变化需要哪些共同操作？ | 共同操作与母题的对应；检查八项候选操作的遗漏和重复 |
| 4 | 哪些特殊表达无法被通用操作充分承载？ | 需要专门表达的原因及适用边界；避免过度通用化 |
| 5 | 哪些能力应成为组件，哪些只是内容、状态或编排？ | 两个一级组件下的候选职责与配合关系；不按概念数量机械创建组件 |
| 6 | 跨问题探索时，哪些理解和上下文必须延续？ | 已知判断、证据、当前焦点与返回关系的承接原则 |

讨论充分后，再决定独立深化稿的结构与施工颗粒度，进入附录 A 九项、附录 B 六条的系统深化，随后形成五母题的逐页逐帧表达。

## 九、后续衔接时应保留的边界

- 通用方法可以先行；具体历史结论必须由材料支持。
- 共同要素、材料和操作可以复用；不同母题的解释任务不能被抹平。
- 组件服务于理解；不能因组件复用而把五个母题讲成同一种故事。
- 母题转换应承接已有探索；不能默认新问题的证据已经齐备。
- 两个一级组件的大方向及用户布局控制权继续有效。
- 原型或示意可以用于检验表达，但必须与真实史料验证区分。
- 历史理解最终可以落到观看、散步、旅行、审美、比较和生活兴趣，不能只剩沉重的意义阐述。
- 本轮不修改 V1.3，不更新施工原型，不发出代码或数据生产任务；保留讨论成果，为下一轮判断提供共同依据。
