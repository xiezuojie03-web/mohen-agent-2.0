# 《墨痕 Agent 2.0 Agent Experience & UI 交互设计 V1.0》

**项目：沪上经纬·墨痕 Agent 2.0**  
**版本：V1.0**  
**日期：2026-09-19**  
**定位：把《墨痕 Agent 2.0 三层架构设计 V2.0》的 Agent 能力转化为用户可感知的入口、体验状态、空间变化与行动界面。**

## 0. 本文解决什么

V2.0 已经定义：

`Context → Understand → Goal → Plan → Skill → Tool → MCP → Evidence → Relation → Discovery → Story Seed → Experience State → Renderer → Observe → Replan`

本文件解决另一个问题：

> **当墨痕真的在工作时，用户到底看到什么？**

核心原则：

> **不要让用户“看见 Agent 在思考”，而要让用户“看见世界正在被重新组织”。**

V2.0 明确：页面不再是探索逻辑的主人，Agent 才是；ExperienceState 是当前体验，Agent 是 Experience Director。fileciteturn25file0L11-L42 fileciteturn25file2L227-L280

# 1. 从“网站 + AI”转向“Agent Experience Space”

## 1.1 现在的网站模式

```text
首页
 ↓
地图页
 ↓
古镇页
 ↓
专题页
 ↓
内容节点
 ↓
聊天框
 ↓
回答 / 卡片 / 页面跳转
```

用户需要先理解“应该进入哪个页面”。

## 1.2 Agent 2.0 模式

```text
用户目标 / 空间 / 行为
          ↓
       墨痕 Agent
          ↓
    理解当前探索任务
          ↓
      自主研究与发现
          ↓
     ExperienceState
          ↓
 ┌────────┼─────────┐
 ↓        ↓         ↓
地图     时间      内容
 ↓        ↓         ↓
关系     图片      故事
 └────────┼─────────┘
          ↓
      ExperienceAction
          ↓
        用户继续
          ↓
       Observe
          ↓
        Replan
```

V2.0 的目标正是从“用户 → 页面 → 组件 → 墨痕”转向“用户 → Agent → Goal → Plan → Tool/Skill → Evidence/Relation/Discovery → Experience State → UI变化”。fileciteturn24file2L193-L251

---

# 2. 一句话定义新的 UI

> **墨痕 UI 不是让用户操作网站的界面，而是让用户进入、观看、追问和继续行动的人文探索空间。**

传统 UI：

```text
用户 → 找功能 → 点页面 → 看内容
```

墨痕 UI：

```text
用户 → 表达意图 → 墨痕组织空间 → 用户发现 → 继续探索
```

---

# 3. Agent 的智能必须“显形”

不要通过“AI正在思考”表现智能，而通过真实的界面变化表现：

| Agent 智能 | 用户看到的变化 |
|---|---|
| 理解地点 | 地图自动聚焦 |
| 理解时间 | 时间轴进入相关年代 |
| 理解目标 | 自动选择体验模式 |
| 发现关系 | 地图出现关系线 |
| 找到证据 | 文献 / 来源 / 图像出现 |
| 形成故事 | 出现叙事入口 |
| 判断下一步 | 出现少量有意义行动 |
| Replan | 追问后原空间继续变化 |

如果 Agent 调用了很多工具，但屏幕没有发生有意义的变化，用户不会感受到 Agent 的能力。

# 4. 总体界面：Persistent Experience Space

建议基础容器：

```text
┌──────────────────────────────────────────────────────┐
│  墨痕                              上海 · 当前探索    │
├──────────────────────────────────────────────────────┤
│                                                      │
│                  EXPERIENCE SPACE                    │
│                                                      │
│        地图 / 历史地图 / 图片 / 关系 / 故事          │
│                                                      │
│                                                      │
├──────────────────────────────────────────────────────┤
│  时间轴 / 当前焦点 / 探索状态                         │
├──────────────────────────────────────────────────────┤
│  墨痕：一句自然语言入口                     [继续]   │
└──────────────────────────────────────────────────────┘
```

这是 Persistent Shell，不是固定页面布局。

内容由 ExperienceState 决定。

V2.0 已将现有 `/map`、`/stories`、`/nodes/[slug]` 等重新定位为 Agent 可以调用的体验空间，而不是固定网站栏目。fileciteturn24file6L539-L607

## 长期存在

- 墨痕入口
- 当前空间位置

- 时间轴容器

## 动态变化

- 地图中心

- Story
- Evidence

所以：

> **不要把每一种体验都设计成一个新页面。**

# 9. Screen 03｜Discovery：不是搜索结果，而是“发现”

Discovery 是最重要的用户体验单元之一。

```text
┌──────────────────────────────────────────────────────┐
│                  南翔历史空间                         │
│                                                      │
│                         ●                            │
│                       ╱   ╲                          │
│                     ●       ●                        │
│                                                      │
│       ┌────────────────────────────────────────┐     │
│       │ 墨痕发现了一条线索                       │     │
│       │                                        │     │
│       │ 为什么南翔会长成今天这个样子？          │     │
│       │                                        │     │
│       │ 我找到了一条连接空间变化与历史发展的线索。│     │
│       │                                        │     │
│       │             [沿着线索看看]              │     │
│       └────────────────────────────────────────┘     │
└──────────────────────────────────────────────────────┘
```

Discovery 必须尽量包含：

1. 值得继续的理由
2. 空间 / 时间 / 人物等视觉钩子
3. 明确行动
4. 必要时的证据入口

它不能退化成：

`标题 + 摘要 + 查看详情`

# 11. Screen 05｜时间不是筛选器，而是 Agent 的叙事镜头

传统：

> 用户自己拖时间轴。

Agent 2.0：

> **Agent 决定什么时候改变时间，以及为什么改变。**

例如：

```text
“这里以前是什么？”
→ time.compare(历史, 现在)

“为什么会变成这样？”
→ time.set(关键时期)
+ map.showLayer(变化因素)
+ story.reveal
```

因此时间轴承担的是：

> **把历史变化变成可观看的时间结构。**

用户：

> “为什么会变成现在这样？”

```text
        ↓

变化原因
新证据
新关系
新故事段落
```


# 15. Screen 09｜Replan：沿当前世界继续推理

Replan 必须保持：

```text
Spatial Continuity
Temporal Continuity
Narrative Continuity
```

也就是：

- 我还在这里
- 我还在这条历史线上
- 我刚才的发现仍然成立

只有目标真的改变时才 Replace。

V1.1 明确：用户继续追问时应优先 Patch，只更新变化部分。fileciteturn25file7L624-L651

# 20. 墨痕不应该永远是右下角聊天框

建议墨痕有三种状态：

```text
                墨痕
                  │
        ┌─────────┼─────────┐
        ↓         ↓         ↓
     Ambient    Guide     Dialogue
        │         │         │
     常驻感知    主动引导    用户提问
```

### Ambient

只保留很轻的入口。

### Guide

发现重要线索时进入体验空间。

### Dialogue

用户需要主动提问、澄清、纠正时展开。

因此：

> **聊天是墨痕的一种状态，不是墨痕的全部形态。**

# 21. “下一步”必须从固定菜单升级为 Agent Proposal

当前 `nextSteps` 容易变成固定推荐。

V2：

```text
Agent Proposal
```

根据：

```text
当前 Goal
+
ExperienceState
+
已探索内容
+
未解决问题
+
Discovery
+
可用工具
```

动态产生。

例如：

```text
第一次进入：
[看看这里以前是什么]

已经看过历史：
[为什么会变化]

已经看过变化：
[找一个人物]

已经看过人物：
[看看他的文献]

已经看过文献：
[把这条线走一遍]
```

这就是“引导”，不是“菜单”。

```text
时间发生变化
      ↓
我看到相关证据
      ↓
我继续问
      ↓
它记得刚才的内容
      ↓
空间继续变化
      ↓
它提出下一步
      ↓
最后把故事变成现实路线
```

这就是 Agent 的可感知层。

# 25. 地图、时间、故事：三个第一表现层

## Map = Experience Canvas

承载：

- 地点
- 历史地点
- 人物
- 事件
- 关系
- 时间
- 路线
- 变化
- Discovery

## Timeline = Narrative Lens

不是筛选器，而是让历史变化成为可观看的时间结构。

## Narrative = Spatial Layer

故事覆盖在空间上，可以从：

- 地图对象
- 时间节点
- Discovery
- 人物
- 文献

进入。

# 38. 最终判断标准

以后判断墨痕 UI 是否真正进入 Agent 2.0，不问“页面好不好看”，而问：

1. 用户能否不用理解网站栏目就开始探索？
2. 一句话能否成为 Agent Goal？
3. Agent 能否改变地图？
4. Agent 能否改变时间？
5. Agent 能否产生可验证 Discovery？
6. 用户追问后空间是否连续？
7. 是否能根据已探索内容避免重复？
8. 是否能提出真正下一步？
9. 故事是否能转化为现实行动？
10. **如果删除聊天窗口，Agent 是否仍然存在？**

前 9 项成立，第 10 项也成立，才可以说 Agent UI 真正成立。

# 39. 本版最终结论

墨痕 2.0 的 UI 不应该继续围绕：

> 首页、地图页、古镇页、故事页、聊天页

而应该围绕：

> **入口 → 理解 → 发现 → 进入 → 时间变化 → 故事 → 追问 → Replan → 路线 → 行动**

因此：

> **页面是容器，组件是能力，ExperienceState 是当前体验，Agent 是体验导演。**

用户真正感受到的 Agent，不是“它说了什么”，而是：

> **“我说了一句话，它让眼前的世界发生了变化，而且它知道下一步带我去哪里。”**
