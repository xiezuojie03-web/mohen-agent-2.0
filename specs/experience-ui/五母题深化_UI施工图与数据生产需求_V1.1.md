## 1. 不可妥协的红线（来自 C4 + V0.9.1 + 主稿 + Review）

1. **双组件唯一**：视觉舞台 + 墨痕叙事，两个一级承载区；不增第三证据栏；故事在双组件内部推进，不另开文章详情页。
2. **命名空间消歧**：`C01–C05`=V0.9.1 **构图**（单景/对照/原件细读/关系观察/连续镜头）；`S01–S05`=V0.9.1 **历史空间表达**；`U01–U07`=墨痕**组件状态**；`N01–N12`=V0.9.1 **M2 示范节拍**；`Mx-P0n`=主稿**各母题认知节拍**；`Mx-C0n`=主稿**各母题判断**（与构图 C 重名，实现层必须加前缀区分）。母题是「问什么」，与 C/S/N/U 多对多。
3. **C/S 按理解任务选择**，不按母题编号绑定；S 是条件分支（原图阅读/关系示意/可定位表达等），非精度升级；无精确定位不配准，无历史外观不生成式复原。
4. **用户布局选择优先**：悬浮/分区/尺寸、显隐，在母题切换、节拍推进、追问、回退、依据中保持；只有用户主动改变才变。
5. **对接既有模型，不新建事实库**：所有字段映射到 `ExperienceState / CompositionState` 与 `L0–L4`；不平行状态架构。
6. **证据诚实**：每条 `Claim / Relation / Place / HistoricalFeature` 可回溯 ≥1 `Evidence`→`Source`；重建 geometry 标 `reconstruction_status`，不伪装测量事实；缺失显式记录，Agent 不得补齐为事实；判断状态须为 支持/部分支持/冲突/尚未证实/已被反证。
7. **历史视觉**：仅可溯源原图 / 现代现场图 / 注释 / 数据驱动重建；首期禁生成式历史场景图。
8. **时间不是工具条**：时期、对象出现/消失、关系在哪个阶段成立，均为**画面内容**；切换操作放墨痕或通过视觉要素完成，不恢复舞台工具条；不把舞台清净变成时间的消失。
9. **墨痕内工具不堆成控制面板**：固定「继续看/前后步」应逐步转为有意义的 **Proposal**（如「看看这项联系在哪个时期成立」）；缩放、对照等辅助可保留，但不能替代叙事引导。
10. **依据绑定具体判断**：查看依据须对应「某判断 → 某材料 → 某位置 → 支持范围」；冲突时呈现不同说法怎样影响当前理解，不停留在通用说明框。
11. **开发总工程师硬边界**：禁止重做一套独立 Agent UI；以现有 `ExperienceShell` / `resolveComposition` / `selectReplanSurface` 承载。
12. **四类待补画面为验收硬要求**（§8）：时间镜头、人物行动、证据修正、动态 Proposal+Trail 必须落实，不新增常驻面板。

## 3. M1 · 消失的关系世界

**① 核心追问**：这些看似独立的对象，在明确历史时期，是否因人的活动构成有作用的联系？须说明谁、为何活动、对象各有什么作用、哪些联系能被证明。子问题：哪些对象值得联系→发生什么活动→为何需要这些对象→联系何时有效→后来是否改变→今天怎样重新辨认。

**② 适用与不适用**：完整解释至少需可识别的关系两端、可核查活动/联系记载、相容时间范围。空间邻近只构成入口；关系变化需另外证据，不能从今日遗存推断历史联系消失。不适用于仅两同名对象、仅旅游解说无出处、跨年代无承接证据的确证展示。与 M3 区别：本题优先解释联系如何运作；行动者选择条件作深入分支。

**③ 入口直觉**：现场入口「这座仓屋为什么靠着这处埠头」；图像入口「这张画里哪些地方参与同一件日常事」；器物入口「一件东西怎样从这里到另一个地方」。首项发现须尽早出现（如账目同时出现的交接节点）。前台不用母题名与研究术语。

**④ 认知进程（节拍）**

| 节拍 | 用户疑问 | 新增理解 | 常用构图/空间 | 进入下一步条件 |
|---|---|---|---|---|
| M1-P01 | 眼前几个对象有关系吗 | 识别对象及联系问题，暂不作结论 | C01 单景 / C04 关系(待连虚线) / S03 | 对象身份与范围明确 |
| M1-P02 | 记录里谁在做什么 | 找到可核查活动与参与者 | C03 原件 / S05 | 活动可定位到材料 |
| M1-P03 | 为什么活动经过这些对象 | 对象分别承担交接/生产/治理等作用（主转折） | C04 关系 / S03；输入 M1-C01、C02 | M1-C01、C02 支持 |
| M1-P04 | 这组联系解释怎样的生活 | 从单条联系扩展到材料实际覆盖的活动组织 | C04 / S03 | 不把少数记录扩大为全部生活 |
| M1-P05 | 后来哪些关系改变了 | 有材料则比较变化；无则只解释该时期 | C02 对照 / S05；M1-C03 可用否则跳过 | 变化判断可用或跳过 |
| M1-P06 | 今天我会怎样重新看 | 将有据联系对应今日可辨痕迹或观察问题 | C01 / S03；M1-C04 | 可定位则远程观察，否则说明 |

**⑤ 判断与证据（M1-C0n，注意与构图 C 重名，实现须加前缀）**

| 判断 | 核对内容 | 可用支持 | 不可据此推断 |
|---|---|---|---|
| M1-C01 对象间存在某活动联系 | 两端身份、活动、有效时期 | 交接记录、行程、交易、制度执行记录 | 相邻/同名/同时出现就有关联 |
| M1-C02 对象承担某种作用 | 谁使用、用途及适用范围 | 使用记载、作业记录、可核实研究 | 建筑形态单独决定实际用途 |
| M1-C03 关系形成或改变 | 前后状态与改变依据分别 | 分期/停用迁移/事件/研究 | 某处今日消失=整个网络消失 |
| M1-C04 今日仍有可辨关联痕迹 | 今日对象与历史身份对应 | 现场/沿革/图像/定位 | 今日形似=原物或功能延续 |

**⑥ UI 表达与操作（每节拍）**

| 节拍 | 舞台要表达 | 墨痕与操作 | 输入 |
|---|---|---|---|
| P01 | 单景或并置呈现对象，暂不连线 | 提出联系问题；选对象可换入口 | 对象身份、入口素材、当前范围 |
| P02 | 原件片段与相关对象对应 | 概括活动；按需进入来源定位 | 活动观察、材料定位 |
| P03 | 关系观察，注活动及方向；路线未知用示意 | 选联系说明作用与依据 | M1-C01、C02、关系端点与类型 |
| P04 | 只增加有据角色与相关对象 | 追问某角色如何参与；保持原对象 | 参与者、作用及范围 |
| P05 | 有可比条件时对照关系状态 | 解释变化；缺材料直接进 P06 | M1-C03 或缺口原因 |
| P06 | 今日痕迹与已理解关系呼应 | 给值得观察的具体问题；可返回旧关系 | M1-C04、今日素材或无法定位说明 |

位置示意与历史地理不能混同；无路线不播沿线行走；关系类型与时期为必要内容，不可隐藏（删去易被误读为常年真实路线）。

**⑦ 数据生产（专用字段为主 → 映射 L0–L4）**

| 专用字段 | 填写要求 | 缺失处理 | 映射到 L0–L4 |
|---|---|---|---|
| 关系两端 | 稳定对象身份；重名另附区分 | 身份不明先不合并 | Entity + Relation(subject/object) |
| 活动与参与者 | 实际动作、目的、个体/群体范围 | 不补写无记载人物经历 | Event / Relation(predicate) |
| 角色与方向 | 对象在活动中作用，方向是否有据 | 未知方向不画箭头 | Relation 属性 + Claim |
| 有效时期 | 记录覆盖日期/区间及精度 | 不延长到整个朝代 | Event 时间 + DATA_CONTRACT 时间六类 |
| 空间表达资格 | 精确位置/近似范围/纯关系示意 | 无几何仅用示意 | Place(精度/reconstruction_status) |
| 支持与反对观察 | 逐条引用内容定位与支持范围 | 无反证≠已排除其他 | Evidence(L2)→Source(L1) |
| 变化与今日对应 | 分别引用 M1-C03、C04 | 未知不产消失/延续结论 | Claim + Relation(变化) |

**⑧ 不足/冲突/反证**：仅存在记录时 P02 后停「对象已知、联系待查」，可转对象细读；有关系无路线则正常进 P03 示意；无变化材料跳过 P05 不造失落结局；身份冲突先并列再暂停受影响关系。反证移除确定性联系、保留问题与撤回说明；有效时期收窄则修订范围不删全部。转 M3 携带对象/活动/时期另核目的与限制；转 M5 另核今日对应，不沿用历史关系作今日事实。

**⑨ 当下连接与验收**：看懂仓屋与埠头朝向关系、散步中寻找交接空间痕迹、重新理解一件日常物的来路。内容验收：C01/C02 当前范围有支持，C03/C04 另有所据。UI 验收：无完整旁白用户仍能辨认对象与关系含义。体验验收：是否因一个具体对象愿意继续问、哪一发现使对象产生新意义、回今天想观察什么；只记三个地名或只记「很多不知道」不判完成。单次只形成一条小而有据联系也可通过。

## 4. M2 · 一个地方为什么会长成这样

**① 核心追问**：明确观察范围与时期内，某种分布/密度/组合/朝向/层次是否确实存在，为什么这样组织？从人人看得见的细节进入，最终成为理解整体的一把钥匙。子问题：多相对于什么→集中在哪里→哪些不同→什么条件通过什么行动影响分布→解释能否容纳规律与例外。

**② 适用与不适用**：确认格局需对象纳入规则、观察范围、同一/可校正时期、足够覆盖记录；解释原因还需作用机制材料而非仅环境背景；比较密度须有可比分母，保存/调查差异单列。仅精选景点、年代混合、范围差异未交代时不作整体排名。与 M4 区别：本题主要解释空间差异与组织结果，可追过程但不要求完整生成史。

**③ 入口直觉**：从一次行走反复遇见的门/桥/巷口，或俯瞰图明显差异开始。「为什么走到这段河岸登岸口更密」比先给统计结论更易产生兴趣，但须材料确认后才可用「更密」。已知道分布直接进原因比较；对数量无感则改具体使用问题（如「居民怎样接近水面」）。不把「奇特/全国最多」作入口；首项发现是局部与整体关系，非地理百科。

**④ 认知进程（节拍）**

| 节拍 | 用户疑问 | 新增理解 | 常用构图/空间 | 进入下一步 |
|---|---|---|---|---|
| M2-P01 | 为什么反复出现同一种东西 | 识别值得观察特征 | C01 单景 / S02 | 不预设异常数量 |
| M2-P02 | 整体上真的如此吗 | 看见范围、分布及例外 | C04/C02 / S02/S05；M2-C01 | 口径可读 |
| M2-P03 | 哪些条件可能解释差异 | 区分待检验解释及预期表现 | C04 / S03 | 不把并置条件当原因 |
| M2-P04 | 条件怎样通过行动产生作用 | 人与环境/制度的具体机制 | C04 / S03；M2-C02 | 有材料支持 |
| M2-P05 | 为什么还有不一样的地方 | 用例外检查解释边界 | C02 对照 / S02；M2-C03 | 核对例外与覆盖 |
| M2-P06 | 再看入口细节会发现什么 | 把单对象放回整体组织 | C01 / S05；M2-C04 | 有可观察细节/可比较图 |

P02 不能省略范围；P03 不罗列所有假说只呈相关且有区分意义者；P04 至少完成一条受限机制，否则主线以格局收束、原因列下一项问题，不伪装已答。

**⑤ 判断与证据（M2-C0n）**

| 判断 | 核对 | 支持 | 误推 |
|---|---|---|---|
| M2-C01 存在某种空间格局 | 范围、纳入规则、年代、覆盖、分母 | 地图/清单/调查可核查可比较 | 现存数量=历史数量 |
| M2-C02 某机制解释部分格局 | 条件、人的行动、分布结果相连 | 建置使用记录、直接行动记载、可追溯研究 | 水多/便利自动解释全部 |
| M2-C03 解释覆盖某些不覆盖某些 | 例外是真实差异还是记录遗漏 | 对照对象相同核查口径 | 把反例隐藏或当噪声 |
| M2-C04 今日仍可观察某结构痕迹 | 历史与今日范围/对象对应 | 现场核对、沿革、图像 | 旅游改造形态直接反推历史 |

**⑥ UI 表达与操作**

| 节拍 | 舞台 | 墨痕与操作 | 输入 |
|---|---|---|---|
| P01 | 单景呈现可辨细节 | 提分布问题；点对象进整体 | 入口素材、对象身份 |
| P02 | 同范围分布或对照，边界与纳入可见 | 点局部仍能回全范围 | M2-C01、对象集合、范围、分母 |
| P03 | 按当前解释突出相关条件，不堆满图层 | 追问一种条件；保留待检验身份 | 候选解释及观察需求 |
| P04 | 条件、行动、受影响对象关联 | 选机制查依据 | M2-C02、活动及结果对象 |
| P05 | 例外与规律同时可辨 | 点例外说明未覆盖原因 | M2-C03、例外及未知 |
| P06 | 返入口对象，保留整体参照 | 给今日观察问题 | M2-C04 或历史图像任务 |

有逐点位置才绘分布；仅数量摘要用明确范围数量比较或定性图，不补造点位。跨范围比较保持比例口径一致。删去范围或例外会把局部误读为普遍规律。

**⑦ 数据生产**

| 专用字段 | 填写口径 | 生产检查 | 映射 |
|---|---|---|---|
| 观察范围与时段 | 边界、覆盖理由、有效时期 | 每对象是否属于范围 | Event 时间 + Place 范围 |
| 对象纳入与排除 | 类型、状态、登记标准及排除理由 | 不混合遗存/重建/仅记载 | Entity + Place(status) |
| 数量与分母 | 原始计数、长度/面积、单位与来源 | 缺分母不算密度；缺记录不记零 | Claim(量化，附口径) |
| 位置与覆盖 | 位置精度、未覆盖区 | 未覆盖不画空白事实 | Place(精度/reconstruction_status) |
| 机制 | 条件、行动、结果对象及判断身份 | 不能只填原因关键词 | Relation/Claim(机制) |
| 例外与竞争解释 | 例外对象、是否可比、替代解释 | 每例外说明保留或排除依据 | Claim(范围) |

**⑧ 不足/冲突/反证**：范围不完整标「已记录范围」禁全地方排名；口径不可比取消密度比较改并置。格局成立机制不足则保留 P02、P03 转可检验后续问题不进确定性 P04。反例先查年代/保存/调查差异，仍可比则收窄或撤回，不删点恢复规律；修订后同步更新受影响对象与墨痕。转 M4 携格局与机制线索补阶段；转 M1 聚焦实际活动联系不赋每个对象整体解释。

**⑨ 当下连接与验收**：再看登岸口/巷口/会馆时知其与周围活动空间关系；建议比较同街两片段或在原图找例外；无通行资料不作路线承诺。内容验收：格局是否确认、机制覆盖哪部分。UI 验收：局部与整体能往返、例外切换不消失。体验验收：哪个细节使你开始看整体；理解后会多注意哪种差异；只复述「市场繁荣所以设施多」不能说明条件如何通过行动产生作用，不算机制通过。

## 5. M3 · 过去的人生活在怎样的地图里

**① 核心追问**：明确时期内，对某个行动者/某类活动，哪些地方重要、哪些选择可行、什么目的和限制组织了空间？地图是生活空间组织方式（节点/次序/边界/可达条件/地点意义），不一定是历史地图。可解释个体/群体/组织，只要一人记录足以说明任务与选择即成立，不强制两群体比较。

**② 适用与不适用**：至少需行动者范围、活动目的、相关节点、一种有据使用条件或角色差异。无完整路线仍可解释节点重要性；无传记可讨论有据群体活动，不虚构姓名与第一人称。行动记录支持实际活动，不自动支持内心感受；精英舆图不默认代表所有居民。无条件材料可描述行程，不能宣称解释了生活空间组织逻辑。

**③ 入口直觉**：从「地图上最近的地方为什么未必是他先去的」进入（仅当材料真显示任务次序与空间距离差别），或从原图中心/方向/命名进入。第一项吸引力来自人的目的（送货/求学/取水/祭祀/治理/照料）。只展示与任务有关的生活条件，不以虚构对话制造代入。

**④ 认知进程（节拍）**

| 节拍 | 用户疑问 | 新增理解 | 常用构图/空间 | 进入下一步 |
|---|---|---|---|---|
| M3-P01 | 这次从谁的处境看 | 身份、时期、所问活动 | C01 / S03 | 群体代表范围明确 |
| M3-P02 | 他要完成什么 | 目的使节点具接货/许可/交付角色 | C04 / S03；M3-C01 | 支持 |
| M3-P03 | 什么条件改变了选择 | 时间/制度/交通/环境限制 | C04 / S03；M3-C02 | 支持 |
| M3-P04 | 地方重要性怎样改变 | 普通地标→任务关键节点/边界 | C04 / S03；M3-C03 | 不超记录 |
| M3-P05 | 别人/另一时段也这样吗 | 有材料比较处境，否则保留单一 | C02 / S05；M3-C04 | 可比才展开 |
| M3-P06 | 今天换一种眼光 | 从使用者目的理解空间 | C01 / S05 | 类比不作历史同一性 |

P03–P04 主转折；P05 可选非成立条件；从某对象进入可先显角色再补 P01/P02，不让所有人先读生平。

**⑤ 判断与证据（M3-C0n）**

| 判断 | 核验 | 支持 | 不可扩展 |
|---|---|---|---|
| M3-C01 行动者有某目的及任务 | 谁、哪次/类活动 | 日记/作业/行程/制度下活动记录 | 从职业标签推全部日常 |
| M3-C02 条件影响某项选择 | 限制是否适用、怎样影响 | 当次行为与条件记录、已核验研究 | 规定存在=人人同等影响 |
| M3-C03 节点具某角色 | 重要性指任务角色还是情感 | 交接/许可/停留/依赖记录 | 频次=情感认同 |
| M3-C04 不同处境可比较 | 时段/目的/代表性 | 可比记录或限定对照 | 几何距离/今日最短路代历史可达性 |

事件次序与地理路径分别核验；仅先后节点产顺序示意，准确路线须道路/航道/连接/有效时期/证据。

**⑥ UI 表达与操作**

| 节拍 | 舞台 | 墨痕与操作 | 输入 |
|---|---|---|---|
| P01 | 保留地方对象，标明行动者范围 | 说明此次观察目的 | 身份、时期、代表范围 |
| P02 | 对象增任务角色而非仅改标题 | 选对象说明为何有关 | M3-C01、C03、节点角色 |
| P03 | 条件就近作用于受影响对象/选择 | 追问限制依据与结果 | M3-C02、条件与行为 |
| P04 | 突出关键节点/依赖/顺序，不伪造距离 | 说明空间组织与普通观看区别 | 角色、关系、表达精度 |
| P05 | 有据时对照同对象不同角色 | 墨痕改视角，留原焦点 | M3-C04、可比条件 |
| P06 | 今日图像/对象引观察任务 | 问今天谁因不同目的使用 | 当下素材或远程内容 |

改换视角须使焦点/角色/可达条件/关系至少一项发生与问题相关变化，不仅替换旁白；不给每群体固定按钮；不显无依据角色行走；条件未知不生成「最佳历史路线」。

**⑦ 数据生产**

| 专用字段 | 填写口径 | 缺失/误用 | 映射 |
|---|---|---|---|
| 行动者与代表范围 | 个体/群体/组织，覆盖哪些人活动 | 无法代表全体限定个体 | Entity(人/群体) |
| 目的与任务 | 原记载或研究解释分别标识 | 不由职业自动生成任务 | Claim(目的) |
| 节点及角色 | 接货/许可/交付/照料等实际角色 | 地名不是角色 | Relation(predicate) |
| 次序与路径 | 事件先后、精确路径分别存 | 次序未知不排序；路径未知不落路 | Event(次序) + Place |
| 条件与选择 | 制度/交通/时间/身体/环境及影响 | 制度要求与实际行动分开 | Claim(条件→选择) |
| 主观意义 | 讲述者、用语、形成时间、出处 | 无材料不写内心独白 | Claim(source=口述/研究) |
| 比较资格 | 对照群体/时期/活动/不可比项 | 不可比保留并置不排名 | Judgment scope |

**⑧ 不足/冲突/反证**：有节点无路径保持 P02–P04 角色与顺序示意；只有制度无行动写「规定要求」不演示真实经历；身份不明限定匿名不补姓名；缺第二群体直接跳 P05 不视失败。同一行动者记录矛盾先查任务/时段/地点；用户追问未记录改道/感受/目的，答缺口保留场景不补合理无据补全。转 M1 新核整体活动联系；转 M5 新核当前实践是否延续。

**⑨ 当下连接与验收**：观察同街对居民/游客/配送者不同用途，或理解某地点今日不显眼却在某种生活中重要。明确这是观察方法迁移，不把今天使用反当历史证明。理解验收：能说目的、角色、至少一项有据条件；仅复述人名或路线不通过。体验验收：人物目的是否让人愿意跟随，条件揭示是否改变观看方法；无需认同/想象内心，也无需生成路线；用陌生另一活动做简短迁移提问检查真理解而非背故事。

## 6. M4 · 一个地方究竟是怎样活起来的

**① 核心追问**：一个地方怎样从某种状态转为另一种状态，哪些条件/行动/事件参与转变？可是形成/扩展/转向/衰退/停顿/再生，不预设持续繁荣。对象不限于聚落，也可是街/文化活动空间/交通联系。子问题：变化前是什么→哪项确实发生→谁做了什么→作用如何传递→其他竞争解释→后来怎样继续或中断。完整小成果可只解释一个转折。

**② 适用与不适用**：描述变化至少需可比较前后状态及时间范围；解释机制还需连接条件/行动/结果的材料。环境提供可能、政策表达意图，仅时间先后或共同出现不能单独证明实际作用。只有两时点图像做阶段比较不制生成机制故事；只有传说/后世总结按材料性质呈现，未核验不给唯一因果；年代先后不确定先展各说不以精确时间轴掩盖冲突。

**③ 入口直觉**：从今日状态提有意思的形成问题（如「这里何时从偶尔停靠变稳定交接」）；衰退与再生也可入口。第一项发现是两种状态间具体差别，非把年代列表从头播。让人看见一个行动怎样改变可做的事情，比泛称经济繁荣更有吸引力。用户只问某转折从对应阶段进，前情由墨痕补足。

**④ 认知进程（节拍）**

| 节拍 | 用户疑问 | 新增理解 | 常用构图/空间 | 进入下一步 |
|---|---|---|---|---|
| M4-P01 | 今天的状态怎样形成 | 找到需解释的变化 | C01 / S04 | 问题范围可收敛 |
| M4-P02 | 前后确实有哪些不同 | 区分已知状态与空白 | C02 对照 / S05；M4-C01 | 可比较支持 |
| M4-P03 | 什么条件使改变可能 | 自然/技术/制度条件角色 | C04 / S03；M4-C02 | 不将可能当必然 |
| M4-P04 | 谁采取什么行动产生作用（主转折） | 作用链中有据连接 | C04/C05 / S04；M4-C03 | 支持 |
| M4-P05 | 其他解释或不同走向 | 机制范围、竞争解释或中断 | C02 / S05；M4-C04 | 服务判断不罗列无据假说 |
| M4-P06 | 今天处在什么历史阶段 | 眼前状态看作过程结果与继续 | C01 / S04 | 有今日材料才说明 |

P04 必须区别「某事发生」与「它如何产生影响」；机制不足则 P03 后返阶段比较开放收束，不以动画填平。

**⑤ 判断与证据（M4-C0n）**

| 判断 | 核验 | 支持 | 不可替代缺口 |
|---|---|---|---|
| M4-C01 状态确实变化 | 对象身份、时间、口径可比 | 分期地图/图像/活动/数量记录 | 保存/登记变化造表面差异 |
| M4-C02 某人或组织采取行动 | 意图/实施/完成分开 | 实施/工作/费用/使用记载 | 只发布文件≠完成 |
| M4-C03 行动对结果产生作用 | 作用环节及结果对应 | 行动后具体使用/机制/可核验研究 | 时间先后≠作用证明 |
| M4-C04 解释在一定范围成立 | 其他条件/反证/未覆盖 | 竞争解释核查与推理范围 | 未找其他≠排除其他原因 |

机制可由多份观察与研究解释共建，不要求原始材料写现代因果术语，但须显式记录推理；争议保存不同立场及证据。

**⑥ UI 表达与操作**

| 节拍 | 舞台 | 墨痕与操作 | 输入 |
|---|---|---|---|
| P01 | 聚焦当前待解释状态 | 提形成/转变问题 | 当前素材、对象、范围 |
| P02 | 可比状态并置或逐状态 | 选差异进解释；显时段精度 | M4-C01、状态与可比条件 |
| P03 | 显与转变相关条件 | 说明条件提供什么可能 | 条件记录及作用资格 |
| P04 | 实施行动/作用环节/结果分别呈现 | 点环节看依据；先后与影响不同说明 | M4-C02、C03、推理记录 |
| P05 | 留缺口，比较有据解释或阶段走向 | 追问为何采用此解释 | M4-C04、反证/竞争 |
| P06 | 回当前状态及可辨痕迹 | 给今日观察或继续提问入口 | 今日核对或无法对应说明 |

连续镜头引导看不同已知状态，不把补间登记成事实；间隔不均不暗示均匀发展；原因未知不用确定性因果箭头，顺序箭头须标「先后」。动画只增强已成立理解，关动画信息仍完整。

**⑦ 数据生产**

| 专用字段 | 填写口径 | 核验/缺失 | 映射 |
|---|---|---|---|
| 阶段状态 | 时段、对象状态、观测口径、材料 | 不邻时点插中间状态 | Event(阶段) |
| 条件 | 自然/交通/制度等解释相关条件 | 背景存在≠产生作用 | Claim(条件) |
| 行动事件 | 行动者、意图、实施、完成时间分别 | 未知实施不写完成 | Event + Relation |
| 结果 | 可观察变化、何时出现、覆盖 | 意图不填结果 | Claim(结果) |
| 作用链 | 每连接判断、支持观察与推理 | 无依据连接留缺口 | Relation(因果，标先后≠影响) |
| 竞争解释 | 内容、材料、未排除因素 | 不把未采集写已排除 | Claim(范围) |
| 时间精度与冲突 | 日期/区间/先后限制/不同说法 | 不强行选精确年排序 | Event 时间 + 时间六类 |

**⑧ 不足/冲突/反证**：只有前后状态留 P02 收窄已知变化；有规定无实施呈意图及未知执行；实施可确结果不明停在行动事实不接确定结果；年代冲突显范围或并列说法暂停依赖精确先后的机制。反证否定某作用环节则撤回该连接复核后续，保留仍有支持的状态与行动事实；中断/衰退/逆转是正常主线真实结果非失败分支。转 M2 新核格局覆盖；转 M1 新核具体活动关系；不共享事件自动继承所有因果。

**⑨ 当下连接与验收**：理解一处设施为何形成、街区为何留某种组织、日常空间是人在条件中不断选择的结果。用具体遗存/图像/今日使用建立连接，不以「历史规律」收尾。内容验收：区分状态/行动/机制三层；用户能指一个有据转折及至少一未解释较大问题。UI 验收：先后与影响不混同，缺口不被动画跨过。体验验收：变化是否带来期待与理解转折而非仅记日期；能说「这次行动改变了什么可行条件」比背事件名更能说明理解；只列年代登记时间梳理通过，不登记生成机制已解释。

## 7. M5 · 今天到底还剩多少过去

**① 核心追问**：今天看到/使用/称呼/记忆的对象，与过去在哪些层面承接、经历什么改变？按用户问题选物质/位置/名称/功能/关系/实践/记忆层面，不给整件对象一次性判真或假。可从建筑/地名/习惯/器物进入；一般当下连接不必转 M5，只有追问历史承接才进。与 M4 相交时 M4 解释变化机制，M5 判变化后还承接什么。

**② 适用与不适用**：至少需今日对象或讲述明确身份，及一个可追溯历史状态。位置/名称相同不足以独证同一对象；迁建/更名/复名/重建/后期叙事分别核查。只知相隔时期状态可解释这些时点承接证据，不能证期间从未中断。无材料清单不计算原物比例；无历史外观不制写实古今擦拭；口述证某种记忆被讲述不自动证被讲述事件发生。历史建筑重建与 UI 解释性复原是两类不同对象。

**③ 入口直觉**：「这座新修过的桥还能看见什么旧联系」或「建筑换了为什么名字还在」。不以揭穿仿古为默认剧情，也不把文化意义当事实可信替代。首项发现来自某具体层面证据差别（如位置保留而构件更换）；用户可只问一层。无真假疑问直接从今日用途/名称/记忆进入，不先造误解再纠正。审美体验保留：让人愿细看变化而非把对象变检验清单。

**④ 认知进程（节拍）**

| 节拍 | 用户疑问 | 新增理解 | 常用构图/空间 | 进入下一步 |
|---|---|---|---|---|
| M5-P01 | 今天我看到的是什么 | 明确今日对象及具体追问 | C01 / S05 | 今日观察身份可核查 |
| M5-P02 | 所问的是哪种过去 | 分开本次承接层面 | C03 / S03 | 不强制展开七层 |
| M5-P03 | 各层材料分别说明什么 | 分辨原物/位置/名称/实践等证据 | C02 对照 / S05；M5-C01、C02 | 对应层面支持 |
| M5-P04 | 中间经历了什么变化 | 重建/迁移/停用/恢复分别可辨 | C02 / S05；M5-C03 | 缺口不被补齐 |
| M5-P05 | 最初整体判断怎样调整 | 形成按层说明理解 | C02 / S03；M5-C04 | 不以平均合不同层真假 |
| M5-P06 | 今天怎样看待与使用 | 细致辨认转观察/审美/生活理解 | C01 / S05 | 事实与价值判断区分 |

P03 可只一维但用户问整体须提示未答层面；P04 不要求完整历代连续史，展可支持节点并使缺口可辨；P05 转折来自细致理解不预设惊人反转。

**⑤ 判断与证据（M5-C0n）**

| 判断 | 核验 | 支持 | 不可扩展 |
|---|---|---|---|
| M5-C01 身份对应 | 位置/名称/沿革/迁移组合 | 身份沿革与现场核对 | 同名=同一物 |
| M5-C02 某层面特定时点相同或不同 | 物质/位置/用途等维度 | 该维度直接相关材料 | 某层一致推所有层连续 |
| M5-C03 存在改变或承接过程 | 重建/迁移/停用/复名事件 | 工程/使用/沿革记录 | 两端相同推中间从未中断 |
| M5-C04 今日实践/记忆有特定来源 | 谁讲述、何时形成、怎样使用 | 口述/现场/实践/研究 | 今日记忆独证古代事件 |

建造时间/构件年代/命名时间/功能存在时间分别记录；文保认定可作一种来源不替代未认定的物质细节；来源冲突保留各自支持层面与范围。

**⑥ UI 表达与操作**

| 节拍 | 舞台 | 墨痕与操作 | 输入 |
|---|---|---|---|
| P01 | 今日对象单景或材料，不预贴真假 | 提当前层面疑问 | 今日素材、对象身份 |
| P02 | 只突出所问层面 | 关联追问切换层面，留对象 | 维度定义与可用判断 |
| P03 | 有可比条件则对照，否则并置阅读 | 选具体层面依据 | M5-C01、C02、可比资格 |
| P04 | 显已知变化节点与未覆盖区间 | 点节点说改变依据 | M5-C03、时段精度与空白 |
| P05 | 同对象层面结论并存不平均 | 答原问题，指未答范围 | 分层判断与状态 |
| P06 | 回今日细节或实践场景 | 给值得细看部位或继续观察问题 | M5-C04 或仅物质当下内容 |

同视角/配准有依据才叠加或擦拭，否则并置避免伪造精确连续；百分比只有完整清单与明确口径才可能，本稿示例不提供该条件；材料间空白不是视觉故障，不能用连续实线掩盖。

**⑦ 数据生产**

| 专用字段 | 填写口径 | 缺失/冲突 | 映射 |
|---|---|---|---|
| 对象身份链 | 历史对象、今日对象、别名、迁移依据 | 名同身份不明不合并 | Entity + Relation(沿革) |
| 承接维度 | 物质/位置/名称/功能/关系/实践/记忆 | 每判断只对应明确层面 | Claim(分层) |
| 状态与观察时间 | 各时点所见及材料 | 不用今日所见填历史空白 | Event 时间 + 时间六类 |
| 变化事件 | 修建/重修/迁建/停用/恢复类型 | 工程事件与 UI 复原另记 | Event + Claim |
| 中间覆盖 | 连续记录/离散时点/未知区间 | 离散不填持续连续 | Event 时间精度 |
| 构件与范围 | 构件清单、部位、年代、核查程度 | 无清单不生成原物比例 | Place(构件/reconstruction_status) |
| 实践与记忆 | 参与者/讲述者、日期、内容、来源性质 | 记忆存在与事件发生分不同判断 | Claim(source=口述/实践) |

**⑧ 不足/冲突/反证**：原物范围不明答已知工程及未核部分取消比例；无同视角取消擦拭保留并置；只两时点展两记录明中间未知；用户只问桥名可仅答名称不强迫其他六层。身份冲突先分候选及其依据暂停叠加；后发现迁建/复名更新受影响层面不抹除其他层判断。转 M4 追改变怎样发生新增机制；转 M1 追旧关系是否仍存新增今日活动证据，不凭名称延续作答。

**⑨ 当下连接与验收**：更细致观看修复痕迹、理解地名记忆作用、观察旧功能消失后空间如何被使用；可欣赏重建桥同时清楚哪些非旧构件；事实说明不强制统一价值评价。理解验收按实际问题：问一维能清该层证据与缺口即可；问整体能分多层面并指出未答部分；不得以「至少说出两层」作统一门槛。UI 验收无伪精确比例或连续时间带替代材料。体验验收：是否愿再看一细节、对修复和使用产生更具体问题，而非只获古/不古标签；未知≠无价值，文化意义≠事实已证。

## 8. 四类跨母题待补画面（来自 Review V1.2，施工硬要求）

主稿已给方法，下列四类是 V0.9.1 当前最薄弱、须在本施工图中显式落实的能力；它们**不新增常驻面板**，全部在双组件内实现。

**8.1 时间作为叙事镜头**
- 是什么：时期、对象出现/消失、关系在哪个阶段成立，都是画面内容。
- 落点：作为舞台/墨痕中的**内容层**呈现（如 P02/P04 显时段精度、P05 显变化区间），切换操作放墨痕或视觉要素；**不恢复舞台工具条**。
- 运行期：`time` 维度进入 `CompositionState` 的视觉焦点标注，不另开时间栏。

**8.2 人物与行动（当前最薄弱）**
- 是什么：目前 UI 多是桥/河/街几何对象，缺人的劳动、往来、选择、生活。
- 落点：M1/M3/M4 的舞台须呈现「谁在做什么」的角色与动作（P02/P03/P04）；墨痕点出行动者与目的，不替用户虚构内心。
- 运行期：从 `Entity(人/群体)` + `Relation(动作)` 驱动，不堆几何标注。

**8.3 证据导致的理解修正**
- 是什么：查看依据须对应「某判断 → 某材料 → 某位置 → 支持范围」；冲突时看不同说法怎样影响理解。
- 落点：墨痕依据入口**绑定当前判断 ID（Mx-C0n）**，非整场景通用列表；来源按钮对应当前判断；不能读原件显摘要身份不伪造扫描页。
- 运行期：依据读取回填 `evidence` 与对应 `Claim`，并标注支持/冲突状态。

**8.4 动态 Proposal 与 Experience Trail**
- 是什么：把固定「继续看/前后步」转为有意义的提议（如「看看这项联系在哪个时期成立」）；用 **Experience Trail**（状态补丁历史）替代仅「上一步」。
- 落点：Proposal 由 Evidence/AskBar 检索结果驱动，在双组件内给出可点建议；Trail 记录已走过的节拍与判断，返回恢复内容上下文且**采用最新用户布局**。
- 运行期：复用 `ExperienceShell.resolveComposition / selectReplanSurface / FOLLOWUP_REPLAN`；新增「母题→Composition」映射与 Trail 栈，不重构外壳、不覆盖用户布局选择。

## 10. 数据生产优先级与金泽盘点（B4，四状态）

按主稿 §7 流程：① 选问题及范围（不预设答案）② 盘点取得材料 ③ 提取观察（原文与归纳分开）④ 形成并核验判断（主线判断在范围成立）⑤ 编排叙事（每节拍有新增理解、分支出口明确）⑥ 制作素材与画面输入（身份明确、不超判断）⑦ 分别检查内容与体验。
