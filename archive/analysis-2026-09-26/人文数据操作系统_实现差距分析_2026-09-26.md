# 《墨痕人文数据操作系统与双 Skill 架构 V1.0》实现差距分析

> 生成：2026-09-26 ｜ 用途：把 ChatGPT 整理的 V1.0 架构 docx，逐项对照 `mohen-agent-2.0` 当前代码事实，判"已实现 / 部分实现 / 未实现"。
> 读法：✅ 已实现（结构+数据+可跑）｜🟡 部分实现（schema 在/骨架在，但机制或填充不足）｜❌ 未实现。

---

## 〇、这份文档本身是什么

- 定位：架构**整理与归位**稿（不是施工权限源）。附录 A 明写"不替代 L1 Roadmap / Phase Execution Plan / Task Book；若要升级为仓库正式 Source of Truth，需单独做 Architecture Reconciliation"。
- 三大件：① 人文数据操作系统（HD OS，6 层 L0–L5）② Developer Skills（11 个，造世界）③ Agent Skills（8 语义 + 5 第一阶段执行，在世界里行动）。
- 桥梁：Living Cultural Relationship Model（关系→证据→意义→当下）；Agent-native Experience（Agent 改 Experience State/Composition，不是生成 UI）。
- 关键自判（§8）：**Agent 主要是"冻结 JSON + reducer / 关键词规则"，Agent Skills 尚未真正形成**；体验仍像研究页；关系存在但无"发现感"。

## 四、Living Cultural Relationship Model（§5，双 Skill 桥梁）

- Schema 已备：`cultural_relation_claims` 带 `evidence_fragment_ids` / `meaning_refs` / `present_connection_refs` / `conflict_refs`；配 `cultural_meaning_candidates` / `cultural_present_connections` / `cultural_conflicts`(008)。
- **但未实现"五层桥"的运行转译**：普通关系 → 历史关系（时间/空间/功能）→ 证据关系（谁留下、支持到哪）→ 意义关系（为何改变理解）→ 当下连接（重新看见今天）。关系多为普通 `relations`，Cultural Relation 薄；Discovery→Experience 转译不足（§8）。
- 判定：🟡（schema 在，活的桥未成）。

## 五、Agent-native Experience（§6，Agent 变用户体验）

- ✅ 架构实现：`ExperienceState` / `CompositionState` / `Surface`(地图/时间/关系/图像/史料/现场/证据) / `ExperienceAction`(聚焦/时间切换/图像对照/证据打开/局部 Patch) / `Renderer` —— 全部在 `packages/experience-engine` + `apps/web/app/experience/jinze-water-net`。
- 🟡 但"舞台建成、导演未活"：`ExperienceShell` 读 **5 份冻结 JSON** 驱动，Composition 是烘焙好的；Agent 运行期不实时决定 Surface 主角（S07 未活）。即 Developer Skill `experience-prototype` 造了舞台，Agent Skill `experience_orchestration` 没当导演。
- 判定：✅架构 / 🟡运行时未由 Agent 驱动。

## 七、最关键的三个"未实现"（飞轮缺口）

1. **Agent Skills 未真正形成**（§8 自认）：8 能力无运行期可执行方法；墨痕仍是"冻结 JSON + 确定性 reducer"，不是会探索的 Agent。这是 M5 人工门 FAIL 的根因。
2. **Living Cultural Relationship Model 未运转**：schema 在，但"普通关系→历史→证据→意义→当下"五层桥没有运行转译；用户看不到"发现"。
3. **飞轮未闭环**：文档 §7.1 的"用户新问题→暴露缺口→Developer Skills 补世界"循环没有运转——当前是一次性 Vertical Slice + 冻结体验，没有"问题驱动开发补世界"的回流。

## 八、建议（待你拍板，未执行）

- **短期最该补的不是数据量，是 Agent Skills 的"活"**：把 S07 experience_orchestration 从"读冻结 JSON"升级为"运行期基于 retrieve 结果实时决定 Surface 主角"，并让 S03/S08 真正产出"发现感/当下连接"。这直接对应 M5 Human Gate。
- 薄 Developer Skill（7 个）可补 `.mjs` 进程使其"一键运行"，但优先级低于 Agent 活化。
- 是否把本 V1.0 升级为仓库正式 Source of Truth（文档说需 Architecture Reconciliation）——建议等 Agent Skills 活化一轮后再做，避免冻结一份"骨架已成就、灵魂未到"的架构当真源。
